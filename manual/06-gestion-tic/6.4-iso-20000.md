# 🧭 1. ¿QUÉ ES ISO/IEC 20000?

**ISO/IEC 20000** es una familia de normas relacionada con la **gestión de servicios de TI**.

Su componente más importante para nuestro estudio es:

> **ISO/IEC 20000-1:2018 · Information technology — Service management — Part 1: Service management system requirements**

En España existe como:

> **UNE-ISO/IEC 20000-1:2018 · Tecnologías de la información. Gestión de Servicios. Parte 1: Requisitos del Sistema de Gestión de Servicios (SGS).**

La versión UNE fue publicada en 2018, confirmada en 2023 y modificada por la enmienda de 2024. citeturn0search10

# 🧠 3. ISO/IEC 20000 NO ES ITIL

Esta es probablemente la distinción más importante del capítulo.

```text
ITIL
→ framework de buenas prácticas

ISO/IEC 20000
→ norma internacional con requisitos
```

ITIL ayuda a responder:

> ¿Qué buenas prácticas podemos utilizar para gestionar servicios?

ISO/IEC 20000-1 ayuda a responder:

> ¿Qué requisitos debe cumplir nuestro sistema de gestión de servicios?

---

# ⚖️ 4. ITIL VS ISO/IEC 20000

| ITIL | ISO/IEC 20000 |
|---|---|
| Framework | Norma internacional |
| Buenas prácticas | Requisitos |
| Orientación | Conformidad |
| No es una norma de certificación organizativa | Puede utilizarse como base para evaluación de conformidad |
| SVS, prácticas, principios | Sistema de Gestión de Servicios |
| Flexible | Deben cumplirse los requisitos aplicables |

### Frase para memorizar

```text
ITIL
→ recomendaciones / buenas prácticas

ISO 20000
→ requisitos / conformidad
```

# 🏗️ 5. ¿QUÉ ES UN SMS?

**SMS** significa:

> **Service Management System**

En español:

> **Sistema de Gestión de Servicios (SGS).**

Es el sistema de gestión utilizado para dirigir y controlar las actividades de gestión de servicios de una organización.


# 🏛️ 44. ISO/IEC 20000 Y PDCA

La estructura de las normas de sistemas de gestión se relaciona conceptualmente con el ciclo:

```text
PLAN
 ↓
DO
 ↓
CHECK
 ↓
ACT
```

Aplicado de forma simplificada:

```text
PLAN
→ contexto + liderazgo + planificación

DO
→ apoyo + operación

CHECK
→ evaluación

ACT
→ mejora
```

> ⚠️ Para el examen, no conviene afirmar que "ISO 20000 consiste únicamente en PDCA". Es una forma útil de visualizar la mejora y el control, no una sustitución de la estructura normativa.

---

# 🔗 45. RELACIÓN CON ITIL

ITIL e ISO/IEC 20000 pueden utilizarse conjuntamente.

Ejemplo:

```text
ITIL
↓
proporciona prácticas y orientación

ISO/IEC 20000
↓
establece requisitos del SMS

Organización
↓
implementa su sistema
```

Una organización puede utilizar prácticas ITIL como apoyo para cumplir determinados requisitos de gestión de servicios.

---

# ⚖️ 46. ISO/IEC 20000 VS ISO 9001

No confundir.

```text
ISO 9001
→ sistema de gestión de la calidad

ISO/IEC 20000-1
→ sistema de gestión de servicios
```

Ambas utilizan estructuras de sistemas de gestión y pueden coexistir.

---

# 🧠 47. ISO/IEC 20000 VS ISO/IEC 27001

Tampoco son equivalentes.

```text
ISO/IEC 20000-1
→ gestión de servicios

ISO/IEC 27001
→ sistema de gestión de seguridad de la información
```

La seguridad puede formar parte de la gestión de servicios, pero son normas diferentes.
