# 1. Seguridad en VMware

Una infraestructura virtualizada concentra muchos servicios.

Un único host ESXi puede ejecutar:

```text
VM01
VM02
VM03
VM04
VM05
```

Por tanto:

> Comprometer el hypervisor puede tener un impacto mucho mayor que comprometer una única máquina virtual.

# 4. Principio de mínimo privilegio

Uno de los conceptos más importantes:

> **Least Privilege**

Cada usuario o servicio debería disponer únicamente de los permisos necesarios para realizar su función.

Ejemplo:

```text
Operador de backups
```

no necesita necesariamente:

```text
Permisos de administración completa de vCenter
```

---

# 5. RBAC

> **Role-Based Access Control**

permite asignar permisos mediante:

```text
Roles
```

en lugar de definir cada permiso de forma aislada para cada usuario.

# 257. 📌 Frases para memorizar

> **Authentication responde "¿quién eres?"**

> **Authorization responde "¿qué puedes hacer?"**

> **RBAC asigna permisos mediante roles.**

> **Least Privilege reduce permisos innecesarios.**

> **Snapshot no es backup.**

> **Replication no sustituye automáticamente al backup.**

> **RPO mide la pérdida de datos aceptable.**

> **RTO mide el tiempo objetivo de recuperación.**

> **Un backup que nunca se restaura no está completamente validado.**

> **PowerCLI permite automatizar VMware mediante PowerShell.**

> **IaC busca infraestructura repetible y versionable.**

> **La automatización debe tener permisos mínimos.**

> **Un script potente puede propagar un error potente.**
