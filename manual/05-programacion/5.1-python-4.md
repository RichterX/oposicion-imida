# 1. INTRODUCCIÓN

Hasta ahora hemos visto cómo escribir instrucciones directamente:

```python
nombre = "Pedro"

if nombre:
    print(nombre)
```

Sin embargo, cuando un bloque de código necesita reutilizarse varias veces, podemos encapsularlo dentro de una **función**.

Las funciones permiten:

```text
Reutilizar código
Organizar programas
Reducir duplicación
Recibir datos
Devolver resultados
```

La estructura básica es:

```python
def nombre_funcion():
    instrucciones
```

---

# 2. DEFINIR UNA FUNCIÓN

Utilizamos la palabra reservada:

```python
def
```

Ejemplo:

```python
def saludar():
    print("Hola")
```

La función todavía no se ejecuta.

Para ejecutarla:

```python
saludar()
```

Resultado:

```text
Hola
```

### 🧠 Idea fundamental

```text
def
 ↓
define la función

nombre()
 ↓
ejecuta la función
```

---

# 3. LLAMAR A UNA FUNCIÓN

Una función se ejecuta mediante una llamada:

```python
saludar()
```

Podemos llamar varias veces:

```python
saludar()
saludar()
saludar()
```

Resultado:

```text
Hola
Hola
Hola
```

# 4. PARÁMETROS

Una función puede recibir datos.

```python
def saludar(nombre):
    print(f"Hola {nombre}")
```

Aquí:

```text
nombre
```

es un **parámetro**.

Podemos llamar:

```python
saludar("Pedro")
```

Resultado:

```text
Hola Pedro
```

---

# 5. PARÁMETRO VS ARGUMENTO

Esta diferencia es importante.

En:

```python
def saludar(nombre):
    print(nombre)
```

`nombre` es un:

```text
parámetro
```

En:

```python
saludar("Pedro")
```

`"Pedro"` es un:

```text
argumento
```

### 🧠 Regla

```text
Definición → parámetro
Llamada    → argumento
```

---

# 6. VARIOS PARÁMETROS

Podemos definir varios:

```python
def sumar(a, b):
    print(a + b)
```

Llamada:

```python
sumar(10, 20)
```

Resultado:

```text
30
```

# 7. `return`

Una función puede devolver un resultado mediante:

```python
return
```

Ejemplo:

```python
def sumar(a, b):
    return a + b
```

Podemos almacenar el resultado:

```python
resultado = sumar(10, 20)

print(resultado)
```

Resultado:

```text
30
```

---

# 8. `print()` VS `return`

No debemos confundirlos.

### `print()`

Muestra información:

```python
def sumar(a, b):
    print(a + b)
```

### `return`

Devuelve información:

```python
def sumar(a, b):
    return a + b
```

Con `return` podemos hacer:

```python
resultado = sumar(10, 20)
```

y reutilizar el resultado.

### 🧠 Regla

```text
print()
→ muestra

return
→ devuelve
```

---

# 9. `return` TERMINA LA FUNCIÓN

Cuando Python encuentra:

```python
return
```

la función termina inmediatamente.

Ejemplo:

```python
def ejemplo():
    print("A")
    return
    print("B")
```

Resultado:

```text
A
```

`"B"` nunca se ejecuta.

---

# 10. `return` SIN VALOR

Podemos utilizar:

```python
return
```

sin especificar un valor.

En ese caso la función devuelve:

```python
None
```

Ejemplo:

```python
def ejemplo():
    return

resultado = ejemplo()

print(resultado)
```

Resultado:

```text
None
```

---

# 11. FUNCIONES SIN `RETURN`

Si una función no ejecuta ningún `return` explícito:

```python
def saludar():
    print("Hola")
```

su valor de retorno es igualmente:

```text
None
```

Por tanto:

```python
resultado = saludar()
```

hace que:

```text
resultado → None
```

aunque la función haya mostrado `"Hola"`.

# 12. VARIOS `return`

Una función puede tener varios `return`.

```python
def mayor_de_edad(edad):
    if edad >= 18:
        return True
    return False
```

También podemos escribir:

```python
def mayor_de_edad(edad):
    if edad >= 18:
        return True
    else:
        return False
```

En cuanto se ejecuta uno de los `return`, la función termina.

# 13. PARÁMETROS CON VALOR POR DEFECTO

Podemos asignar un valor por defecto:

```python
def saludar(nombre="mundo"):
    print(f"Hola {nombre}")
```

Si no proporcionamos argumento:

```python
saludar()
```

Resultado:

```text
Hola mundo
```

Si proporcionamos uno:

```python
saludar("Pedro")
```

Resultado:

```text
Hola Pedro
```

# 14. ORDEN DE PARÁMETROS

Los parámetros sin valor por defecto deben aparecer antes que los parámetros con valor por defecto.

Correcto:

```python
def funcion(a, b=10):
    pass
```

Incorrecto:

```python
def funcion(a=10, b):
    pass
```

Esto produce un error de sintaxis.

### 🧠 Regla

```text
parámetros obligatorios
        ↓
parámetros opcionales
```

# 15. ARGUMENTOS POSICIONALES

Los argumentos pueden asociarse por posición.

```python
def presentar(nombre, edad):
    print(nombre, edad)

presentar("Pedro", 35)
```

Aquí:

```text
nombre → "Pedro"
edad   → 35
```

porque coinciden las posiciones.

---

# 16. ARGUMENTOS NOMBRADOS

Podemos especificar explícitamente el nombre del parámetro:

```python
presentar(nombre="Pedro", edad=35)
```

También podemos cambiar el orden:

```python
presentar(edad=35, nombre="Pedro")
```

El resultado es el mismo.

---

# 17. ARGUMENTOS POSICIONALES + NOMBRADOS

Podemos combinar ambos:

```python
def presentar(nombre, edad, ciudad):
    print(nombre, edad, ciudad)

presentar("Pedro", edad=35, ciudad="Murcia")
```

Pero un argumento posicional no puede aparecer después de un argumento nombrado.

Incorrecto:

```python
presentar(nombre="Pedro", 35, ciudad="Murcia")
```

# 18. `*args`

Python permite recibir un número variable de argumentos posicionales mediante:

```python
*args
```

Ejemplo:

```python
def sumar(*args):
    return sum(args)
```

Podemos llamar:

```python
sumar(1, 2)
sumar(1, 2, 3)
sumar(1, 2, 3, 4, 5)
```

Dentro de la función:

```python
args
```

es una:

```text
tuple
```

---

# 19. EJEMPLO DE `*args`

```python
def mostrar(*args):
    print(args)

mostrar(10, 20, 30)
```

Resultado:

```text
(10, 20, 30)
```

### ⚠️ Trampa

`args` no es una lista.

Es una:

```text
tuple
```

El nombre `args` es una convención. Lo importante es el `*`.

También sería válido:

```python
def mostrar(*numeros):
    print(numeros)
```

---

# 20. `**kwargs`

Para recibir un número variable de argumentos nombrados utilizamos:

```python
**kwargs
```

Ejemplo:

```python
def mostrar(**kwargs):
    print(kwargs)
```

Llamada:

```python
mostrar(nombre="Pedro", edad=35)
```

Resultado conceptual:

```python
{
    "nombre": "Pedro",
    "edad": 35
}
```

`kwargs` es un:

```text
dict
```

---

# 21. `*args` VS `**kwargs`

| Sintaxis | Recibe | Tipo dentro de la función |
|---|---|---|
| `*args` | Argumentos posicionales variables | `tuple` |
| `**kwargs` | Argumentos nombrados variables | `dict` |

### 🧠 Regla

```text
*args
→ tuple

**kwargs
→ dict
```

# 30. LEGB

Python busca nombres siguiendo el principio:

```text
L → Local
E → Enclosing
G → Global
B → Built-in
```

Es decir:

```text
Local
  ↓
Enclosing
  ↓
Global
  ↓
Built-in
```

Este mecanismo se conoce como **regla LEGB**.

---

# 31. LOCAL

Python busca primero en el ámbito de la función actual.

```python
x = "global"

def funcion():
    x = "local"
    print(x)

funcion()
```

Resultado:

```text
local
```

La variable local tiene prioridad.

---

# 32. ENCLOSING

El ámbito **enclosing** aparece especialmente cuando tenemos funciones anidadas.

```python
def externa():
    x = "externa"

    def interna():
        print(x)

    interna()

externa()
```

La función `interna()` encuentra `x` en el ámbito de la función `externa()`.

---

# 33. GLOBAL

Si no encuentra el nombre en los ámbitos anteriores, Python busca en el ámbito global.

```python
x = 100

def funcion():
    print(x)

funcion()
```

Resultado:

```text
100
```

```text
sum
type
str
int

dict
```

Por ejemplo:

```python
print(len([1, 2, 3]))
```

Python encuentra:

```text

len
```

en el ámbito de nombres incorporados.

# 35. `global`

# 37. `nonlocal`

`nonlocal` se utiliza con variables de un ámbito **enclosing**.

Ejemplo:

```python
def externa():
    contador = 0

    def interna():
        nonlocal contador
        contador += 1

    interna()

    print(contador)

externa()
```

Resultado:

```text
1
```

### 🧠 Diferencia

```text
global
→ variable del ámbito global

nonlocal
→ variable de una función exterior/enclosing
```

Con `def`:

# 43. `map()`

`map()` aplica una función a cada elemento de un iterable.

Ejemplo:

```python
numeros = [1, 2, 3, 4]

resultado = map(lambda x: x * 2, numeros)
```

Podemos convertirlo en lista:

```python
resultado = list(map(lambda x: x * 2, numeros))
```

Resultado:

```text
[2, 4, 6, 8]
```

---

# 44. `filter()`

`filter()` selecciona elementos según una función que devuelva un valor verdadero o falso.

Ejemplo:

```python
numeros = [1, 2, 3, 4, 5]

pares = list(
    filter(lambda x: x % 2 == 0, numeros)
)
```

Resultado:

```text
[2, 4]
```

---

# 45. `reduce()`

`reduce()` aplica una función acumulativamente.

Se encuentra en:

```python
functools
```

Ejemplo:

```python
from functools import reduce

numeros = [1, 2, 3, 4]

resultado = reduce(
    lambda acumulado, x: acumulado + x,
    numeros
)
```

Resultado:

```text
10
```

Conceptualmente:

```text
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
```

---

# 46. `map()` VS `filter()` VS `reduce()`

| Función | Propósito |
|---|---|
| `map()` | Transformar elementos |
| `filter()` | Seleccionar elementos |
| `reduce()` | Acumular valores |

### Regla rápida

```text
map
 ↓
transforma

filter
 ↓
filtra

reduce
 ↓
acumula
```

# 47. `map()` Y LIST COMPREHENSION

Muchas operaciones con `map()` pueden expresarse con una comprensión.

Con `map()`:

```python
resultado = list(map(lambda x: x * 2, numeros))
```

Con comprensión:

```python
resultado = [x * 2 for x in numeros]
```

Ambas producen el mismo resultado.

---

# 48. `filter()` Y LIST COMPREHENSION

Con `filter()`:

```python
pares = list(filter(lambda x: x % 2 == 0, numeros))
```

Con comprensión:

```python
pares = [x for x in numeros if x % 2 == 0]
```

# 49. RECURSIVIDAD

Una función es recursiva cuando se llama a sí misma.

Ejemplo clásico: factorial.

```python
def factorial(n):
    if n <= 1:
        return 1

    return n * factorial(n - 1)
```

Por ejemplo:

```python
factorial(4)
```

conceptualmente:

```text
4 × factorial(3)
4 × 3 × factorial(2)
4 × 3 × 2 × factorial(1)
4 × 3 × 2 × 1
= 24
```

---

# 50. CASO BASE

Toda recursión correcta debe tener algún mecanismo que permita terminar.

En:

```python
if n <= 1:
    return 1
```

tenemos el:

```text
caso base
```

Sin un caso base adecuado podemos acabar en una recursión infinita.

# 51. DOCSTRINGS

```python
def sumar(a, b):
    """Devuelve la suma de dos números."""

```

Esta cadena es un:

```text
docstring
```

Podemos consultar:

```python
print(sumar.__doc__)
```

# 52. ANOTACIONES DE TIPO

Python permite añadir anotaciones:

```python
def sumar(a: int, b: int) -> int:
    return a + b
```

Esto indica la intención de que:

```text
a → int
b → int
resultado → int
```

Las anotaciones **no convierten automáticamente** los valores ni imponen por sí mismas una comprobación de tipos en tiempo de ejecución.
