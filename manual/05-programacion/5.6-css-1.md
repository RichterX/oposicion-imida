---

# 1. INTRODUCCIÓN

**CSS** significa:

```text
Cascading Style Sheets
```

En español:

```text
Hojas de Estilo en Cascada
```

CSS es el lenguaje utilizado para definir la presentación de documentos estructurados, especialmente documentos HTML.

Permite controlar:

```text
colores
tipografías
espaciado
tamaños
posicionamiento
distribución
bordes
fondos
animaciones
diseño responsive
```

---

# 2. HTML VS CSS

Podemos recordar:

```text
HTML
→ estructura y significado

CSS
→ presentación

JavaScript
→ comportamiento
```

Ejemplo:

```html
<button class="boton">
    Guardar
</button>
```

HTML define:

```text
existe un botón
```

CSS puede definir:

```css
.boton {
    background: blue;
    color: white;
    padding: 10px;
}
```

---

# 3. CSS NO ES UN LENGUAJE DE PROGRAMACIÓN

CSS es un:

```text
lenguaje de hojas de estilo
```

No debemos confundirlo con:

```text
JavaScript
```

que sí es un lenguaje de programación.

---

# 4. FORMAS DE INCLUIR CSS

Existen tres formas principales.

```text
Inline
Internal
External
```

---

# 5. CSS INLINE

Se escribe directamente en el atributo:

```html
style
```

Ejemplo:

```html
<p style="color: red;">
    Texto
</p>
```

Ventaja:

```text
rápido para casos puntuales
```

Desventajas:

```text
poca reutilización
mezcla estructura y presentación
mantenimiento difícil
```

---

# 6. CSS INTERNO

Puede incluirse dentro de:

```html
<style>
```

normalmente en `<head>`.

Ejemplo:

```html
<style>
    p {
        color: red;
    }
</style>
```

---

# 7. CSS EXTERNO

Se coloca en un archivo `.css`.

Ejemplo:

```css
p {
    color: red;
}
```

Y se enlaza desde HTML:

```html
<link
    rel="stylesheet"
    href="estilos.css">
```

Esta suele ser la opción preferida para hojas de estilo reutilizables.

---

# 8. SINTAXIS CSS

La estructura básica:

```css
selector {
    propiedad: valor;
}
```

Ejemplo:

```css
p {
    color: red;
    font-size: 16px;
}
```

Tenemos:

```text
selector
propiedad
valor
declaración
```

---

# 9. REGLA CSS

Una regla CSS completa está formada conceptualmente por:

```text
selector
+
bloque de declaraciones
```

Ejemplo:

```css
h1 {
    color: blue;
    margin-bottom: 20px;
}
```

---

# 10. COMENTARIOS

Los comentarios CSS se escriben:

```css
/* Esto es un comentario */
```

---

# 11. SELECTOR UNIVERSAL

El selector:

```css
*
```

selecciona todos los elementos.

Ejemplo:

```css
* {
    box-sizing: border-box;
}
```

Es frecuente utilizarlo para establecer reglas globales.

---

# 12. SELECTOR DE ELEMENTO

Selecciona elementos por su nombre:

```css
p {
    color: black;
}
```

Afecta a todos los:

```html
<p>
```

---

# 13. SELECTOR DE CLASE

Se utiliza:

```text
.
```

Ejemplo:

```css
.boton {
    padding: 10px;
}
```

Selecciona:

```html
<button class="boton">
```

---

# 14. SELECTOR DE ID

Se utiliza:

```text
#
```

Ejemplo:

```css
#menu {
    width: 300px;
}
```

Selecciona:

```html
<div id="menu">
```

---

# 15. SELECTORES DE ATRIBUTO

Podemos seleccionar elementos según sus atributos.

Ejemplo:

```css
input[type="email"] {
    border: 1px solid;
}
```

Otros operadores:

```text
[atributo]
[atributo="valor"]
[atributo~="valor"]
[atributo|="valor"]
[atributo^="valor"]
[atributo$="valor"]
[atributo*="valor"]
```

---

# 16. OPERADORES DE ATRIBUTOS

### `[attr]`

El atributo existe.

```css
input[required] {
    ...
}
```

---

### `[attr="value"]`

El valor coincide exactamente.

```css
input[type="email"] {
    ...
}
```

---

### `[attr^="value"]`

El valor comienza por:

```text
value
```

---

### `[attr$="value"]`

El valor termina en:

```text
value
```

---

### `[attr*="value"]`

El valor contiene:

```text
value
```

---

# 17. SELECTOR DESCENDIENTE

El espacio representa un descendiente.

```css
nav a {
    color: blue;
}
```

Selecciona los enlaces que están dentro de:

```text
nav
```

a cualquier nivel de profundidad.

---

# 18. SELECTOR DE HIJO DIRECTO

El símbolo:

```text
>
```

selecciona hijos directos.

```css
nav > a {
    color: blue;
}
```

Selecciona:

```text
a
```

que sean hijos directos de:

```text
nav
```

---

# 19. HERMANO ADYACENTE

El operador:

```text
+
```

selecciona el hermano inmediatamente posterior.

Ejemplo:

```css
h2 + p {
    margin-top: 0;
}
```

Selecciona el:

```text
p
```

que aparece inmediatamente después de un `h2` y comparte el mismo padre.

---

# 20. HERMANOS POSTERIORES

El operador:

```text
~
```

selecciona hermanos posteriores que coincidan.

Ejemplo:

```css
h2 ~ p {
    color: gray;
}
```

Selecciona los `p` posteriores que comparten padre con `h2`.

---

# 21. SELECTORES AGRUPADOS

Podemos agrupar selectores mediante:

```text
,
```

Ejemplo:

```css
h1,
h2,
h3 {
    font-family: sans-serif;
}
```

Se aplica a todos ellos.

---

# 22. PSEUDOCLASES

Las pseudoclases representan estados o condiciones especiales.

Se escriben mediante:

```text
:
```

Ejemplos:

```css
:hover
:focus
:active
:visited
:checked
:disabled
:first-child
:last-child
:nth-child()
```

---

# 23. `:hover`

Se aplica cuando el puntero se encuentra sobre el elemento.

```css
button:hover {
    background: black;
}
```

---

# 24. `:focus`

Se aplica cuando el elemento tiene el foco.

```css
input:focus {
    outline: 2px solid blue;
}
```

Es especialmente importante para accesibilidad y navegación mediante teclado.

---

# 25. `:active`

Representa el estado de activación del elemento durante una interacción.

```css
button:active {
    transform: scale(0.98);
}
```

---

# 26. `:visited`

Permite seleccionar enlaces que han sido visitados.

```css
a:visited {
    color: purple;
}
```

---

# 27. `:checked`

Selecciona controles seleccionados:

```css
input:checked {
    accent-color: green;
}
```

Puede utilizarse con:

```text
checkbox
radio
```

---

# 28. `:disabled`

Selecciona controles deshabilitados:

```css
button:disabled {
    opacity: 0.5;
}
```

---

# 29. `:first-child`

Selecciona un elemento si es el primer hijo de su padre.

```css
li:first-child {
    font-weight: bold;
}
```

---

# 30. `:last-child`

Selecciona un elemento si es el último hijo.

```css
li:last-child {
    font-weight: bold;
}
```

---

# 31. `:nth-child()`

Permite seleccionar elementos según su posición entre los hijos.

Ejemplo:

```css
li:nth-child(2) {
    color: red;
}
```

Selecciona el segundo hijo que sea `li` en el contexto del selector.

---

# 32. `:nth-of-type()`

Permite seleccionar según la posición del elemento entre sus hermanos del mismo tipo.

Ejemplo:

```css
p:nth-of-type(2) {
    color: blue;
}
```

### 🧠 Diferencia

```text
:nth-child()
→ posición entre todos los hijos

:nth-of-type()
→ posición entre elementos del mismo tipo
```

---

# 33. PSEUDOELEMENTOS

Los pseudoelementos representan partes conceptuales de un elemento.

Se escriben normalmente:

```text
::
```

Ejemplos:

```css
::before
::after
::first-letter
::first-line
::selection
```

---

# 34. `::before` Y `::after`

Permiten generar contenido conceptual antes o después del contenido del elemento.

Ejemplo:

```css
.aviso::before {
    content: "⚠ ";
}
```

Es importante recordar:

```text
::before
::after
```

no crean un nuevo elemento HTML independiente en el documento original.

---

# 35. `content`

La propiedad:

```css
content
```

se utiliza especialmente con:

```text
::before
::after
```

Ejemplo:

```css
.boton::after {
    content: " →";
}
```

---

# 36. ESPECIFICIDAD

La especificidad determina qué regla gana cuando varias reglas CSS pueden aplicarse al mismo elemento.

Podemos recordar una jerarquía simplificada:

```text
inline
  ↓
ID
  ↓
class / atributos / pseudoclases
  ↓
elementos / pseudoelementos
```

Pero la resolución real depende también de:

```text
origin
importance
layer
specificity
order
```

---

# 37. VALOR CONCEPTUAL DE ESPECIFICIDAD

Una forma didáctica de visualizarla:

```text
ID       → 1-0-0
clase    → 0-1-0
elemento → 0-0-1
```

Por ejemplo:

```css
#menu .item
```

tiene:

```text
1-1-0
```

Mientras:

```css
nav .item
```

tiene:

```text
0-1-1
```

Por tanto:

```text
#menu .item
```

tiene mayor especificidad.

---

# 38. ESPECIFICIDAD NO ES SIMPLEMENTE "CONTAR SELECTORES"

No debemos pensar:

```text
3 clases > 1 ID
```

porque no funciona así.

Por ejemplo:

```text
1 ID
```

supera en especificidad a:

```text
muchas clases
```

dentro del sistema tradicional de comparación por componentes.

---

# 39. CASCADA

CSS significa:

```text
Cascading Style Sheets
```

La cascada determina qué declaraciones terminan aplicándose cuando existen conflictos.

Intervienen factores como:

```text
origen
importancia
capas
especificidad
orden
```

---

# 40. ORDEN DE APARICIÓN

Si dos reglas tienen la misma relevancia y especificidad, una regla posterior puede ganar.

Ejemplo:

```css
p {
    color: red;
}

p {
    color: blue;
}
```

El resultado será:

```text
blue
```

porque la segunda regla aparece después.

---

# 41. `!important`

Puede marcar una declaración como importante:

```css
p {
    color: red !important;
}
```

`!important` altera la prioridad normal de la cascada.

Debe utilizarse con moderación.

No es una solución general para problemas de especificidad.

---

# 42. HERENCIA

Algunas propiedades CSS se heredan de los elementos padres.

Por ejemplo:

```css
body {
    color: #222;
}
```

El texto de muchos descendientes puede recibir ese color por herencia.

No todas las propiedades son heredables.

---

# 43. PROPIEDADES HEREDABLES

Entre las propiedades que habitualmente se heredan:

```text
color
font-family
font-size
line-height
```

No debemos asumir que:

```text
todas
```

las propiedades se heredan.

---

# 44. VALORES ESPECIALES DE PROPIEDADES

CSS dispone de valores como:

```text
inherit
initial
unset
revert
revert-layer
```

---

# 45. `inherit`

Fuerza a utilizar el valor heredado del elemento padre.

```css
color: inherit;
```

---

# 46. `initial`

Restablece la propiedad a su valor inicial definido por CSS.

```css
color: initial;
```

---

# 47. `unset`

Actúa conceptualmente como:

```text
inherit
```

si la propiedad es heredable, y como:

```text
initial
```

si no lo es.

---

# 48. `revert`

Permite revertir el valor hacia una regla anterior de la cascada/origen.

Es especialmente útil para volver a comportamientos proporcionados por estilos de usuario o navegador cuando corresponda.

---

# 49. UNIDADES ABSOLUTAS

Algunas unidades:

```text
px
cm
mm
Q
in
pt
pc
```

La más habitual en desarrollo web:

```text
px
```

---

# 50. UNIDADES RELATIVAS

Entre las unidades relativas:

```text
%
em
rem
vw
vh
vmin
vmax
```

---

# 51. `%`

Representa un porcentaje relativo al contexto correspondiente de la propiedad.

Ejemplo:

```css
width: 50%;
```

No debemos asumir que siempre se calcula respecto al ancho del padre.

La referencia depende de la propiedad.

---

# 52. `em`

`em` es una unidad relativa al tamaño de fuente del contexto correspondiente.

En muchas propiedades relacionadas con el tamaño de fuente:

```text
1em
```

representa el tamaño de fuente del elemento.

Puede acumularse mediante herencia.

---

# 53. `rem`

`rem` significa:

```text
root em
```

y se relaciona con el tamaño de fuente del elemento raíz:

```html
<html>
```

Por eso suele ser más predecible que `em` para escalas globales.

---

# 54. `vw`

Representa un porcentaje del ancho del viewport.

```text
1vw = 1% del ancho del viewport
```

---

# 55. `vh`

Representa un porcentaje de la altura del viewport.

```text
1vh = 1% de la altura del viewport
```

En CSS moderno existen además unidades de viewport pequeñas, grandes y dinámicas, como:

```text
svh
lvh
dvh
```

que ayudan a gestionar mejor los cambios de las interfaces móviles.

---

# 56. COLORES

CSS permite definir colores mediante diferentes formatos.

Ejemplos:

```css
color: red;
```

```css
color: #ff0000;
```

```css
color: rgb(255, 0, 0);
```

```css
color: rgba(255, 0, 0, 0.5);
```

```css
color: hsl(0, 100%, 50%);
```

---

# 57. HEXADECIMAL

Formato:

```text
#RRGGBB
```

Ejemplo:

```text
#ff0000
```

representa rojo.

También puede utilizarse la forma abreviada:

```text
#f00
```

cuando los pares pueden abreviarse.

---

# 58. RGB / RGBA

Ejemplo:

```css
rgb(255, 0, 0)
```

representa rojo.

En sintaxis moderna también pueden utilizarse componentes de transparencia mediante:

```css
rgb(255 0 0 / 50%)
```

La sintaxis histórica `rgba()` también es ampliamente reconocida.

---

# 59. HSL

HSL significa:

```text
Hue
Saturation
Lightness
```

Ejemplo:

```css
hsl(0, 100%, 50%)
```

representa un rojo puro en este modelo.

---

# 60. OPACIDAD

La propiedad:

```css
opacity
```

controla la opacidad de un elemento.

Ejemplo:

```css
opacity: 0.5;
```

Un valor de:

```text
0
```

es completamente transparente.

Un valor de:

```text
1
```

es completamente opaco.

---

# 61. BOX MODEL

Uno de los conceptos más importantes de CSS:

```text
Box Model
```

Cada elemento puede representarse conceptualmente como:

```text
┌──────────────────────────────┐
│            margin            │
│  ┌────────────────────────┐  │
│  │         border         │  │
│  │  ┌──────────────────┐  │  │
│  │  │     padding      │  │  │
│  │  │  ┌────────────┐  │  │  │
│  │  │  │  content   │  │  │  │
│  │  │  └────────────┘  │  │  │
│  │  └──────────────────┘  │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

Orden:

```text
content
padding
border
margin
```

---

# 62. CONTENT

Es la zona donde se encuentra el contenido del elemento.

Por ejemplo:

```text
texto
imagen
hijos
```

según el elemento y su modelo de formato.

---

# 63. PADDING

El padding es el espacio interior entre:

```text
contenido
```

y:

```text
borde
```

Ejemplo:

```css
padding: 20px;
```

---

# 64. BORDER

El borde rodea:

```text
content + padding
```

Ejemplo:

```css
border: 1px solid black;
```

---

# 65. MARGIN

El margin representa espacio exterior alrededor de la caja.

Ejemplo:

```css
margin: 20px;
```

No forma parte del área de contenido de la caja.

---

# 66. `box-sizing`

La propiedad:

```css
box-sizing
```

determina cómo se calcula el tamaño declarado de determinados elementos.

Valores importantes:

```text
content-box
border-box
```

---

# 67. `content-box`

Es el comportamiento tradicional por defecto para muchos elementos.

Si tenemos:

```css
width: 200px;
padding: 20px;
border: 5px solid;
```

con:

```css
box-sizing: content-box;
```

el ancho total horizontal será:

```text
200
+ 20 + 20
+ 5 + 5
= 250px
```

sin considerar márgenes.

---

# 68. `border-box`

Con:

```css
box-sizing: border-box;
```

el:

```text
width
```

incluye:

```text
content
+
padding
+
border
```

Por tanto, en el ejemplo anterior:

```text
ancho total = 200px
```

El área disponible para contenido se reduce para acomodar padding y borde.

---

# 69. `box-sizing` GLOBAL

Es frecuente encontrar:

```css
*,
*::before,
*::after {
    box-sizing: border-box;
}
```

Esto hace más intuitivo el cálculo de tamaños en muchos diseños.

---

# 70. WIDTH Y HEIGHT

Podemos establecer:

```css
width: 300px;
height: 200px;
```

Pero su interpretación depende del:

```text
box-sizing
```

y del modelo de layout.

---

# 71. `min-width` / `max-width`

Permiten establecer límites:

```css
min-width
max-width
```

Ejemplo:

```css
.container {
    width: 100%;
    max-width: 1200px;
}
```

Esto permite un diseño flexible con un límite máximo.

---

# 72. `min-height` / `max-height`

Funcionan de forma equivalente para la altura:

```css
min-height
max-height
```

---

# 73. MARGIN COLAPSING

En determinados contextos, los márgenes verticales de elementos de flujo normal pueden colapsar.

Ejemplo conceptual:

```text
margin-bottom de A
        +
margin-top de B
```

no siempre se suman simplemente.

Este comportamiento es una fuente habitual de confusión.

---

# 74. `display`

La propiedad:

```css
display
```

determina cómo participa un elemento en el modelo de formato/layout.

Valores fundamentales:

```text
block
inline
inline-block
none
flex
grid
```

---

# 75. `display: block`

Un elemento de tipo block:

```css
display: block;
```

participa como una caja de bloque.

Normalmente comienza en una nueva línea dentro del flujo.

Ejemplos habituales por defecto:

```text
div
p
section
```

---

# 76. `display: inline`

Un elemento inline participa dentro del flujo de texto.

Ejemplos habituales:

```text
span
a
strong
```

Por defecto, sus dimensiones de `width` y `height` no se comportan como las de una caja de bloque tradicional.

---

# 77. `display: inline-block`

Combina características:

```text
inline
+
control de dimensiones de caja
```

Puede aparecer junto a otros elementos en línea, pero permite definir:

```text
width
height
padding
border
```

de forma más similar a una caja de bloque.

---

# 78. `display: none`

Un elemento con:

```css
display: none;
```

no participa en el layout.

No ocupa espacio como una caja renderizada normal.

---

# 79. `visibility`

La propiedad:

```css
visibility
```

puede ocultar visualmente un elemento sin retirarlo del layout de la misma forma que `display: none`.

Ejemplo:

```css
visibility: hidden;
```

### 🧠 Diferencia

```text
display: none
→ no participa en el layout

visibility: hidden
→ permanece en el layout, pero no es visible
```

---

# 80. OVERFLOW

La propiedad:

```css
overflow
```

controla qué ocurre cuando el contenido desborda la caja.

Valores conocidos:

```text
visible
hidden
scroll
auto
```

Ejemplo:

```css
.container {
    overflow: auto;
}
```

---

# 81. `overflow-x` Y `overflow-y`

Permiten controlar horizontal y vertical por separado.

```css
overflow-x: auto;
overflow-y: hidden;
```

---

# 82. OPACIDAD VS VISIBILIDAD

No son lo mismo:

```text
opacity: 0
```

hace el elemento completamente transparente, pero puede seguir participando en interacción y layout.

Mientras:

```text
visibility: hidden
```

lo hace invisible y, en condiciones normales, no es interactuable.

---

# 83. VARIABLES CSS

CSS permite definir propiedades personalizadas.

Ejemplo:

```css
:root {
    --color-principal: #3366ff;
    --espaciado: 16px;
}
```

Y utilizarlas:

```css
.boton {
    color: var(--color-principal);
    padding: var(--espaciado);
}
```

---

# 84. VENTAJA DE LAS VARIABLES

Permiten centralizar valores reutilizables:

```text
colores
espaciados
tamaños
tipografías
```

Esto facilita mantener sistemas de diseño consistentes.

---

# 85. `calc()`

Permite realizar cálculos en valores CSS.

Ejemplo:

```css
width: calc(100% - 40px);
```

Es útil para combinar:

```text
porcentajes
unidades absolutas
unidades relativas
```

---

# 86. FUNCIONES CSS

CSS dispone de numerosas funciones.

Ejemplos:

```text
calc()
min()
max()
clamp()
var()
```

---

# 87. `clamp()`

Permite definir:

```text
mínimo
valor preferido
máximo
```

Ejemplo:

```css
font-size: clamp(
    1rem,
    2vw,
    2rem
);
```

Esto resulta especialmente útil para diseños fluidos y responsive.

# 88. `min()` Y `max()`

Permiten seleccionar el menor o mayor valor entre expresiones.

Ejemplo:

```css
width: min(90%, 1200px);
```

Puede interpretarse conceptualmente como:

```text
utiliza el valor menor entre:
90%
y
1200px
```
