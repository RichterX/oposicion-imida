# 2. LISTAS

Una lista es una colección **ordenada y mutable** de elementos.

Se representa mediante corchetes:

```python
numeros = [1, 2, 3, 4]
```

También puede contener diferentes tipos:

```python
datos = [10, "Python", True, 3.14]
```

---

# 3. CARACTERÍSTICAS DE LAS LISTAS

Una lista es:

```text
Ordenada
Mutable
Indexable
Permite elementos duplicados
```

Ejemplo:

```python
frutas = ["manzana", "pera", "manzana"]
```

Los duplicados están permitidos.

---

# 4. CREAR UNA LISTA

Lista vacía:

```python
lista = []
```

También podemos utilizar:

```python
lista = list()
```

Lista con elementos:

```python
numeros = [10, 20, 30]
```

---

# 5. INDEXACIÓN

Los elementos de una lista se pueden acceder mediante índices.

```python
frutas = ["manzana", "pera", "plátano"]
```

Los índices comienzan en:

```text
0
```

Por tanto:

```text
0 → manzana
1 → pera
2 → plátano
```

Podemos hacer:

```python
print(frutas[0])
```

Resultado:

```text
manzana
```

---

# 6. ÍNDICES NEGATIVOS

Python permite utilizar índices negativos.

```text
-1 → último elemento
-2 → penúltimo
-3 → antepenúltimo
```

Ejemplo:

```python
frutas = ["manzana", "pera", "plátano"]

print(frutas[-1])
```

Resultado:

```text
plátano
```

---

# 7. MODIFICAR ELEMENTOS

Las listas son mutables.

Podemos modificar un elemento:

```python
frutas = ["manzana", "pera", "plátano"]

frutas[1] = "naranja"
```

Ahora:

```text
["manzana", "naranja", "plátano"]
```

---

# 8. `len()`

La función:

```python
len()
```

```python
frutas = ["manzana", "pera", "plátano"]

print(len(frutas))
```

Resultado:

```text
3
```

# 9. `append()`

Añade un elemento al final de una lista.

```python
frutas = ["manzana", "pera"]

frutas.append("plátano")
```

Resultado:

```text
["manzana", "pera", "plátano"]
```

# 10. `insert()`

Permite insertar un elemento en una posición concreta.

```python
frutas = ["manzana", "plátano"]

frutas.insert(1, "pera")
```

Resultado:

```text
["manzana", "pera", "plátano"]
```

La sintaxis:

```python
lista.insert(indice, elemento)
```

---

# 11. `extend()`

Añade los elementos de otro iterable.

```python
frutas = ["manzana", "pera"]

frutas.extend(["plátano", "naranja"])
```

Resultado:

```text
["manzana", "pera", "plátano", "naranja"]
```

---

# 12. `append()` VS `extend()`

Esta diferencia es muy importante.

```python
lista = [1, 2]

lista.append([3, 4])
```

Resultado:

```text
[1, 2, [3, 4]]
```

En cambio:

```python
lista = [1, 2]

lista.extend([3, 4])
```

Resultado:

```text
[1, 2, 3, 4]
```

### 🧠 Regla

```text
append()
→ añade UN elemento

extend()
→ añade los elementos de un iterable
```

---

# 13. `remove()`

Elimina la primera aparición de un valor.

```python
frutas = ["manzana", "pera", "manzana"]

frutas.remove("manzana")
```

Resultado:

```text
["pera", "manzana"]
```

⚠️ Si el elemento no existe, se produce:

```text
ValueError
```

---

# 14. `pop()`

Elimina y devuelve un elemento.

Sin argumento:

```python
frutas = ["manzana", "pera", "plátano"]

elemento = frutas.pop()
```

Se elimina el último elemento.

Ahora:

```text
frutas → ["manzana", "pera"]
elemento → "plátano"
```

También podemos indicar un índice:

```python
elemento = frutas.pop(0)
```

---

# 15. `remove()` VS `pop()`

| Método | Funcionamiento |
|---|---|
| `remove(valor)` | Elimina por valor |
| `pop(indice)` | Elimina por posición y devuelve el elemento |

### ⚠️ Trampa

```python
lista.remove(2)
```

busca el valor `2`.

Mientras:

```python
lista.pop(2)
```

intenta eliminar el elemento situado en el índice `2`.

# 19. `sort()`

```python
numeros = [4, 1, 3, 2]

```

Resultado:


# 20. `sort()` VS `sorted()`

Muy importante.

`sort()`:

```python
numeros.sort()
```

modifica la lista original.

`sorted()`:

```python
resultado = sorted(numeros)
```

crea y devuelve una nueva lista ordenada.

Ejemplo:

```python
numeros = [3, 1, 2]

resultado = sorted(numeros)
```

Ahora:

```text
numeros  → [3, 1, 2]
resultado → [1, 2, 3]
```

### 🧠 Regla

```text
sort()
→ modifica la lista

sorted()
→ devuelve una nueva lista ordenada
```

# 22. `copy()`

Permite crear una copia superficial de una lista.

```python
original = [1, 2, 3]

copia = original.copy()
```

Ahora:

```text
original → [1, 2, 3]
copia    → [1, 2, 3]
```

Son listas independientes en cuanto a la estructura exterior.

# 23. ASIGNACIÓN VS COPIA

Esto es una fuente clásica de preguntas.

```python
a = [1, 2, 3]
b = a
```

No hemos creado una copia independiente.

Ambas variables hacen referencia al mismo objeto.

```python
b.append(4)
```

Ahora:

```text
a → [1, 2, 3, 4]
b → [1, 2, 3, 4]
```

---

# 24. COPIA CON `copy()`

```python
a = [1, 2, 3]
b = a.copy()

b.append(4)
```

Ahora:

```text
a → [1, 2, 3]
b → [1, 2, 3, 4]
```

# 25. SLICING

El slicing permite obtener una parte de una secuencia.

Sintaxis:

```python
secuencia[inicio:fin:paso]
```

El límite `fin` es exclusivo.

Ejemplo:

```python
numeros = [0, 1, 2, 3, 4]

print(numeros[1:4])
```

Resultado:

```text
[1, 2, 3]
```

---

```python
numeros[:3]
```

Resultado:

```text

```

---

# 27. SLICING SIN FIN

```python
numeros[2:]
```

Resultado:

```text
[2, 3, 4]
```

---

# 28. SLICING CON PASO

```python
numeros = [0, 1, 2, 3, 4, 5]

numeros[::2]
```

Resultado:

```text
[0, 2, 4]
```

# 29. INVERTIR UNA LISTA CON SLICING

# 30. TUPLAS

Una tupla es una colección:

```text
Ordenada
Inmutable
Indexable
```

Se suele representar mediante paréntesis:

```python
colores = ("rojo", "verde", "azul")
```

---

# 31. INMUTABILIDAD DE LAS TUPLAS

Una vez creada una tupla, no podemos modificar sus elementos.

```python
colores = ("rojo", "verde", "azul")

colores[0] = "amarillo"
```

Esto produce:

```text
TypeError
```

---

# 32. TUPLA DE UN SOLO ELEMENTO

Aquí hay una trampa clásica.

Esto:

```python
valor = (10)
```

no crea una tupla.

Es simplemente:

```text
int
```

Para crear una tupla de un solo elemento necesitamos una coma:

```python
valor = (10,)
```

Ahora sí es una:

```text
tuple
```

---

# 33. CREAR TUPLAS SIN PARÉNTESIS

Los paréntesis no son estrictamente necesarios en muchos casos.

```python
coordenadas = 10, 20
```

crea:

```text
(10, 20)
```

Esto se denomina **tuple packing**.

---

# 34. DESEMPAQUETADO DE TUPLAS

Podemos hacer:

```python
coordenadas = (10, 20)

x, y = coordenadas
```

Ahora:

```text
x = 10
y = 20
```

---

# 35. DESEMPAQUETADO CON `*`

Python permite capturar varios elementos:

```python
numeros = (1, 2, 3, 4, 5)

primero, *resto = numeros
```

Resultado:

```text
primero → 1
resto   → [2, 3, 4, 5]
```

Observa que `resto` es una **lista**.

---

# 36. MÉTODOS DE LAS TUPLAS

```text

```

Ejemplo:



# 37. LISTA VS TUPLA

| Indexable | Sí | Sí |

# 69. MUTABILIDAD

Este concepto será importantísimo en Python.

Un objeto **mutable** puede cambiar después de ser creado.

Ejemplos:

```text
list
set
dict
```

Un objeto **inmutable** no puede modificarse después de crearse.

Ejemplos:

```text
int
float
bool
str
tuple
```

---

# 70. EJEMPLO DE MUTABILIDAD

Una lista:

```python
lista = [1, 2, 3]

lista[0] = 100
```

es válida.

Resultado:

```text
[100, 2, 3]
```

Una cadena:

```python
texto = "Hola"

texto[0] = "J"
```

produce:

```text
TypeError
```

Las cadenas son inmutables.

# 71. COPIA SUPERFICIAL

Una copia superficial copia la estructura exterior, pero no necesariamente todos los objetos internos.

Ejemplo:

```python
original = [[1, 2], [3, 4]]

copia = original.copy()
```

La lista exterior es diferente, pero las listas interiores siguen siendo referencias a los mismos objetos.

Por eso:

```python
copia[0].append(99)
```

puede afectar también a:

```python
original
```

Resultado conceptual:

```text
original → [[1, 2, 99], [3, 4]]
copia    → [[1, 2, 99], [3, 4]]
```

---

# 72. `copy.deepcopy()`

Para realizar una copia profunda podemos utilizar:

```python
import copy

copia = copy.deepcopy(original)
```

Esto copia también las estructuras anidadas.

Es un concepto que debemos reconocer aunque lo estudiaremos con más profundidad posteriormente.
