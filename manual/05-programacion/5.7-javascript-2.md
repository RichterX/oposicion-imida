# 2. OBJETOS

Un objeto permite almacenar información mediante pares:

```text
clave → valor
```

Ejemplo:

```javascript
const usuario = {
    nombre: "Pedro",
    edad: 30,
    activo: true
};
```

Tenemos:

```text
nombre → "Pedro"
edad   → 30
activo → true
```

---

# 3. ACCEDER A PROPIEDADES

Podemos utilizar:

```javascript
usuario.nombre
```

o:

```javascript
usuario["nombre"]
```

Ambas expresiones acceden a:

```text
nombre
```

---

# 4. DOT NOTATION

La notación mediante punto:

```javascript
usuario.nombre
```

es cómoda cuando conocemos el nombre de la propiedad de forma estática.

---

# 5. BRACKET NOTATION

La notación mediante corchetes:

```javascript
usuario["nombre"]
```

es especialmente útil cuando el nombre de la propiedad está almacenado en una variable.

Ejemplo:

```javascript
const propiedad = "nombre";

console.log(
    usuario[propiedad]
);
```

---

# 6. AÑADIR PROPIEDADES

Podemos añadir propiedades:

```javascript
usuario.email =
    "pedro@example.com";
```

---

# 7. MODIFICAR PROPIEDADES

```javascript
usuario.edad = 31;
```

---

# 8. ELIMINAR PROPIEDADES

Utilizamos:

```javascript
delete
```

Ejemplo:

```javascript
delete usuario.activo;
```

---

# 9. MÉTODOS DE OBJETOS

Un objeto puede contener funciones.

```javascript
const usuario = {

    nombre: "Pedro",

    saludar() {
        return "Hola";
    }
};
```

La función:

```text
saludar
```

es un método del objeto.

---

# 10. `this`

Dentro de un método tradicional de un objeto podemos utilizar:

```javascript
this
```

para referirnos al objeto asociado a la llamada.

Ejemplo:

```javascript
const usuario = {

    nombre: "Pedro",

    saludar() {
        return `Hola ${this.nombre}`;
    }
};
```

Al ejecutar:

```javascript
usuario.saludar();
```

`this` hace referencia al objeto utilizado en esa llamada, en este contexto.

---

# 11. `this` DEPENDE DE LA LLAMADA

En funciones tradicionales, el valor de:

```text
this
```

depende de cómo se invoque la función y de las reglas del modo de ejecución.

Ejemplo:

```javascript
const usuario = {
    nombre: "Pedro",

    saludar() {
        console.log(this.nombre);
    }
};

usuario.saludar();
```

---

# 12. ARROW FUNCTIONS Y `this`

Una arrow function:

```javascript
const saludar = () => {
    ...
};
```

no crea su propio `this`.

Utiliza el `this` léxico del contexto exterior.

### 🧠 Trampa

No debemos sustituir automáticamente:

```text
function
```

por:

```text
() =>
```

en métodos que necesiten su propio `this` dinámico.

# 13. PROPIEDADES COMPUTADAS

Podemos crear propiedades utilizando una expresión entre:

```text
[]
```

Ejemplo:

```javascript
const nombrePropiedad = "nombre";

const usuario = {
    [nombrePropiedad]:
        "Pedro"

```

El resultado contiene:

```text

```

# 14. DESTRUCTURING DE OBJETOS

Permite extraer propiedades:

```javascript
const usuario = {
    nombre: "Pedro",
    edad: 30

    nombre,
```


# 15. RENOMBRAR DURANTE DESTRUCTURING

Podemos utilizar:

```javascript

    nombre: nombreUsuario

```

La propiedad:

```text
nombre
```

se almacena en:

```text
nombreUsuario
```

---

# 16. VALORES POR DEFECTO EN DESTRUCTURING

Ejemplo:

```javascript

    ciudad = "Murcia"
} = usuario;
```

Si la propiedad `ciudad` es `undefined`, se utilizará:

```text
"Murcia"
```

---

# 17. DESTRUCTURING ANIDADO

Ejemplo:

```javascript
const usuario = {
    nombre: "Pedro",
    direccion: {
        ciudad: "Murcia"
    }
};

const {
    direccion: {
        ciudad
    }
} = usuario;
```

Obtenemos:

```text
ciudad
```

---

# 18. REST EN DESTRUCTURING

Podemos recoger las propiedades restantes:

```javascript
const usuario = {
    nombre: "Pedro",
    edad: 30,
    activo: true
};

const {
    nombre,
    ...resto
} = usuario;
```

`resto` contendrá las demás propiedades.

# 19. SPREAD DE OBJETOS

Podemos copiar propiedades enumerables propias:

```javascript
const usuario = {
    nombre: "Pedro",
    edad: 30
};

const copia = {
    ...usuario
};
```

---

# 20. SPREAD NO ES COPIA PROFUNDA

Esto es muy importante.

```javascript
const original = {
    direccion: {
        ciudad: "Murcia"
    }
};

const copia = {
    ...original
};
```

La propiedad:

```text
direccion
```

sigue haciendo referencia al mismo objeto interno.

Por tanto:

```text
spread de objetos
→ copia superficial
```

---

# 21. COMBINAR OBJETOS

Podemos combinar objetos:

```javascript
const datosBase = {
    nombre: "Pedro"
};

const datosExtra = {
    edad: 30
};

const usuario = {
    ...datosBase,
    ...datosExtra
};
```

Resultado:

```javascript
{
    nombre: "Pedro",
    edad: 30
}
```

---

# 22. PROPIEDADES REPETIDAS CON SPREAD

Si existen propiedades repetidas:

```javascript
const a = {
    nombre: "Pedro"
};

const b = {
    nombre: "Juan"
};

const usuario = {
    ...a,
    ...b
};
```

La propiedad posterior:

```text
b.nombre
```

sobrescribe la anterior.

Resultado:

```text
nombre: "Juan"
```

# 35. `find()`

Devuelve el primer elemento que cumple una condición.

Ejemplo:

```javascript
const usuarios = [

    { id: 2, nombre: "Luis" },
```

```javascript
{
```

```text
undefined
```

Devuelve el índice del primer elemento que cumple la condición.

```text

```

Si no encuentra ninguno:

# 37. `some()`

Comprueba si **al menos un elemento** cumple la condición.

```javascript

    1, 3, 5, 8

numeros.some(

);
```

Resultado:

```text
true
```

# 38. `every()`

Comprueba si **todos los elementos** cumplen la condición.

```javascript
numeros.every(
```



# 39. `map()`

Crea un nuevo array transformando cada elemento.

Ejemplo:

```javascript
const numeros = [
    1, 2, 3

const dobles =
    numeros.map(
        n => n * 2
```

```text
[2, 4, 6]
```

El array original no se modifica por el propio `map()`.

# 40. `filter()`

Crea un nuevo array con los elementos que cumplen una condición.

```javascript
const numeros = [
    1, 2, 3, 4

const pares =
    numeros.filter(
        n => n % 2 === 0
```


# 41. `reduce()`

Reduce los elementos a un único resultado según la función proporcionada.

Ejemplo:

```javascript
const numeros = [
    1, 2, 3, 4
];

const suma =
    numeros.reduce(
        (total, numero) =>
            total + numero,
        0
    );
```

Resultado:

```text
10
```

# 42. `reduce()` Y ACUMULADOR

En:

```javascript
reduce(
    (total, numero) =>
        total + numero,
    0
)
```

tenemos:

```text

→ acumulador

numero
→ elemento actual

0
→ valor inicial del acumulador
```

# 43. `sort()`

Ordena los elementos del array.

### ⚠️ Trampa importante

Por defecto:

```javascript
[10, 2, 30].sort()
```

no realiza necesariamente una ordenación numérica.

El orden por defecto se basa en la conversión a strings y comparación según el orden lexicográfico.

Para ordenar números:

```javascript
numeros.sort(
    (a, b) => a - b
);
```

Para orden descendente:

```javascript
numeros.sort(
    (a, b) => b - a
);
```

---

# 44. `sort()` MODIFICA EL ARRAY

A diferencia de:

```text
map
filter
slice
```

`sort()` modifica el array original.

Esto es importante.

---

# 45. `reverse()`

Invierte el orden de los elementos.

```javascript
numeros.reverse();
```

También modifica el array original.

# 47. `split()`

Es un método de `String`, no de Array.

Convierte una cadena en un array según un separador.

```javascript
const texto =
    "Ana,Luis,Pedro";

const nombres =
    texto.split(",");
```

Resultado:

```text
["Ana", "Luis", "Pedro"]
```

### 🧠 Pareja clásica

```text
array.join()
→ array → string

string.split()
→ string → array
```

# 52. `forEach()`

Ejemplo:

```javascript
numeros.forEach(
    numero => {
        console.log(numero);
    }
);
```

### 🧠 Trampa

```text

→ devuelve un nuevo array

forEach()
→ se utiliza para ejecutar una función por elemento y no está diseñado para producir ese nuevo array
```

# 72. MAP VS OBJECT

Un `Map` está diseñado específicamente como colección de pares clave/valor.

Ventajas y diferencias importantes:

```text
Map
→ API específica para colecciones
→ size
→ set/get/has/delete
→ claves de distintos tipos
```

Un objeto:

```text
Object
→ estructura de propiedades
→ prototipos y semántica de objeto
→ acceso mediante . o []
```

No significa que `Map` sea siempre mejor que `Object`.

Depende del problema.

# 80. JSON

JSON significa:

```text
JavaScript Object Notation
```

Es un formato de intercambio de datos basado en una sintaxis de texto.

Ejemplo:

```json
{
    "nombre": "Pedro",
    "edad": 30,
    "activo": true
}
```

---

# 81. JSON VS OBJECT

Un objeto JavaScript:

```javascript
const usuario = {
    nombre: "Pedro"
};
```

no es exactamente lo mismo que una cadena JSON:

```javascript
const json =
    '{"nombre":"Pedro"}';
```

El primero es:

```text
objeto JavaScript
```

El segundo:

```text
string
```

que contiene JSON.

---

# 82. `JSON.stringify()`

Convierte un valor JavaScript en una cadena JSON cuando el valor es serializable.

Ejemplo:

```javascript
const usuario = {
    nombre: "Pedro",
    edad: 30
};

const json =
    JSON.stringify(usuario);
```

Resultado:

```text
'{"nombre":"Pedro","edad":30}'
```

---

# 83. `JSON.parse()`

Convierte una cadena JSON válida en un valor JavaScript.

Ejemplo:

```javascript
const json =
    '{"nombre":"Pedro"}';

const usuario =
    JSON.parse(json);
```

Ahora:

```text
usuario
```

es un objeto JavaScript.

---

# 84. CICLO JSON

Podemos recordarlo así:

```text
Objeto JS
    │
    │ stringify()
    ↓
JSON string
    │
    │ parse()
    ↓
Objeto JS
```

---

# 85. JSON: TIPOS PERMITIDOS

JSON admite:

```text
object
array
string
number
boolean
null
```

No admite directamente conceptos JavaScript como:

```text
undefined
function
```

# 86. PROPIEDADES JSON

Los nombres de propiedades de un objeto JSON deben aparecer entre:

```text
comillas dobles
```

Correcto:

```json
{
    "nombre": "Pedro"
}
```

No:

```text
{
    nombre: "Pedro"
}
```

Eso sería sintaxis de objeto JavaScript, no JSON válido.
