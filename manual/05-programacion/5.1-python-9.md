# 2. ITERABLES

Un objeto es **iterable** cuando podemos recorrer sus elementos.

Ejemplos:

```python
lista = [1, 2, 3]
tupla = (1, 2, 3)
cadena = "Hola"
```

Todos ellos pueden utilizarse con:

```python

```

Por ejemplo:

```python

    print(numero)
```

# 3. ITERABLE VS ITERADOR

No debemos confundir:

```text
Iterable
```

con:

```text
Iterator
```

Un iterable es un objeto que puede proporcionar un iterador.

Un iterador mantiene el estado de la iteración y proporciona los elementos uno a uno.

Conceptualmente:

```text
ITERABLE
   ↓
iter()
   ↓
ITERADOR
   ↓
next()
   ↓
elemento
```

# 4. `iter()`

La función:

```python
iter()
```

obtiene un iterador a partir de un objeto iterable.

Ejemplo:

```python
numeros = [10, 20, 30]

iterador = iter(numeros)
```

Ahora:

```text
numeros
→ iterable

iterador
→ iterator
```

# 5. `next()`

La función:

```python
next()
```

obtiene el siguiente elemento de un iterador.

Ejemplo:

```python
numeros = [10, 20, 30]

iterador = iter(numeros)

print(next(iterador))
print(next(iterador))
print(next(iterador))
```

Resultado:

```text

20
30
```

# 6. `StopIteration`

Cuando no quedan elementos:

```python

```

produce:

```text
StopIteration
```

Por ejemplo:

```python

print(next(numeros))
print(next(numeros))
print(next(numeros))
```

La tercera llamada provoca:

```text
StopIteration
```

# 8. PROTOCOLO DE ITERACIÓN

Un iterador normalmente proporciona:

```python
__iter__()
__next__()
```

`__iter__()` devuelve el iterador.

`__next__()` devuelve el siguiente elemento.

Cuando no quedan elementos:

```python
__next__()
```

debe provocar:

```text
StopIteration
```

---

# 9. CREAR UN ITERADOR PERSONALIZADO

Podemos crear una clase que implemente el protocolo.

```python
class Contador:

    def __init__(self, limite):
        self.actual = 0
        self.limite = limite

    def __iter__(self):
        return self

    def __next__(self):
        if self.actual >= self.limite:
            raise StopIteration

        valor = self.actual
        self.actual += 1

        return valor
```

Podemos utilizar:

```python
contador = Contador(3)

for numero in contador:
    print(numero)
```

Resultado:

```text
0
1
2
```

---

# 10. `__iter__()` DEVUELVE EL ITERADOR

En un iterador típico:

```python
def __iter__(self):
    return self
```

Esto significa que el propio objeto actúa como iterador.

---

# 11. `__next__()`

`__next__()` define cómo obtener el siguiente elemento.

Ejemplo:

```python
def __next__(self):
    if self.actual >= self.limite:
        raise StopIteration

    valor = self.actual
    self.actual += 1

    return valor
```

# 12. GENERADORES

Los generadores ofrecen una forma mucho más sencilla de crear iteradores.

Se utiliza:

```python
yield
```

Ejemplo:

```python
def numeros():
    yield 1
    yield 2
    yield 3
```

La función es un:

```text
generator
```

---

# 13. `yield`

A diferencia de:

```python
return
```

`yield` produce un valor y **pausa la ejecución de la función generadora**.

Ejemplo:

```python
def numeros():
    yield 1
    yield 2
    yield 3
```

Cuando pedimos elementos:

```python
generador = numeros()

print(next(generador))
print(next(generador))
print(next(generador))
```

obtenemos:

```text
1
2
3
```

---

# 14. `yield` VS `return`

La diferencia fundamental:

```text
return
→ termina la función

yield
→ produce un valor y pausa el generador
```

Después de un `yield`, el generador puede continuar desde ese punto.

---

# 15. ESTADO DE UN GENERADOR

Ejemplo:

```python
def contar():
    print("A")
    yield 1

    print("B")
    yield 2

    print("C")
    yield 3
```

Cuando hacemos:

```python
generador = contar()
```

el cuerpo todavía no se ejecuta de la misma forma que una llamada normal.

Al hacer:

```python
next(generador)
```

se ejecuta hasta:

```python
yield 1
```

Después queda pausado.

El siguiente:

```python
next(generador)
```

continúa desde:

```python
print("B")
```

---

# 16. GENERADORES Y MEMORIA

Una ventaja importante de los generadores es que pueden producir elementos bajo demanda.

Una lista:

```python
numeros = [x for x in range(1000000)]
```

crea y almacena los elementos.

Un generador:

```python
numeros = (x for x in range(1000000))
```

los produce progresivamente.

Conceptualmente:

```text
Lista
→ almacena valores

Generador
→ produce valores cuando se necesitan
```

# 22. GENERADORES INFINITOS

Un generador puede producir valores indefinidamente.

Ejemplo:

```python
def contador():
    numero = 0

    while True:
        yield numero
        numero += 1
```

No debemos convertirlo directamente en:

```python
list(contador())
```

porque nunca terminaría.

Pero podemos consumirlo parcialmente:

```python
generador = contador()

print(next(generador))
print(next(generador))
print(next(generador))
```

# 26. DECORADORES

Un decorador permite modificar o ampliar el comportamiento de una función o clase sin modificar directamente su código original.

La sintaxis utiliza:

```python
@decorador
```

Ejemplo:

```python
def decorador(funcion):
    def envoltura():
        print("Antes")
        funcion()
        print("Después")

    return envoltura
```

---

# 27. APLICAR UN DECORADOR

Podemos escribir:

```python
@decorador
def saludar():
    print("Hola")
```

Esto equivale conceptualmente a:

```python
def saludar():
    print("Hola")

saludar = decorador(saludar)
```

### 🧠 Regla

```text
@decorador
```

es una forma cómoda de aplicar un decorador.

# 28. EJEMPLO COMPLETO

```python
def registrar(funcion):
```

# 30. DECORADORES CON ARGUMENTOS

Si la función decorada recibe argumentos, la envoltura puede utilizar:

```python
*args
**kwargs
```

Ejemplo:

```python
def registrar(funcion):

    def envoltura(*args, **kwargs):
        print("Antes")

        resultado = funcion(*args, **kwargs)

        print("Después")

        return resultado

    return envoltura
```

Ahora podemos decorar:

```python
@registrar
def sumar(a, b):
    return a + b
```

Y:

```python
resultado = sumar(10, 20)
```

# 31. PRESERVAR INFORMACIÓN CON `functools.wraps`

Cuando envolvemos una función, podemos perder ciertos metadatos como:

```text
__name__
__doc__
```

Python proporciona:

```python
from functools import wraps
```

Ejemplo:

```python
def registrar(funcion):

    @wraps(funcion)
    def envoltura(*args, **kwargs):
        print("Antes")
        return funcion(*args, **kwargs)

    return envoltura
```

Esto ayuda a conservar metadatos de la función original.

---

# 32. DECORADOR CON `wraps`

Ejemplo completo:

```python
from functools import wraps


def registrar(funcion):

    @wraps(funcion)
    def envoltura(*args, **kwargs):
        print("Ejecutando")
        return funcion(*args, **kwargs)

    return envoltura
```

Después:

```python
@registrar
def saludar(nombre):
    """Saluda a una persona."""

    print(f"Hola {nombre}")
```

Podemos consultar:

```python
saludar.__name__
```

y mantener:

```text
saludar
```

como nombre de la función original.

# 33. `functools`

# 34. `functools.partial`

`partial()` permite crear una nueva función con algunos argumentos ya fijados.

Ejemplo:

```python
from functools import partial


def multiplicar(a, b):
    return a * b


doblar = partial(multiplicar, 2)
```

Ahora:

```python
doblar(5)
```

equivale conceptualmente a:

```python
multiplicar(2, 5)
```

Resultado:

```text
10
```

---

# 35. `functools.reduce`

Recordemos:

```python
from functools import reduce
```

Permite acumular elementos.

Ejemplo:

```python
resultado = reduce(
    lambda a, b: a + b,
    [1, 2, 3, 4]
)
```

Resultado:

```text
10
```

---

# 36. `functools.lru_cache`

Permite almacenar resultados de llamadas para evitar recalcularlos.

Ejemplo:

```python
from functools import lru_cache


@lru_cache
def fibonacci(n):
    if n < 2:
        return n

    return fibonacci(n - 1) + fibonacci(n - 2)
```

La caché puede mejorar enormemente el rendimiento de determinadas funciones repetitivas.

---

# 37. `@lru_cache`

`lru_cache` es un decorador.

Por tanto:

```python
@lru_cache
def funcion(...):
    ...
```

modifica el comportamiento de la función para almacenar resultados.

# 38. CLOSURES

Un closure aparece cuando una función interna conserva acceso a variables de su función exterior incluso después de que la función exterior haya terminado.

Ejemplo:

```python
def crear_multiplicador(factor):

    def multiplicar(numero):
        return numero * factor

    return multiplicar
```

Podemos hacer:

```python
doblar = crear_multiplicador(2)
triple = crear_multiplicador(3)
```

Ahora:

```python
doblar(5)
```

produce:

```text
10
```

y:

```python
triple(5)
```

produce:

```text
15
```

---

# 39. CLOSURE Y `factor`

Aunque `crear_multiplicador()` ya haya terminado, la función interna conserva acceso a:

```text
factor
```

Esto es una característica fundamental de los closures.

---

# 40. `nonlocal` Y CLOSURES

Podemos modificar una variable enclosing mediante:

```python
nonlocal
```

Ejemplo:

```python
def contador():

    valor = 0

    def incrementar():
        nonlocal valor
        valor += 1
        return valor

    return incrementar
```

Ahora:

```python
c = contador()

print(c())
print(c())
print(c())
```

Resultado:

```text
1
2
3
```

La función interna conserva el estado.

# 41. DECORADORES Y CLOSURES

Muchos decoradores utilizan closures.

```python
def decorador(funcion):
```

La función:


# 42. DECORADORES ENCADENADOS

Podemos utilizar varios decoradores:

```python

```


# 43. EJEMPLO DE ORDEN

```python

    pass
```

equivale a:

```python
funcion = A(B(funcion))
```

Por tanto:

```text
B
↓
A
```

envuelven la función en ese orden de aplicación.
