# 1. INTRODUCCIÓN

En las partes anteriores hemos aprendido a:

```text
crear XML
entender su estructura
definir restricciones con DTD
definir esquemas con XSD
```

Ahora necesitamos aprender a **buscar y seleccionar información dentro de un documento XML**.

Aquí aparecen dos tecnologías especialmente importantes:

```text
XPath
XSLT
```

Podemos pensar:

```text
XPath
→ localizar/seleccionar información

XSLT
→ transformar XML en otro resultado
```

---

# 2. ¿QUÉ ES XPATH?

XPath significa:

```text
XML Path Language
```

Es un lenguaje utilizado para seleccionar y navegar por nodos de un documento XML.

Se utiliza, entre otros contextos, junto con:

```text
XSLT
XQuery
DOM
```

---

# 3. DOCUMENTO DE EJEMPLO

Utilizaremos este XML durante la explicación:

```xml
<empresa>

    <empleados>

        <empleado id="1">
            <nombre>Pedro</nombre>
            <puesto>Desarrollador</puesto>
            <salario>25000</salario>
        </empleado>

        <empleado id="2">
            <nombre>Ana</nombre>
            <puesto>Administradora</puesto>
            <salario>30000</salario>
        </empleado>

        <empleado id="3">
            <nombre>Luis</nombre>
            <puesto>Desarrollador</puesto>
            <salario>28000</salario>
        </empleado>

    </empleados>

</empresa>
```

Árbol:

```text
empresa
└── empleados
    ├── empleado
    │   ├── nombre
    │   ├── puesto
    │   └── salario
    │
    ├── empleado
    │   ├── nombre
    │   ├── puesto
    │   └── salario
    │
    └── empleado
        ├── nombre
        ├── puesto
        └── salario
```

---

# 4. NODOS XML

XPath trabaja con nodos.

Entre los tipos de nodos que podemos encontrar están:

```text
document
element
attribute
text
comment
processing instruction
```

---

# 5. NODO DOCUMENT

Representa el documento XML completo.

Conceptualmente:

```text
document
└── empresa
```

---

# 6. NODO ELEMENT

Representa un elemento:

```xml
<empleado>
```

o:

```xml
<nombre>
```

---

# 7. NODO ATTRIBUTE

Representa un atributo:

```xml
id="1"
```

---

# 8. NODO TEXT

Representa contenido textual.

Ejemplo:

```xml
<nombre>Pedro</nombre>
```

El texto:

```text
Pedro
```

es un nodo de texto.

---

# 9. RUTA ABSOLUTA

Una expresión XPath puede comenzar desde la raíz:

```text
/empresa
```

Esto selecciona:

```text
empresa
```

---

# 10. RUTA MÁS PROFUNDA

Podemos escribir:

```text
/empresa/empleados/empleado
```

Selecciona los elementos:

```text
empleado
```

que siguen esa ruta desde la raíz.

---

# 11. `/`

La barra:

```text
/
```

representa navegación entre niveles del árbol.

Ejemplo:

```text
/empresa/empleados
```

significa:

```text
raíz
→ empresa
→ empleados
```

---

# 12. `//`

El operador:

```text
//
```

permite seleccionar descendientes en cualquier profundidad.

Ejemplo:

```text
//empleado
```

selecciona elementos `empleado` independientemente de su profundidad bajo el contexto correspondiente.

---

# 13. DIFERENCIA `/` VS `//`

```text
/empresa/empleados/empleado
```

indica una ruta concreta.

Mientras:

```text
//empleado
```

busca descendientes `empleado` a cualquier profundidad.

### 🧠 Trampa

```text
/
→ hijo inmediato

//
→ descendiente
```

---

# 14. `.`

El punto:

```text
.
```

representa el nodo de contexto actual.

---

# 15. `..`

Los dos puntos:

```text
..
```

representan el nodo padre.

Conceptualmente:

```text
empleado
  ↑
 ..
```

---

# 16. `*`

El comodín:

```text
*
```

selecciona cualquier elemento que coincida con ese paso.

Ejemplo:

```text
/empresa/*
```

selecciona los elementos hijos de:

```text
empresa
```

---

# 17. COMODÍN DE ATRIBUTOS

También podemos utilizar:

```text
@*
```

para referirnos a atributos del contexto.

---

# 18. ATRIBUTOS CON `@`

Para seleccionar un atributo concreto:

```text
//empleado/@id
```

seleccionamos:

```text
id
```

de cada empleado.

---

# 19. TEXTO

Podemos utilizar:

```text
text()
```

Ejemplo:

```text
//nombre/text()
```

selecciona los nodos de texto de los elementos `nombre`.

---

# 20. `node()`

El test:

```text
node()
```

representa nodos en general.

Es más amplio que seleccionar únicamente elementos.

---

# 21. PREDICADOS

Los predicados permiten filtrar resultados.

Se escriben entre:

```text
[ ]
```

Ejemplo:

```text
/empresa/empleados/empleado[1]
```

---

# 22. PRIMER ELEMENTO

```text
/empresa/empleados/empleado[1]
```

selecciona el primer `empleado` de ese conjunto.

---

# 23. SEGUNDO ELEMENTO

```text
/empresa/empleados/empleado[2]
```

selecciona el segundo.

---

# 24. FILTRAR POR HIJO

Podemos escribir:

```text
//empleado[puesto="Desarrollador"]
```

Esto selecciona empleados cuyo elemento:

```text
puesto
```

tiene el valor:

```text
Desarrollador
```

---

# 25. FILTRAR POR ATRIBUTO

Ejemplo:

```text
//empleado[@id="2"]
```

selecciona el empleado cuyo:

```text
id
```

es:

```text
2
```

---

# 26. PREDICADO NUMÉRICO

Podemos utilizar:

```text
//empleado[2]
```

para seleccionar el segundo elemento.

También podemos realizar comparaciones.

Ejemplo:

```text
//empleado[salario > 27000]
```

selecciona empleados con salario superior a:

```text
27000
```

---

# 27. OPERADORES DE COMPARACIÓN

XPath permite utilizar operadores como:

```text
=
!=
<
>
<=
>=
```

Ejemplo:

```text
//empleado[salario >= 28000]
```

---

# 28. OPERADORES LÓGICOS

Podemos combinar condiciones.

```text
and
or
not()
```

Ejemplo:

```text
//empleado[
    puesto="Desarrollador"
    and
    salario > 26000
]
```

---

# 29. `contains()`

Permite comprobar si una cadena contiene otra.

Ejemplo:

```text
//nombre[contains(., "Pedro")]
```

---

# 30. `starts-with()`

Comprueba si una cadena comienza por un texto.

Ejemplo:

```text
//nombre[
    starts-with(., "P")
]
```

---

# 31. `string-length()`

Devuelve la longitud de una cadena.

Ejemplo conceptual:

```text
string-length(
    //nombre
)
```

---

# 32. `count()`

Cuenta nodos.

Ejemplo:

```text
count(//empleado)
```

Podría devolver:

```text
3
```

---

# 33. `sum()`

Permite calcular una suma sobre valores numéricos.

Ejemplo:

```text
sum(//salario)
```

---

# 34. `position()`

Devuelve la posición del nodo dentro del conjunto de contexto.

Ejemplo:

```text
//empleado[
    position() = 1
]
```

selecciona el primero.

---

# 35. `last()`

Devuelve la posición del último nodo del conjunto.

Ejemplo:

```text
//empleado[
    position() = last()
]
```

selecciona el último empleado.

---

# 36. PRIMER Y ÚLTIMO

Podemos simplificar:

```text
//empleado[1]
```

→ primero.

```text
//empleado[last()]
```

→ último.

---

# 37. `ancestor`

XPath permite navegar por relaciones entre nodos.

Algunos ejes:

```text
ancestor
ancestor-or-self
child
descendant
descendant-or-self
parent
self
following-sibling
preceding-sibling
```

---

# 38. `child`

Selecciona hijos.

Ejemplo:

```text
child::empleado
```

---

# 39. `parent`

Selecciona el padre:

```text
parent::empleados
```

---

# 40. `ancestor`

Selecciona antecesores.

Por ejemplo:

```text
ancestor::empresa
```

desde un empleado puede llegar al elemento:

```text
empresa
```

---

# 41. `descendant`

Selecciona descendientes:

```text
descendant::nombre
```

---

# 42. `following-sibling`

Selecciona hermanos posteriores.

Ejemplo conceptual:

```text
following-sibling::empleado
```

---

# 43. `preceding-sibling`

Selecciona hermanos anteriores.

---

# 44. AXIS

Estos caminos se denominan:

```text
axes
```

o:

```text
ejes
```

Los ejes permiten expresar relaciones dentro del árbol XML.

---

# 45. ATAJO DE `child`

La expresión:

```text
/empresa/empleados
```

equivale conceptualmente a:

```text
/child::empresa/child::empleados
```

---

# 46. ATAJO DE ATRIBUTO

```text
@id
```

equivale conceptualmente a:

```text
attribute::id
```

---

# 47. `self`

El eje:

```text
self
```

hace referencia al nodo actual.

Ejemplo:

```text
self::empleado
```

---

# 48. NAMESPACE EN XPATH

Cuando trabajamos con namespaces, normalmente necesitamos utilizar prefijos asociados al namespace.

Por ejemplo:

```xml
<lib:libro
    xmlns:lib="urn:libros">
```

En XPath podríamos utilizar:

```text
/lib:libro
```

si el prefijo está correctamente asociado en el contexto de evaluación.

---

# 49. XSLT

XSLT significa:

```text
Extensible Stylesheet Language Transformations
```

Es un lenguaje para transformar documentos XML.

---

# 50. ¿QUÉ HACE XSLT?

Podemos transformar:

```text
XML
```

en:

```text
HTML
```

o:

```text
XML
```

o:

```text
texto
```

entre otros resultados.

Conceptualmente:

```text
XML
 ↓
XSLT
 ↓
resultado
```

---

# 51. XSLT Y XPATH

XSLT utiliza XPath para seleccionar nodos.

Por tanto:

```text
XPath
→ selección

XSLT
→ transformación
```

Esta relación es fundamental.

---

# 52. HOJA DE ESTILO XSLT

Una hoja XSLT utiliza normalmente:

```xml
<xsl:stylesheet
    xmlns:xsl=
        "http://www.w3.org/1999/XSL/Transform"
    version="1.0">
```

---

# 53. `xsl:template`

Define una plantilla.

Ejemplo:

```xml
<xsl:template match="/">
    ...
</xsl:template>
```

---

# 54. `match`

El atributo:

```text
match
```

indica sobre qué nodos se aplica una plantilla.

Ejemplo:

```xml
<xsl:template
    match="/empresa">
```

---

# 55. `xsl:value-of`

Permite obtener el valor de una expresión XPath.

Ejemplo:

```xml
<xsl:value-of
    select="nombre"/>
```

---

# 56. `select`

Muchos elementos XSLT utilizan:

```text
select
```

para indicar una expresión XPath.

Ejemplo:

```xml
<xsl:value-of
    select="//nombre"/>
```

---

# 57. `xsl:for-each`

Permite iterar sobre un conjunto de nodos.

Ejemplo:

```xml
<xsl:for-each
    select="//empleado">

    <p>
        <xsl:value-of
            select="nombre"/>
    </p>

</xsl:for-each>
```

---

# 58. `xsl:if`

Permite realizar una condición.

Ejemplo:

```xml
<xsl:if
    test="salario > 27000">

    ...

</xsl:if>
```

El atributo:

```text
test
```

utiliza XPath.

---

# 59. `xsl:choose`

Permite expresar alternativas.

Conceptualmente:

```xml
<xsl:choose>

    <xsl:when
        test="salario > 30000">
        ...
    </xsl:when>

    <xsl:otherwise>
        ...
    </xsl:otherwise>

</xsl:choose>
```

---

# 60. `xsl:when`

Representa una condición dentro de:

```text
xsl:choose
```

---

# 61. `xsl:otherwise`

Representa la alternativa cuando no se cumple ninguna condición anterior.

---

# 62. `xsl:apply-templates`

Permite solicitar la aplicación de plantillas a nodos seleccionados.

Ejemplo:

```xml
<xsl:apply-templates
    select="//empleado"/>
```

---

# 63. `xsl:sort`

Permite ordenar resultados.

Ejemplo:

```xml
<xsl:for-each
    select="//empleado">

    <xsl:sort
        select="salario"
        data-type="number"
        order="descending"/>

    ...

</xsl:for-each>
```

---

# 64. EJEMPLO SENCILLO XSLT

XML:

```xml
<empresa>

    <empleado>
        <nombre>Pedro</nombre>
        <puesto>Desarrollador</puesto>
    </empleado>

    <empleado>
        <nombre>Ana</nombre>
        <puesto>Administradora</puesto>
    </empleado>

</empresa>
```

XSLT:

```xml
<xsl:stylesheet
    version="1.0"
    xmlns:xsl=
        "http://www.w3.org/1999/XSL/Transform">

    <xsl:template match="/">

        <html>

            <body>

                <h1>Empleados</h1>

                <ul>

                    <xsl:for-each
                        select="empresa/empleado">

                        <li>

                            <xsl:value-of
                                select="nombre"/>

                        </li>

                    </xsl:for-each>

                </ul>

            </body>

        </html>

    </xsl:template>

</xsl:stylesheet>
```

Resultado conceptual:

```html
<h1>Empleados</h1>

<ul>
    <li>Pedro</li>
    <li>Ana</li>
</ul>
```

---

# 65. ASOCIAR XSLT CON XML

Un documento XML puede asociarse a una hoja XSLT mediante una instrucción de procesamiento:

```xml
<?xml-stylesheet
    type="text/xsl"
    href="empleados.xsl"?>
```

---

# 66. XML + XSLT

El flujo conceptual:

```text
XML
 │
 │ datos
 ↓
XSLT
 │
 │ transformación
 ↓
HTML / XML / texto
```

---

# 67. XPath VS XSLT

Es una distinción fundamental.

### XPath

```text
selecciona y navega
```

### XSLT

```text
transforma
```

Podemos imaginar:

```text
XPath
→ "dame estos nodos"

XSLT
→ "utiliza estos nodos para construir otro documento"
```

---

# 68. 🧠 MAPA CONCEPTUAL

```text
                         XML
                          │
                          ↓
                        XPath
                          │
            ┌─────────────┼─────────────┐
            ↓             ↓             ↓
         rutas        predicados       ejes
            │             │             │
          / //          [ ]          parent
          . ..          @id          child
          *             = >          ancestor
                                      sibling
                          │
                          ↓
                         XSLT
                          │
            ┌─────────────┼──────────────┐
            ↓             ↓              ↓
        template       for-each        choose
            │             │              │
          match         select          when
            │
            ↓
       transformación
            │
            ↓
       HTML/XML/texto
```
