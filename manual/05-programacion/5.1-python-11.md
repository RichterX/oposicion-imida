# 6. LISTA PYTHON VS ARRAY NUMPY

Podemos tener:

```python
lista = [1, 2, 3, 4]
```

o:

```python
array = np.array([1, 2, 3, 4])
```

Aunque ambos pueden almacenar valores, NumPy está diseñado específicamente para operaciones numéricas eficientes.

---

# 7. OPERACIONES VECTORIALIZADAS

Una característica importante de NumPy es que podemos realizar operaciones sobre arrays completos.

Ejemplo:

```python
import numpy as np

numeros = np.array([1, 2, 3])

resultado = numeros * 2
```

Resultado:

```text
[2 4 6]
```

No necesitamos escribir explícitamente un `for`.

---

# 8. OPERACIONES ELEMENTO A ELEMENTO

Podemos hacer:

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

resultado = a + b
```

Resultado:

```text
[11 22 33]
```

La operación se realiza elemento a elemento.

# 76. TIMEOUT

En código real es recomendable utilizar un timeout:

```python

    url,
    timeout=10
)
```

Esto evita esperar indefinidamente por una respuesta.

---

# 77. EXCEPCIONES DE REQUESTS

Requests proporciona excepciones relacionadas con las peticiones.

Una forma habitual:

```python
try:
    respuesta = requests.get(
        url,
        timeout=10
    )

    respuesta.raise_for_status()

except requests.RequestException as error:
    print(error)
```

---

# 78. `raise_for_status()`

Este método comprueba el estado HTTP y puede lanzar una excepción para respuestas de error.

Por ejemplo, respuestas:

```text
4xx
5xx
```

pueden provocar una excepción mediante:

```python
response.raise_for_status()
```
