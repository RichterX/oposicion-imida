# 2. TIPADO DINÁMICO

Python utiliza tipado dinámico.

Esto significa que una variable no necesita declarar explícitamente su tipo:

```python
numero = 10
nombre = "Pedro"
activo = True
```

El objeto tiene un tipo determinado y una variable puede referenciar objetos de diferentes tipos durante la ejecución.

Por ejemplo:

```python
valor = 10
valor = "Hola"
```

es válido.

---

# 3. TIPADO FUERTE

Python también se considera normalmente un lenguaje de **tipado fuerte**.

Esto significa que no realiza conversiones implícitas arbitrarias entre tipos incompatibles.

Por ejemplo:

```python
"10" + 5
```

produce:

```text
TypeError
```

Podemos convertir explícitamente:

```python
int("10") + 5
```

Resultado:

```text
15
```

### 🧠 Importante

```text
Dinámico
→ el tipo se determina en tiempo de ejecución

Fuerte
→ no realiza conversiones implícitas incompatibles de forma arbitraria
```

# 4. TYPE HINTS

Python permite indicar el tipo esperado mediante **anotaciones de tipo**.

Ejemplo:

```python
edad: int = 35
```

Otro ejemplo:

```python
nombre: str = "Pedro"
```

Las anotaciones proporcionan información sobre el tipo esperado.

---

# 5. LAS ANOTACIONES NO SON NORMALMENTE RESTRICCIONES EN TIEMPO DE EJECUCIÓN

Esto es importante.

Podemos escribir:

```python
edad: int = 35
```

pero Python no convierte automáticamente:

```python
edad = "Pedro"
```

en un error simplemente por haber escrito la anotación.

Las anotaciones sirven principalmente para:

```text
Documentación
IDEs
Linters
Type checkers
Herramientas de análisis estático
```

---

# 6. ANOTACIONES DE FUNCIONES

Podemos anotar parámetros:

```python
def sumar(a: int, b: int):
    return a + b
```

También podemos indicar el valor de retorno:

```python
def sumar(a: int, b: int) -> int:
    return a + b
```

---

# 7. ANOTACIONES DE VARIABLES

Ejemplo:

```python
nombre: str
edad: int
activo: bool
```

También:

```python
usuarios: list[str]
```

# 8. `typing`

El módulo:

```python
typing
```

proporciona herramientas para expresar tipos más complejos.

Ejemplo:

```python
from typing import Optional
```

En Python moderno muchas anotaciones pueden expresarse directamente con tipos incorporados.

---

# 9. `list`, `dict`, `tuple` Y TIPADO

En Python moderno podemos escribir:

```python
numeros: list[int]
```

Esto indica:

```text
lista cuyos elementos deberían ser enteros
```

También:

```python
usuarios: dict[str, int]
```

indica un diccionario cuyos elementos se esperan como:

```text
clave → str
valor → int
```

---

# 10. TUPLAS

Podemos especificar los elementos de una tupla:

```python
persona: tuple[str, int]
```

Conceptualmente:

```text
str
+
int
```

en ese orden.

Para una tupla de longitud variable con un mismo tipo:

```python
numeros: tuple[int, ...]
```

---

# 11. `Optional`

Tradicionalmente:

```python
Optional[int]
```

significa:

```text
int o None
```

Ejemplo:

```python
from typing import Optional

edad: Optional[int] = None
```

En Python moderno también podemos expresar:

```python
edad: int | None = None
```

---

# 12. `Union`

`Union` permite indicar que un valor puede pertenecer a varios tipos.

Ejemplo:

```python
from typing import Union

valor: Union[int, str]
```

significa:

```text
int
o
str
```

En Python moderno también puede escribirse:

```python
valor: int | str
```

---

# 13. `Any`

`Any` significa, conceptualmente:

```text
cualquier tipo
```

Ejemplo:

```python
from typing import Any

valor: Any
```

Puede contener:

```python
valor = 10
valor = "Hola"
valor = [1, 2, 3]
```

### ⚠️ Importante

Abusar de `Any` reduce la utilidad del tipado estático.

---

# 14. `Callable`

Podemos indicar que esperamos una función u otro objeto invocable.

Ejemplo:

```python
from typing import Callable

operacion: Callable[[int, int], int]
```

Conceptualmente:

```text
recibe:
    int
    int

devuelve:
    int
```

---

# 15. `TypeVar`

`TypeVar` permite representar un tipo genérico.

Ejemplo:

```python
from typing import TypeVar

T = TypeVar("T")
```

Podemos utilizarlo:

```python
def primero(elementos: list[T]) -> T:
    return elementos[0]
```

La idea es conservar la relación entre:

```text
tipo de entrada
```

y:

```text
tipo de salida
```

---

# 16. TIPOS GENÉRICOS

Un tipo genérico permite expresar estructuras que funcionan con distintos tipos manteniendo información sobre ellos.

Ejemplo conceptual:

```python
def primero(elementos: list[T]) -> T:
    return elementos[0]
```

Si:

```python
list[int]
```

entra, el resultado se interpreta como:

```text
int
```

Si:

```python
list[str]
```

entra, el resultado se interpreta como:

```text
str
```

---

# 17. `Protocol`

Python proporciona:

```python
from typing import Protocol
```

para expresar interfaces estructurales.

Ejemplo:

```python
class Hablador(Protocol):

    def hablar(self) -> str:
        ...
```

Una clase no necesita heredar explícitamente de `Hablador` para ser compatible estructuralmente.

Si proporciona:

```python
hablar() -> str
```

puede cumplir el protocolo desde la perspectiva del análisis estático.

---

# 18. DUCK TYPING Y `Protocol`

Esto conecta con el concepto visto anteriormente:

```text
Duck typing
```

La idea:

```text
si el objeto proporciona el comportamiento requerido,
puede utilizarse
```

`Protocol` permite expresar esta idea de forma explícita para herramientas de tipado.

---

# 19. `Literal`

`Literal` permite indicar valores concretos.

Ejemplo:

```python
from typing import Literal

modo: Literal["lectura", "escritura"]
```

La intención es que el valor sea uno de:

```text
"lectura"
"escritura"
```

---

# 20. `Final`

Podemos utilizar:

```python
from typing import Final

PI: Final = 3.14159
```

La anotación indica la intención de que ese valor no se reasigne.

### ⚠️ Importante

`Final` es principalmente una indicación para herramientas de análisis estático, no un mecanismo de inmutabilidad absoluta impuesto por el intérprete.

# 21. ENUMERACIONES

Python incluye el módulo:

```python
enum
```

Podemos utilizar:

```python
from enum import Enum
```

Ejemplo:

```python
class Color(Enum):
    ROJO = 1
    VERDE = 2
    AZUL = 3
```

Ahora:

```python
Color.ROJO
```

representa un miembro de la enumeración.

---

# 22. ¿POR QUÉ UTILIZAR `Enum`?

En lugar de utilizar valores arbitrarios:

```python
estado = 1
```

podemos utilizar:

```python
Estado.ACTIVO
```

Esto puede hacer el código más expresivo y reducir errores.

---

# 23. COMPARAR ENUMS

Ejemplo:

```python
from enum import Enum


class Estado(Enum):
    ACTIVO = 1
    INACTIVO = 2


estado = Estado.ACTIVO
```

Podemos hacer:

```python
if estado == Estado.ACTIVO:
    print("Activo")
```

---

# 24. `auto()`

El módulo `enum` también proporciona:

```python
from enum import Enum, auto
```

Ejemplo:

```python
class Estado(Enum):
    ACTIVO = auto()
    INACTIVO = auto()
    PENDIENTE = auto()
```

Python asigna automáticamente los valores.

---

# 25. `IntEnum`

Existe también:

```python
IntEnum
```

que combina el comportamiento de una enumeración con una relación con `int`.

Ejemplo:

```python
from enum import IntEnum

class Prioridad(IntEnum):
    BAJA = 1
    MEDIA = 2
    ALTA = 3
```

# 26. DATACLASSES

Python proporciona:

```python
dataclasses
```

para crear clases orientadas principalmente a almacenar datos reduciendo código repetitivo.

Ejemplo:

```python
from dataclasses import dataclass


@dataclass
class Persona:
    nombre: str
    edad: int
```

Ahora podemos hacer:

```python
persona = Persona("Pedro", 35)
```

---

# 27. ¿QUÉ APORTA `@dataclass`?

Una dataclass puede generar automáticamente métodos como:

```text
__init__
__repr__
__eq__
```

según la configuración.

Esto evita escribir manualmente mucho código repetitivo.

---

# 28. DATACLASS VS CLASE NORMAL

Sin dataclass:

```python
class Persona:

    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad
```

Con dataclass:

```python
from dataclasses import dataclass


@dataclass
class Persona:
    nombre: str
    edad: int
```

La segunda forma es mucho más compacta.

---

# 29. VALORES POR DEFECTO

Podemos utilizar valores por defecto:

```python
@dataclass
class Persona:
    nombre: str
    activo: bool = True
```

Entonces:

```python
persona = Persona("Pedro")
```

tendrá:

```text
activo → True
```

---

# 30. `field()`

Podemos personalizar campos mediante:

```python
from dataclasses import dataclass, field
```

Ejemplo:

```python
@dataclass
class Grupo:
    nombre: str
    miembros: list[str] = field(default_factory=list)
```

Esto permite crear una nueva lista para cada instancia.

---

# 31. ¿POR QUÉ `default_factory`?

No debemos utilizar alegremente:

```python
miembros: list[str] = []
```

cuando queremos un contenedor independiente por instancia.

Con:

```python
field(default_factory=list)
```

cada objeto obtiene su propia lista.

Conceptualmente:

```text
Objeto A
→ lista A

Objeto B
→ lista B
```

---

# 32. DATACLASS INMUTABLE

Podemos utilizar:

```python
@dataclass(frozen=True)
```

Ejemplo:

```python
@dataclass(frozen=True)
class Punto:
    x: int
    y: int
```

La intención es impedir reasignaciones de los campos después de crear la instancia.

# 33. UNPACKING

Python permite desempaquetar valores.

Ejemplo:

```python
numeros = [1, 2, 3]

a, b, c = numeros
```

Ahora:

```text
a → 1
b → 2
c → 3
```

---

# 34. UNPACKING CON `*`

Podemos utilizar:

```python
a, *resto = [1, 2, 3, 4]
```

Resultado:

```text
a → 1
resto → [2, 3, 4]
```

---

# 35. UNPACKING AL FINAL

También:

```python
*inicio, ultimo = [1, 2, 3, 4]
```

Resultado:

```text
inicio → [1, 2, 3]
ultimo → 4
```

---

# 36. UNPACKING EN EL CENTRO

Podemos hacer:

```python
a, *medio, z = [1, 2, 3, 4, 5]
```

Resultado:

```text
a → 1
medio → [2, 3, 4]
z → 5
```

---

# 37. UNPACKING DE DICCIONARIOS

Para diccionarios podemos utilizar:

```python
**
```

Ejemplo:

```python
datos1 = {"nombre": "Ana"}
datos2 = {"edad": 30}

datos = {
    **datos1,
    **datos2
}
```

Resultado:

```python
{
    "nombre": "Ana",
    "edad": 30
}
```

---

# 38. `**` EN LLAMADAS A FUNCIONES

También podemos utilizar:

```python
datos = {
    "nombre": "Ana",
    "edad": 30
}


def mostrar(nombre, edad):
    print(nombre, edad)
```

Y:

```python
mostrar(**datos)
```

Es equivalente conceptualmente a:

```python
mostrar(
    nombre="Ana",
    edad=30
)
```

---

# 39. `*args` Y `**kwargs`

Ya hemos visto:

```python
*args
**kwargs
```

`*args` recoge argumentos posicionales.

`**kwargs` recoge argumentos nombrados.

Ejemplo:

```python
def funcion(*args, **kwargs):
    print(args)
    print(kwargs)
```

# 40. OPERADOR WALRUS `:=`

Python incluye el operador de asignación por expresión:

```python
:=
```

conocido informalmente como:

```text
walrus operator
```

Ejemplo:

```python
if (longitud := len("Hola")) > 3:
    print(longitud)
```

La expresión:

```python
longitud := len("Hola")
```

asigna y produce el valor.

---

# 41. DIFERENCIA `=` VS `:=`

```python
=
```

es una asignación convencional.

Mientras:

```python
:=
```

permite asignar dentro de una expresión.

Ejemplo:

```python
while (linea := archivo.readline()):
    print(linea)
```

---

# 42. OPERADORES DE IDENTIDAD

Python dispone de:

```python
is
is not
```

Se utilizan para comprobar **identidad de objetos**, no igualdad de valores.

Ejemplo:

```python
a is b
```

pregunta si:

```text
a y b hacen referencia al mismo objeto
```

---

# 43. `==` VS `is`

```python
==
```

compara igualdad.

```python
is
```

compara identidad.

Ejemplo conceptual:

```python
a == b
```

significa:

```text
¿tienen el mismo valor según la comparación?
```

Mientras:

```python
a is b
```

significa:

```text
¿son exactamente el mismo objeto?
```

---

# 44. `is None`

Es habitual utilizar:

```python
if valor is None:
    ...
```

en lugar de:

```python
if valor == None:
    ...
```

La primera forma comprueba identidad con el objeto singleton:

```text
None
```

```python
in
not in
```

Ejemplo:


Resultado:

```text

```

También:

```python

```

# 46. OPERADORES BOOLEANOS

Python utiliza:

```text
and
or
not
```

Ejemplo:

```python

    ...
```

# 47. SHORT-CIRCUIT

Los operadores:

```python
and
or
```

utilizan evaluación de cortocircuito.

Ejemplo:

```python
False and funcion()
```

no necesita evaluar:

```python
funcion()
```

porque el resultado ya se conoce.

---

# 48. `and` Y `or` NO SIEMPRE DEVUELVEN `True` O `False`

Este es un detalle importante.

En Python:

```python
a and b
```

puede devolver uno de los propios operandos.

Ejemplo:

```python
resultado = 0 or 10
```

Resultado:

```text
10
```

Otro:

```python
resultado = "Hola" and 10
```

Resultado:

```text
10
```

---

# 49. OPERADOR TERNARIO

Python permite expresar una condición en una sola expresión:

```python
resultado = "mayor" if edad >= 18 else "menor"
```

Equivale conceptualmente a:

```python
if edad >= 18:
    resultado = "mayor"
else:
    resultado = "menor"
```

---

# 50. PATTERN MATCHING

Desde Python 3.10 existe:

```python
match
case
```

para realizar pattern matching estructural.

Ejemplo:

```python
def describir(valor):

    match valor:
        case 0:
            return "cero"

        case 1:
            return "uno"

        case _:
            return "otro"
```

---

# 51. `case _`

El patrón:

```python
case _:
```

actúa como caso general.

Conceptualmente se parece al:

```text
default
```

de otros lenguajes.

---

# 52. MATCH CON VARIAS ALTERNATIVAS

Podemos utilizar:

```python
match valor:

    case 1 | 2 | 3:
        print("Pequeño")

    case _:
        print("Otro")
```

El operador:

```text
|
```

permite expresar alternativas en patrones.

---

# 53. MATCH CON GUARDAS

Podemos añadir una condición:

```python
match valor:

    case x if x > 10:
        print("Mayor que 10")

    case _:
        print("10 o menor")
```

La condición:

```python
if x > 10
```

es una guarda.

---

# 54. MATCH CON ESTRUCTURAS

Pattern matching también puede trabajar con estructuras.

Por ejemplo:

```python
match punto:

    case (0, 0):
        print("Origen")

    case (x, 0):
        print(f"Eje X: {x}")

    case (0, y):
        print(f"Eje Y: {y}")

    case (x, y):
        print(f"Punto: {x}, {y}")
```

Esto permite descomponer estructuras de datos.

---

# 55. MATCH CON DICCIONARIOS

También podemos utilizar patrones con diccionarios:

```python
match usuario:

    case {"nombre": nombre, "edad": edad}:
        print(nombre, edad)

    case _:
        print("Formato desconocido")
```

---

# 56. MATCH VS `if/elif`

No significa que:

```text
match
```

reemplace siempre a:

```text
if/elif
```

`match` resulta especialmente interesante cuando queremos comparar y descomponer estructuras siguiendo patrones.

---

# 57. `assert`

Aunque ya hemos trabajado las excepciones, conviene recordar:

```python
assert
```

Permite comprobar una condición durante la ejecución.

Ejemplo:

```python
edad = 20

assert edad >= 18
```

Si la condición es falsa:

```text
AssertionError
```

---

# 58. `assert` CON MENSAJE

Podemos escribir:

```python
assert edad >= 18, "Debe ser mayor de edad"
```

Si falla:

```text
AssertionError
```

con el mensaje correspondiente.

---

# 59. ⚠️ `assert` NO ES UNA VALIDACIÓN DE SEGURIDAD

Las aserciones pueden desactivarse mediante determinadas opciones de ejecución de Python.

Por ello no deben utilizarse como mecanismo principal para validar datos externos o condiciones de seguridad.
