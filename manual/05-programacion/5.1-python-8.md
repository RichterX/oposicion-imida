# 1. INTRODUCCIÓN

Python permite utilizar el paradigma de **Programación Orientada a Objetos (POO)**.

La idea fundamental es organizar el programa alrededor de:

```text
Objetos
```

que contienen:

```text
Datos
+
Comportamiento
```

Por ejemplo, podemos representar una persona:

```text
Persona
├── nombre
├── edad
└── saludar()
```

Los datos serían los atributos:

```text
nombre
edad
```

y el comportamiento estaría representado por métodos:

```text
saludar()
```

---

# 2. CLASES Y OBJETOS

Una **clase** es una definición o plantilla que describe cómo serán determinados objetos.

Un **objeto** es una instancia concreta de una clase.

Conceptualmente:

```text
CLASE
  ↓
plantilla
  ↓
OBJETOS
  ├── objeto 1
  ├── objeto 2
  └── objeto 3
```

Ejemplo:

```python
class Persona:
    pass
```

Creamos objetos:

```python
persona1 = Persona()
persona2 = Persona()
```

Ambos son instancias de:

```text
Persona
```

---

# 3. DEFINIR UNA CLASE

Utilizamos:

```python
class
```

Ejemplo:

```python
class Persona:
    pass
```

Por convención, los nombres de las clases utilizan **PascalCase**:

```python
class Persona:
    pass

class CuentaBancaria:
    pass
```

# 4. CREAR OBJETOS


Ahora:

```text
persona
```

es un objeto de tipo:

```text
Persona
```

Podemos comprobarlo:

```python
print(type(persona))
```

# 5. `__init__`

Uno de los métodos especiales más conocidos es:

```python
__init__
```

Se utiliza habitualmente para inicializar el estado de un objeto.

Ejemplo:

```python
class Persona:

    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad
```

Ahora:

```python
persona = Persona("Pedro", 35)
```

El objeto tendrá:

```text
nombre → Pedro
edad   → 35
```

---

# 6. `self`

`self` representa, convencionalmente, la instancia actual.

En:

```python
class Persona:

    def __init__(self, nombre):
        self.nombre = nombre
```

tenemos:

```text
nombre
```

como parámetro recibido y:

```text
self.nombre
```

como atributo del objeto.

---

# 7. ATRIBUTOS DE INSTANCIA

Los atributos de instancia pertenecen a cada objeto.

Ejemplo:

```python
class Persona:

    def __init__(self, nombre):
        self.nombre = nombre
```

Podemos crear:

```python
persona1 = Persona("Ana")
persona2 = Persona("Luis")
```

Entonces:

```text
persona1.nombre → Ana
persona2.nombre → Luis
```

Cada instancia mantiene su propio valor.

---

# 8. MÉTODOS

Los métodos son funciones definidas dentro de una clase.

Ejemplo:

```python
class Persona:

    def __init__(self, nombre):
        self.nombre = nombre

    def saludar(self):
        print(f"Hola, soy {self.nombre}")
```

Podemos hacer:

```python
persona = Persona("Pedro")

persona.saludar()
```

Resultado:

```text
Hola, soy Pedro
```

---

# 9. `self` EN LOS MÉTODOS

Normalmente, los métodos de instancia reciben:

```python
self
```

como primer parámetro.

Ejemplo:

```python
class Persona:

    def saludar(self):
        print("Hola")
```

Cuando hacemos:

```python
persona.saludar()
```

Python pasa implícitamente la instancia como `self`.

### 🧠 Importante

`self` no es una palabra reservada de Python.

Es una **convención**.

Podría utilizarse otro nombre, aunque hacerlo sería contrario a la convención habitual y poco recomendable.

# 12. SOMBREADO DE ATRIBUTOS

Una instancia puede tener un atributo con el mismo nombre que uno de clase.

Ejemplo:

```python
class Persona:

    nombre = "Desconocido"
```

Podemos hacer:

```python
persona = Persona()

persona.nombre = "Pedro"
```

Ahora:

```text
persona.nombre
```

utiliza el atributo de instancia.

El atributo de clase sigue existiendo en la clase.

# 13. MODIFICAR ATRIBUTOS

Podemos modificar un atributo directamente:

```python
persona.nombre = "Luis"
```

También podemos crear atributos nuevos:

```python
persona.edad = 35
```

Python permite esta flexibilidad en las instancias normales.

# 14. ENCAPSULACIÓN

La encapsulación consiste en controlar cómo se accede al estado y comportamiento de un objeto.

Python no utiliza exactamente el mismo sistema de modificadores de acceso que lenguajes como Java o C++.

En su lugar utiliza principalmente:

```text
Convenciones
Name mangling
Propiedades
```

---

# 15. ATRIBUTOS CON `_`

Un atributo como:

```python
self._saldo
```

indica convencionalmente:

```text
"interno / protegido por convención"
```

No impide realmente el acceso desde fuera.

Por ejemplo:

```python
cuenta._saldo
```

sigue siendo posible.

### 🧠 Importante

Un solo `_`:

```text
no proporciona privacidad real
```

Es una convención.

---

# 16. ATRIBUTOS CON `__`

Un nombre como:

```python
self.__saldo
```

activa el mecanismo conocido como:

```text
name mangling
```

Python transforma internamente el nombre para dificultar ciertos accesos accidentales.

No equivale a una privacidad absoluta.

---

# 17. NAME MANGLING

Ejemplo:

```python
class Cuenta:

    def __init__(self):
        self.__saldo = 100
```

Internamente, el atributo se almacena con un nombre transformado relacionado con la clase.

Podemos inspeccionar el objeto:

```python
cuenta.__dict__
```

y observar el nombre transformado.

### 🧠 Regla

```text
_saldo
→ convención de uso interno

__saldo
→ name mangling
```

---

# 18. PROPIEDADES

Python permite controlar el acceso a atributos mediante:

```python
@property
```

Ejemplo:

```python
class Persona:

    def __init__(self, nombre):
        self._nombre = nombre

    @property
    def nombre(self):
        return self._nombre
```

Podemos acceder:

```python
persona.nombre
```

como si fuera un atributo.

---

# 19. `@property`

Una propiedad permite presentar un método mediante una interfaz de atributo.

En:

```python
@property
def nombre(self):
    return self._nombre
```

podemos hacer:

```python
persona.nombre
```

en lugar de:

```python
persona.nombre()
```

---

# 20. `@property` CON SETTER

Podemos definir también cómo se modifica:

```python
class Persona:

    def __init__(self, edad):
        self._edad = edad

    @property
    def edad(self):
        return self._edad

    @edad.setter
    def edad(self, valor):
        if valor < 0:
            raise ValueError("Edad no válida")

        self._edad = valor
```

Ahora:

```python
persona.edad = 35
```

pasa por el setter.

---

# 21. `@property` COMO VALIDACIÓN

Una de las aplicaciones habituales es validar valores:

```python
@edad.setter
def edad(self, valor):
    if valor < 0:
        raise ValueError("Edad no válida")

    self._edad = valor
```

Esto permite controlar el estado interno del objeto.

# 22. HERENCIA

La herencia permite crear una clase a partir de otra.

Ejemplo:

```python
class Animal:
    def hablar(self):
        print("Sonido")


class Perro(Animal):
    pass
```

Ahora:

```python
perro = Perro()

perro.hablar()
```

El método se hereda de:

```text
Animal
```

---

# 23. CLASE PADRE Y CLASE HIJA

En:

```python
class Perro(Animal):
    pass
```

tenemos:

```text
Animal
→ clase padre / superclase

Perro
→ clase hija / subclase
```

---

# 24. HERENCIA Y REUTILIZACIÓN

La clase hija puede reutilizar comportamiento de la clase padre.

```python
class Animal:

    def respirar(self):
        print("Respirando")


class Perro(Animal):
    pass
```

Entonces:

```python
perro = Perro()

perro.respirar()
```

funciona aunque `respirar()` no esté definido directamente en `Perro`.

---

# 25. SOBRESCRITURA DE MÉTODOS

Una clase hija puede redefinir un método heredado.

```python
class Animal:

    def hablar(self):
        print("Sonido")


class Perro(Animal):

    def hablar(self):
        print("Guau")
```

Ahora:

```python
perro = Perro()

perro.hablar()
```

Resultado:

```text
Guau
```

El método de `Perro` sobrescribe el heredado.

---

# 26. `super()`

Podemos utilizar:

```python
super()
```

para acceder a comportamiento de la clase padre.

Ejemplo:

```python
class Animal:

    def __init__(self, nombre):
        self.nombre = nombre


class Perro(Animal):

    def __init__(self, nombre, raza):
        super().__init__(nombre)
        self.raza = raza
```

Así reutilizamos el constructor de `Animal`.

---

# 27. `super()` Y MÉTODOS

También:

```python
class Animal:

    def hablar(self):
        print("Sonido")


class Perro(Animal):

    def hablar(self):
        super().hablar()
        print("Guau")
```

Resultado:

```text
Sonido
Guau
```

---

# 28. POLIMORFISMO

El polimorfismo permite utilizar objetos de diferentes clases mediante una interfaz común.

Ejemplo:

```python
class Perro:

    def hablar(self):
        print("Guau")


class Gato:

    def hablar(self):
        print("Miau")
```

Podemos crear:

```python
animales = [
    Perro(),
    Gato()
]
```

y:

```python
for animal in animales:
    animal.hablar()
```

Resultado:

```text
Guau
Miau
```

El código no necesita conocer específicamente qué clase representa cada objeto.

---

# 29. DUCK TYPING

Python utiliza ampliamente el concepto conocido como:

```text
Duck typing
```

La idea informal es:

```text
No importa tanto qué clase es el objeto,
sino qué operaciones puede realizar.
```

Si un objeto tiene:

```python
hablar()
```

podemos utilizarlo en un contexto que necesite un objeto capaz de:

```text
hablar
```

No es necesario que pertenezca a una determinada jerarquía de clases.

---

# 30. EJEMPLO DE DUCK TYPING

```python
class Perro:

    def hablar(self):
        print("Guau")


class Robot:

    def hablar(self):
        print("Hola humano")


def hacer_hablar(objeto):
    objeto.hablar()
```

Podemos hacer:

```python
hacer_hablar(Perro())
hacer_hablar(Robot())
```

Ambos funcionan porque proporcionan:

```python
hablar()
```

---

# 31. MÉTODOS DE CLASE

Python permite definir métodos de clase mediante:

```python
@classmethod
```

Ejemplo:

```python
class Persona:

    especie = "Humano"

    @classmethod
    def obtener_especie(cls):

```

Aquí:

```text
cls
```

representa la clase.

# 32. `cls`

De la misma forma que:

```text
self
```

se utiliza convencionalmente para la instancia:

```text
cls
```

se utiliza convencionalmente para la clase en un `classmethod`.

Ejemplo:

```python
@classmethod
def crear(cls):
    return cls()
```

---

# 33. CUÁNDO UTILIZAR `classmethod`

Es útil cuando el comportamiento necesita trabajar con:

```text
la clase
```

en lugar de una instancia concreta.

Un caso frecuente es implementar constructores alternativos:

```python
class Persona:

    def __init__(self, nombre):
        self.nombre = nombre

    @classmethod
    def desde_texto(cls, texto):
        return cls(texto.strip())
```

Podemos hacer:

```python
persona = Persona.desde_texto(" Pedro ")
```

---

# 34. MÉTODOS ESTÁTICOS

También existe:

```python
@staticmethod
```

Un método estático no recibe automáticamente:

```text
self
```

ni:

```text
cls
```

Ejemplo:

```python
class Matematicas:

    @staticmethod
    def sumar(a, b):
        return a + b
```

Podemos hacer:

```python
Matematicas.sumar(2, 3)
```

---

# 35. `staticmethod` VS `classmethod`

| Tipo | Primer parámetro automático | Trabaja principalmente con |
|---|---|---|
| Método de instancia | `self` | Instancia |
| `classmethod` | `cls` | Clase |
| `staticmethod` | Ninguno | Ninguno automáticamente |

### 🧠 Regla

```text
self
→ objeto

cls
→ clase

staticmethod
→ ninguno
```

# 37. `__str__`

Define una representación textual pensada para usuarios.

Ejemplo:

```python
class Persona:

    def __init__(self, nombre):
        self.nombre = nombre

    def __str__(self):
        return f"Persona: {self.nombre}"
```

Ahora:

```python
persona = Persona("Pedro")

print(persona)
```

Resultado:

```text
Persona: Pedro
```

---

# 38. `__repr__`

`__repr__` proporciona una representación textual destinada principalmente a desarrolladores y depuración.

Ejemplo:

```python
class Persona:

    def __init__(self, nombre):
        self.nombre = nombre

    def __repr__(self):
        return f"Persona(nombre={self.nombre!r})"
```

Podemos obtener:

```text
Persona(nombre='Pedro')
```

### 🧠 Regla simplificada

```text
__str__
→ representación amigable

__repr__
→ representación orientada a desarrollo/depuración
```

```python
class Grupo:
```

# 44. MRO

Cuando existe herencia múltiple, Python necesita determinar el orden en que busca métodos.

Esto se denomina:

```text
Method Resolution Order
```

o:

```text
MRO
```

Podemos consultarlo mediante:

```python
C.mro()
```

o:

```python
C.__mro__
```

---

# 45. EJEMPLO DE MRO

```python
class A:
    def hablar(self):
        print("A")


class B(A):
    def hablar(self):
        print("B")


class C(B):
    pass
```

Al ejecutar:

```python
C().hablar()
```

Python busca según la MRO.

En este caso encuentra:

```text
C
↓
B
↓
A
```

y ejecuta:

```text
B.hablar()
```

# 46. CLASES ABSTRACTAS

Python proporciona el módulo:

```python
abc
```

para trabajar con clases abstractas.

Podemos importar:

```python
from abc import ABC, abstractmethod
```

Ejemplo:

```python
class Animal(ABC):

    @abstractmethod
    def hablar(self):
        pass
```

Una clase con métodos abstractos puede utilizarse como base para exigir determinadas operaciones a las subclases.

---

# 47. MÉTODO ABSTRACTO

Un método decorado con:

```python
@abstractmethod
```

representa una operación que las clases concretas deben implementar.

Ejemplo:

```python
class Animal(ABC):

    @abstractmethod
    def hablar(self):
        pass
```

Una subclase concreta puede hacer:

```python
class Perro(Animal):

    def hablar(self):
        print("Guau")
```

---

# 48. INSTANCIACIÓN DE CLASE ABSTRACTA

Una clase abstracta con métodos abstractos pendientes no puede instanciarse directamente.

Conceptualmente:

```text
Clase abstracta
      ↓
define contrato
      ↓
subclases
      ↓
implementación
```

# 49. COMPOSICIÓN

No todo debe resolverse mediante herencia.

La composición consiste en que un objeto contiene otros objetos.

Ejemplo:

```python
class Motor:
    def arrancar(self):
        print("Motor arrancado")


class Coche:

    def __init__(self):
        self.motor = Motor()
```

Aquí:

```text
Coche
  └── contiene un Motor
```

Esto representa una relación:

```text
tiene-un
```

mientras que la herencia representa:

```text
es-un
```

---

# 50. HERENCIA VS COMPOSICIÓN

| Concepto | Relación |
|---|---|
| Herencia | "es un" |
| Composición | "tiene un" |

Ejemplo:

```text
Perro es un Animal
```

puede representar herencia.

Mientras:

```text
Coche tiene un Motor
```

puede representar composición.

```python
persona = Persona("Pedro")

```

Resultado:

```text
True
```

También tiene en cuenta la herencia.

# 52. `issubclass()`

Permite comprobar si una clase es subclase de otra:

```python
issubclass(Perro, Animal)
```

Resultado:

```text
True
```

---

# 53. `type()` VS `isinstance()`

Podemos utilizar:

```python
type(objeto)
```

para conocer su tipo exacto.

Mientras:

```python
isinstance(objeto, Clase)
```

también tiene en cuenta la herencia.

Ejemplo conceptual:

```python
class Animal:
    pass

class Perro(Animal):
    pass

perro = Perro()
```

Entonces:

```python
type(perro) == Perro
```

es:

```text
True
```

y:

```python
isinstance(perro, Animal)
```

también es:

```text
True
```
