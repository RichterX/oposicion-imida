# 2. ESTRUCTURAS CONDICIONALES

Las estructuras condicionales permiten ejecutar código dependiendo de si una condición es verdadera o falsa.

La estructura básica es:

```python
if condicion:
    instrucciones
```

Ejemplo:

```python
edad = 20

if edad >= 18:
    print("Mayor de edad")
```

Si la condición:

```python
edad >= 18
```

es `True`, se ejecuta el bloque.

---

# 3. `if`

La palabra reservada:

```python
if
```

introduce una condición.

Ejemplo:

```python
temperatura = 30

if temperatura > 25:
    print("Hace calor")
```

La sintaxis utiliza `:` al final de la condición:

```python
if condicion:
```

y el bloque debe estar correctamente indentado.

---

# 4. `else`

Podemos especificar qué hacer cuando la condición no se cumple.

```python
edad = 16

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
```

Resultado:

```text
Menor de edad
```

La estructura es:

```text
if
 ├── condición verdadera → bloque if
 └── condición falsa → bloque else
```

---

# 5. `elif`

Cuando necesitamos comprobar varias condiciones utilizamos:

```python
elif
```

Ejemplo:

```python
nota = 7

if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")
```

Python comprueba las condiciones **de arriba hacia abajo**.

En cuanto encuentra una condición verdadera, ejecuta su bloque y continúa después de toda la estructura.

---

# 6. ORDEN DE EVALUACIÓN DE `if / elif / else`

Observa:

```python
x = 10

if x > 5:
    print("A")
elif x > 8:
    print("B")
else:
    print("C")
```

Resultado:

```text
A
```

Aunque:

```python
x > 8
```

también es verdadero, nunca se evalúa como una rama ejecutada porque el primer `if` ya se ha cumplido.

### 🧠 Regla de examen

En una cadena:

```text
if
elif
elif
else
```

se ejecuta como máximo **una rama**.

```text
not
```


# 8. CONDICIONES ANIDADAS

Un `if` puede encontrarse dentro de otro.

```python
edad = 25
tiene_carnet = True

if edad >= 18:
    if tiene_carnet:
        print("Puede conducir")
```

Sin embargo, siempre que sea posible, podemos simplificar:

```python
if edad >= 18 and tiene_carnet:
    print("Puede conducir")
```

# 9. OPERADOR CONDICIONAL

Python permite escribir una expresión condicional en una sola línea.

Sintaxis:

```python
valor_si_true if condicion else valor_si_false
```

Ejemplo:

```python
edad = 20

resultado = "Adulto" if edad >= 18 else "Menor"
```

Ahora:

```text
resultado = "Adulto"
```

Esto suele conocerse como **expresión condicional**.

---

# 10. COMPARACIÓN CON OTROS LENGUAJES

En PHP podemos encontrar:

```php
$resultado = $edad >= 18 ? "Adulto" : "Menor";
```

En JavaScript:

```javascript
const resultado = edad >= 18 ? "Adulto" : "Menor";
```

En Python:

```python
resultado = "Adulto" if edad >= 18 else "Menor"
```

### ⚠️ Trampa

Python **no utiliza** `?:` para esta expresión.

# 11. BUCLES

Los bucles permiten repetir un bloque de código.

Python proporciona principalmente:

```text

```

---

# 12. BUCLE `while`

`while` repite un bloque mientras una condición sea verdadera.

Ejemplo:

```python
contador = 1

while contador <= 5:
    print(contador)
    contador += 1
```

Resultado:

```text
1
2
3
4
5
```

---

# 13. FUNCIONAMIENTO DE `while`

El flujo es:

```text
        ┌───────────────┐
        │ ¿condición?   │
        └───────┬───────┘
                │
         ┌──────┴──────┐
       True           False
         │               │
         ▼               ▼
    ejecutar bloque     salir
         │
         └───────► volver a comprobar
```

---

# 14. CUIDADO CON LOS BUCLES INFINITOS

Este código:

```python
contador = 1

while contador <= 5:
    print(contador)
```

no modifica `contador`.

La condición siempre seguirá siendo verdadera:

```text
1 <= 5
```

Por tanto, el bucle será infinito.

### 🧠 Regla

Cuando uses `while`, comprueba siempre que exista alguna forma de que la condición llegue a ser falsa.

# 17. `for` NO ES EXACTAMENTE COMO EL `for` DE PHP

# 18. `range()`

`range()` genera una secuencia de números que podemos recorrer.

La forma más sencilla:

```python
range(stop)
```

Por ejemplo:

```python
for i in range(5):
    print(i)
```

Resultado:

```text
0
1
2
3
4
```

### ⚠️ Muy importante

`range(5)` **no llega hasta 5**.

Genera:

```text
0, 1, 2, 3, 4
```

---

# 19. `range(start, stop)`

Podemos indicar un inicio:

```python
range(2, 6)
```

produce:

```text
2
3
4
5
```

El límite final:

```text
6
```

queda excluido.

---

# 20. `range(start, stop, step)`

También podemos especificar el paso:

```python
range(0, 10, 2)
```

produce:

```text
0
2
4
6
8
```

Otro ejemplo:

```python
range(10, 0, -2)
```

produce:

```text
10
8
6
4
2
```

---

# 21. REGLA DE `range()`

La sintaxis completa:

```python
range(start, stop, step)
```

donde:

```text
start → inicio
stop  → límite exclusivo
step  → incremento
```

Si omitimos `start`:

```python
range(stop)
```

comienza en:

```text
0
```

Si omitimos `step`:

```text
step = 1
```

# 23. `break`

`break` termina inmediatamente el bucle en el que se encuentra.

Ejemplo:

```python
for i in range(10):
    if i == 5:
        break
    print(i)
```

Resultado:

```text
0
1
2
3
4
```

Cuando:

```python
i == 5
```

se ejecuta:

```python
break
```

y el bucle termina.

---

# 24. `continue`

`continue` no termina el bucle.

Hace que se salte la iteración actual y pase a la siguiente.

Ejemplo:

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

Resultado:

```text
0
1
3
4
```

El `2` se omite.

---

# 25. `break` VS `continue`

Esta diferencia es fundamental.

```text
break
 ↓
TERMINA EL BUCLE
```

Mientras:

```text
continue
 ↓
OMITE LA ITERACIÓN ACTUAL
 ↓
SIGUE EL BUCLE
```

### 🧠 Regla de examen

```text
break    → salir
continue → saltar
```

---

# 26. `pass`

Python dispone también de:

```python
pass
```

`pass` no termina el bucle ni salta la iteración.

Simplemente **no hace nada**.

Ejemplo:

```python
for i in range(5):
    pass
```

El bucle se ejecuta, pero el cuerpo no realiza ninguna operación.

Se utiliza frecuentemente como marcador de posición.

---

# 27. `break`, `continue` Y `pass`

| Instrucción | Efecto |
|---|---|
| `break` | Termina el bucle |
| `continue` | Salta a la siguiente iteración |
| `pass` | No hace nada |

Esta tabla es muy susceptible de aparecer en preguntas tipo test.

# 28. `else` EN BUCLES

Una característica particularmente interesante de Python es que tanto `for` como `while` pueden tener un bloque `else`.

Ejemplo:

```python
for i in range(3):
    print(i)
else:
    print("Fin")
```

Resultado:

```text
0
1
2
Fin
```

---

# 29. ¿CUÁNDO SE EJECUTA EL `else` DEL BUCLE?

El `else` se ejecuta cuando el bucle termina **normalmente**, es decir, cuando no ha sido interrumpido mediante `break`.

Ejemplo:

```python
for i in range(5):
    if i == 2:
        break
else:
    print("Fin")
```

El `else` no se ejecuta.

### 🧠 Regla

```text
Bucle termina normalmente
        ↓
      else ✓

Bucle termina con break
        ↓
      else ✗
```

# 31. `enumerate()`

Cuando recorremos una colección y necesitamos tanto:

```text
índice

valor
```

podemos utilizar:

```python
enumerate()
```

Ejemplo:

```python
frutas = ["manzana", "pera", "plátano"]

for indice, fruta in enumerate(frutas):
    print(indice, fruta)
```

Resultado:

```text
0 manzana

```

# 32. `enumerate()` CON `start`

```text

2 pera
3 plátano
```

Esto es especialmente útil cuando queremos numerar elementos desde `1`.

# 33. `zip()`

`zip()` permite recorrer varias secuencias simultáneamente.

Ejemplo:

```python
nombres = ["Ana", "Luis", "Pedro"]
edades = [20, 30, 40]

for nombre, edad in zip(nombres, edades):
    print(nombre, edad)
```

Resultado:

```text
Ana 20
Luis 30
Pedro 40
```

Conceptualmente:

```text
Ana   ↔ 20
Luis  ↔ 30
Pedro ↔ 40
```

---

# 34. `zip()` Y LONGITUDES DIFERENTES

Si las secuencias tienen diferente longitud:

```python
nombres = ["Ana", "Luis", "Pedro"]
edades = [20, 30]
```

```python
for nombre, edad in zip(nombres, edades):
    print(nombre, edad)
```

el recorrido termina cuando se agota el iterable más corto.

Resultado:

```text
Ana 20
Luis 30
```

`Pedro` no aparece porque no tiene un elemento correspondiente en `edades`.

# 35. ITERABLES

Hasta ahora hemos utilizado mucho la palabra:

```text
iterable
```

Un iterable es, simplificando, un objeto que puede proporcionar sus elementos uno a uno para ser recorrido.

Ejemplos habituales:

```text
list
tuple
str
set
dict
range
```

Por ejemplo:

```python
for letra in "Hola":
    print(letra)
```

La cadena es iterable.

---

# 36. ITERADOR VS ITERABLE

Para el examen puede ser importante distinguir:

```text
Iterable
```

de:

```text
Iterador
```

Un **iterable** es un objeto que puede proporcionar un iterador.

Un **iterador** mantiene el estado del recorrido y proporciona los elementos sucesivos mediante `next()`.

Ejemplo:

```python
numeros = [10, 20, 30]

iterador = iter(numeros)

print(next(iterador))
print(next(iterador))
```

Resultado:

```text
10
20
```

---

# 37. `iter()`

La función:

```python
iter()
```

obtiene un iterador a partir de un iterable.

Ejemplo:

```python
numeros = [10, 20, 30]

it = iter(numeros)
```

---

# 38. `next()`

La función:

```python
next()
```

obtiene el siguiente elemento de un iterador.

```python
numeros = [10, 20, 30]

it = iter(numeros)

print(next(it))
print(next(it))
print(next(it))
```

Resultado:

```text
10
20
30
```

Si intentamos obtener otro elemento:

```python
next(it)
```

se produce:

```text
StopIteration
```

# 39. COMPRENSIONES

Python permite construir colecciones de forma compacta.

Las más conocidas son las **list comprehensions**.

Ejemplo tradicional:

```python
numeros = [1, 2, 3, 4]

dobles = []

for numero in numeros:
    dobles.append(numero * 2)
```

Podemos escribirlo como:

```python
dobles = [numero * 2 for numero in numeros]
```

Resultado:

```text
[2, 4, 6, 8]
```

---

# 40. ESTRUCTURA DE UNA LIST COMPREHENSION

La estructura básica:

```python
[expresion for elemento in iterable]
```

Por ejemplo:

```python
[x * 2 for x in range(5)]
```

Resultado:

```text
[0, 2, 4, 6, 8]
```

---

# 41. COMPREHENSION CON CONDICIÓN

Podemos añadir un `if`.

```python
numeros = range(10)

pares = [x for x in numeros if x % 2 == 0]
```

Resultado:

```text
[0, 2, 4, 6, 8]
```

La estructura:

```python
[expresion for elemento in iterable if condicion]
```

---

# 42. COMPREHENSION CON `if / else`

También podemos introducir una expresión condicional:

```python
resultado = [
    "par" if x % 2 == 0 else "impar"
    for x in range(5)
]
```

Resultado:

```text
["par", "impar", "par", "impar", "par"]
```

### ⚠️ Importante

Hay una diferencia sintáctica entre:

```python
[x for x in numeros if condicion]
```

y:

```python
[valor_si_true if condicion else valor_si_false for x in numeros]
```

---

# 43. SET COMPREHENSION

También podemos construir conjuntos:

```python
pares = {x for x in range(10) if x % 2 == 0}
```

Resultado conceptualmente:

```text
{0, 2, 4, 6, 8}
```

---

# 44. DICT COMPREHENSION

También podemos crear diccionarios:

```python
cuadrados = {x: x ** 2 for x in range(5)}
```

Resultado:

```text
{
    0: 0,
    1: 1,
    2: 4,
    3: 9,
    4: 16
}
```

# 45. GENERADORES Y EXPRESIONES GENERADOR

Una expresión similar puede utilizar paréntesis:

```python
generador = (x * 2 for x in range(5))
```

Esto no crea directamente una lista con todos los resultados.

Crea un **generador**, que produce los valores bajo demanda.

Por ejemplo:

```python
for valor in generador:
    print(valor)
```

Resultado:

```text
0
2
4
6
8
```

Los generadores los estudiaremos con más profundidad posteriormente.

# 46. BUCLES ANIDADOS

Podemos colocar un bucle dentro de otro.

Ejemplo:


```text

1 0
1 1

```

El bucle interior se ejecuta completamente por cada iteración del exterior.
