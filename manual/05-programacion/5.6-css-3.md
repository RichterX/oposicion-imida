# 2. TRANSICIONES

Una transición permite suavizar el cambio entre dos estados de una propiedad CSS.

Por ejemplo:

```css
.boton {
    background-color: blue;
    transition: background-color 0.3s;
}

.boton:hover {
    background-color: red;
}
```

Sin transición:

```text
azul → rojo
```

Con transición:

```text
azul → transición gradual → rojo
```

---

# 3. `transition-property`

Indica qué propiedad o propiedades deben animarse mediante una transición.

Ejemplo:

```css
.boton {
    transition-property: background-color;
}
```

También podemos indicar varias:

```css
transition-property:
    background-color,
    transform;
```

---

# 4. `transition-duration`

Indica cuánto dura la transición.

Ejemplo:

```css
transition-duration: 0.3s;
```

También pueden utilizarse milisegundos:

```css
transition-duration: 300ms;
```

Recordatorio:

```text
1s = 1000ms
```

---

# 5. `transition-timing-function`

Controla cómo progresa la transición durante el tiempo.

Valores conocidos:

```text
ease
linear
ease-in
ease-out
ease-in-out
```

También pueden utilizarse funciones como:

```text
cubic-bezier()
steps()
```

---

# 6. `linear`

La velocidad permanece constante durante la transición.

Conceptualmente:

```text
velocidad constante
```

---

# 7. `ease`

Produce una transición con aceleración y desaceleración.

Es uno de los valores predeterminados habituales de CSS.

---

# 8. `ease-in`

La transición comienza más lentamente y acelera.

---

# 9. `ease-out`

La transición comienza más rápidamente y desacelera hacia el final.

---

# 10. `ease-in-out`

Combina:

```text
inicio suave
+
final suave
```

---

# 11. `transition-delay`

Permite retrasar el comienzo de la transición.

Ejemplo:

```css
transition-delay: 200ms;
```

El cambio espera:

```text
200ms
```

antes de comenzar.

---

# 12. SHORTHAND `transition`

Podemos resumir varias propiedades:

```css
transition:
    background-color
    0.3s
    ease
    0s;
```

Conceptualmente:

```text
property
duration
timing-function
delay
```

# 13. TRANSICIONES VS ANIMACIONES

### Transition

Normalmente necesita un cambio de estado:

```text
estado A
   ↓
estado B
```

Por ejemplo:

```text
normal → hover
```

### Animation

Puede ejecutarse mediante:

```text
@keyframes
```

y tener múltiples etapas.

# 14. TRANSFORMACIONES

La propiedad:

```css
transform
```

permite transformar visualmente un elemento.

Operaciones habituales:

```text
translate
scale
rotate
skew
```

---

# 15. `translate`

Permite desplazar visualmente un elemento.

Ejemplo:

```css
transform: translateX(20px);
```

También:

```css
transform: translateY(20px);
```

o:

```css
transform: translate(20px, 10px);
```

---

# 16. `translateX`

Mueve el elemento en el eje horizontal:

```css
transform:
    translateX(50px);
```

---

# 17. `translateY`

Mueve el elemento verticalmente:

```css
transform:
    translateY(20px);
```

---

# 18. `translateZ`

Permite una transformación en el eje Z dentro de un contexto 3D.

Ejemplo:

```css
transform:
    translateZ(20px);
```

---

# 19. `scale`

Modifica visualmente el tamaño.

Ejemplo:

```css
transform:
    scale(1.2);
```

Esto representa:

```text
120 %
```

del tamaño original en este contexto.

También:

```css
transform:
    scale(1.2, 0.8);
```

permite diferentes factores en los ejes.

---

# 20. `scaleX` Y `scaleY`

```css
transform: scaleX(1.2);
```

modifica la escala horizontal.

```css
transform: scaleY(0.8);
```

modifica la escala vertical.

---

# 21. `rotate`

Permite rotar un elemento.

Ejemplo:

```css
transform:
    rotate(45deg);
```

También pueden utilizarse otras unidades angulares como:

```text
deg
rad
grad
turn
```

---

# 22. `skew`

Inclina un elemento.

Ejemplo:

```css
transform:
    skewX(20deg);
```

o:

```css
transform:
    skewY(10deg);
```

---

# 23. MÚLTIPLES TRANSFORMACIONES

Podemos combinar transformaciones:

```css
transform:
    translateX(20px)
    rotate(10deg)
    scale(1.1);
```

El orden de las transformaciones importa.

No debemos asumir que:

```text
A + B
```

produce exactamente el mismo resultado que:

```text
B + A
```

---

# 24. `transform-origin`

Define el punto de referencia desde el que se realizan determinadas transformaciones.

Ejemplo:

```css
transform-origin:
    center;
```

También:

```css
transform-origin:
    top left;
```

Puede utilizarse con rotaciones, escalados y otras transformaciones.

---

# 25. `perspective`

Permite establecer una perspectiva para transformaciones 3D.

Ejemplo:

```css
transform:
    perspective(500px)
    rotateY(45deg);
```

También existe la propiedad:

```css
perspective
```

para establecer perspectiva en un contexto 3D.

No deben confundirse ambos usos.

---

# 26. `backface-visibility`

Controla si la cara posterior de un elemento transformado en 3D puede ser visible.

Valores:

```text
visible
hidden
```

Ejemplo:

```css
.card {
    backface-visibility: hidden;
}
```

---

# 27. ANIMACIONES CSS

CSS permite definir animaciones mediante:

```css
@keyframes
```

y la propiedad:

```css
animation
```

---

# 28. `@keyframes`

Define las etapas de una animación.

Ejemplo:

```css
@keyframes aparecer {
    from {
        opacity: 0;
    }

    to {
        opacity: 1;
    }
}
```

---

# 29. PORCENTAJES EN `@keyframes`

También podemos utilizar porcentajes:

```css
@keyframes mover {
    0% {
        transform: translateX(0);
    }

    50% {
        transform: translateX(100px);
    }

    100% {
        transform: translateX(0);
    }
}
```

Esto permite definir múltiples estados.

---

# 30. `animation-name`

Indica qué `@keyframes` debe utilizarse.

Ejemplo:

```css
.elemento {
    animation-name: aparecer;
}
```

---

# 31. `animation-duration`

Indica la duración:

```css
animation-duration: 2s;
```

---

# 32. `animation-delay`

Retrasa el inicio:

```css
animation-delay: 500ms;
```

---

# 33. `animation-iteration-count`

Indica cuántas veces se ejecuta la animación.

Ejemplo:

```css
animation-iteration-count: 3;
```

Para repetirla indefinidamente:

```css
animation-iteration-count: infinite;
```

---

# 34. `animation-direction`

Controla la dirección de reproducción.

Valores conocidos:

```text
normal
reverse
alternate
alternate-reverse
```

---

# 35. `normal`

La animación se reproduce en la dirección normal:

```text
0% → 100%
```

---

# 36. `reverse`

La animación se reproduce:

```text
100% → 0%
```

---

# 37. `alternate`

Alterna:

```text
normal
→ reverse
→ normal
→ reverse
```

en iteraciones sucesivas.

---

# 38. `alternate-reverse`

Comienza en dirección inversa y alterna posteriormente.

---

# 39. `animation-fill-mode`

Determina qué estilos se aplican antes y después de la ejecución de una animación.

Valores importantes:

```text
none
forwards
backwards
both
```

---

# 40. `forwards`

Mantiene los estilos definidos por el último keyframe relevante al terminar la animación.

---

# 41. `backwards`

Puede aplicar los estilos del primer keyframe durante el periodo de espera de la animación, teniendo en cuenta la dirección.

---

# 42. `both`

Combina los comportamientos de:

```text
forwards
+
backwards
```

---

# 43. `animation-play-state`

Permite controlar si la animación está:

```text
running
paused
```

Ejemplo:

```css
.elemento {
    animation-play-state: paused;
}
```

---

# 44. `animation-timing-function`

Controla cómo progresa la animación.

Puede utilizar:

```text
linear
ease
ease-in
ease-out
ease-in-out
cubic-bezier()
steps()
```

---

# 45. SHORTHAND `animation`

Podemos combinar propiedades:

```css
.elemento {
    animation:
        aparecer
        2s
        ease
        0s
        infinite
        alternate;
}
```

La sintaxis completa puede incluir varias propiedades y su orden debe interpretarse correctamente según la gramática de `animation`.

---

# 46. TRANSICIONES Y RENDIMIENTO

Las propiedades relacionadas con:

```text
transform
opacity
```

suelen ser buenas candidatas para animaciones eficientes en navegadores modernos.

Esto no significa que:

```text
transform = siempre GPU
```

ni que cualquier animación vaya automáticamente a una capa independiente.

El rendimiento depende del navegador, hardware y contexto.

---

# 47. `will-change`

Permite indicar que un elemento probablemente cambiará determinadas propiedades.

Ejemplo:

```css
.elemento {
    will-change: transform;
}
```

Debe utilizarse con cuidado.

No es una propiedad para añadir indiscriminadamente a todos los elementos.

# 48. SOMBRAS

CSS permite añadir sombras mediante:

```text
box-shadow
text-shadow
```

---

# 49. `box-shadow`

Ejemplo:

```css
.card {
    box-shadow:
        0 4px 10px
        rgba(0, 0, 0, 0.2);
}
```

Puede incluir:

```text
offset-x
offset-y
blur-radius
spread-radius
color
```

---

# 50. `box-shadow`: COMPONENTES

Conceptualmente:

```text
0       → desplazamiento X
4px     → desplazamiento Y
10px    → desenfoque
rgba()  → color
```

También podemos indicar:

```text
spread-radius
```

antes del color.

---

# 51. SOMBRA INTERIOR

Podemos utilizar:

```css
box-shadow:
    inset 0 2px 5px rgba(0, 0, 0, 0.2);
```

`inset` convierte la sombra en una sombra interior.

---

# 52. MÚLTIPLES SOMBRAS

Podemos especificar varias sombras separadas por comas:

```css
box-shadow:
    0 2px 5px rgba(0, 0, 0, 0.2),
    0 10px 20px rgba(0, 0, 0, 0.1);
```

---

# 53. `text-shadow`

Permite añadir sombra al texto.

Ejemplo:

```css
h1 {
    text-shadow:
        2px 2px 4px
        rgba(0, 0, 0, 0.4);
}
```

# 54. GRADIENTES

CSS permite crear fondos con gradientes.

Tipos principales:

```text
linear-gradient
radial-gradient
conic-gradient
```

---

# 55. `linear-gradient`

Crea una transición lineal entre colores.

Ejemplo:

```css
background:
    linear-gradient(
        to right,
        blue,
        purple
    );
```

---

# 56. DIRECCIÓN DEL GRADIENTE

Podemos utilizar:

```text
to right
to left
to top
to bottom
```

o ángulos:

```css
linear-gradient(
    45deg,
    red,
    blue
);
```

---

# 57. `radial-gradient`

Crea un gradiente que se extiende radialmente desde un punto.

Ejemplo:

```css
background:
    radial-gradient(
        circle,
        white,
        blue
    );
```

---

# 58. `conic-gradient`

Crea un gradiente alrededor de un punto central.

Ejemplo:

```css
background:
    conic-gradient(
        red,
        yellow,
        green,
        blue,
        red
    );
```

Puede utilizarse para:

```text
gráficos
ruedas de color
indicadores
efectos visuales
```

---

# 59. TRANSPARENCIA Y GRADIENTES

Podemos utilizar colores con transparencia:

```css
linear-gradient(
    to right,
    rgba(0, 0, 0, 0.8),
    rgba(0, 0, 0, 0)
);
```

Esto permite crear overlays y degradados sobre imágenes.

```css
background
```

# 63. `background-position`

# 65. `filter`

Ejemplo:


# 66. FUNCIONES DE `filter`


---

# 67. `blur()`

Ejemplo:

```css
filter:
    blur(5px);
```

Aplica desenfoque.

---

# 68. `grayscale()`

Convierte el contenido visual hacia escala de grises.

```css
filter:
    grayscale(100%);
```

---

# 69. `brightness()`

Permite modificar el brillo.

```css
filter:
    brightness(120%);
```

---

# 70. `contrast()`

Permite modificar el contraste.

```css
filter:
    contrast(150%);
```

---

# 71. `drop-shadow()`

Puede crear una sombra basada en la forma alfa del elemento.

Ejemplo:

```css
.logo {
    filter:
        drop-shadow(
            0 4px 4px
            rgba(0, 0, 0, 0.3)
        );
}
```

### Diferencia importante

```text
box-shadow
→ sombra de la caja

drop-shadow()
→ puede seguir la silueta alfa del contenido
```

Esto resulta especialmente útil con:

```text
PNG transparentes
SVG
```

---

# 72. `backdrop-filter`

Permite aplicar determinados filtros al contenido situado detrás de un elemento.

Ejemplo:

```css
.panel {
    backdrop-filter:
        blur(10px);
}
```

Es habitual en interfaces con efectos de vidrio.

Su disponibilidad depende del navegador y contexto.

# 75. `currentColor`

```css

```

representa el valor actual de la propiedad:

```text
color
```

Ejemplo:

```css

    color: blue;
```

El borde utilizará el mismo color que el texto.

# 76. `transparent`

CSS dispone del valor:

```text
transparent
```

que representa un color completamente transparente.

# 77. OUTLINE

La propiedad:

```css
outline
```

permite dibujar un contorno alrededor de un elemento.

Ejemplo:

```css
button:focus {
    outline:
        2px solid blue;
}
```

El outline no forma parte del box model de la misma manera que:

```text
border
```

# 78. BORDER VS OUTLINE

```text
border
→ forma parte del box model

outline
→ no ocupa espacio en el layout como el border
```

Esto es especialmente importante para:

```text
focus
accesibilidad
```

# 80. `user-select`

Controla si el usuario puede seleccionar texto.

Ejemplo:

```css
.elemento {
```

Debe utilizarse con moderación porque desactivar la selección puede perjudicar la usabilidad.

# 81. `pointer-events`

Controla determinadas interacciones del puntero.

Ejemplo:

```css
.overlay {
    pointer-events: none;
}
```

Puede hacer que el elemento no reciba eventos de puntero en determinadas circunstancias.

---

# 82. `scroll-behavior`

Permite controlar el comportamiento de desplazamiento mediante CSS.

Ejemplo:

```css
html {
    scroll-behavior: smooth;
}
```

Esto puede producir desplazamientos suaves al navegar hacia fragmentos del documento.

Debe considerarse también la preferencia:

```text
prefers-reduced-motion
```

---

# 83. `scroll-margin`

Puede proporcionar espacio alrededor del elemento cuando se desplaza hacia él mediante ciertas operaciones de scroll.

Ejemplo:

```css
section {
    scroll-margin-top: 80px;
}
```

Es útil cuando existe un:

```text
header sticky
```

que podría ocultar el encabezado de la sección al saltar a un fragmento.

---

# 84. TRANSICIÓN + TRANSFORM

Un patrón muy común:

```css
.card {
    transition:
        transform 0.2s ease;
}

.card:hover {
    transform:
        translateY(-5px);
}
```

Resultado:

```text
estado normal
      ↓
movimiento suave
      ↓
estado hover
```

---

# 85. ANIMACIÓN COMPLETA

Ejemplo:

```css
@keyframes aparecer {
    from {
        opacity: 0;
        transform:
            translateY(20px);
    }

    to {
        opacity: 1;
        transform:
            translateY(0);
    }
}

.card {
    animation:
        aparecer
        0.5s
        ease-out
        forwards;
}
```

Este patrón combina:

```text
keyframes
+
opacity
+
transform
+
timing function
+
fill mode
```

---

# 86. ACCESIBILIDAD Y ANIMACIONES

Algunas personas pueden experimentar problemas con movimientos intensos.

Por ello es importante respetar:

```css
@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms;
        animation-iteration-count: 1;
        transition-duration: 0.01ms;
    }
}
```

En diseños reales puede ser preferible desactivar o reducir las animaciones de manera cuidadosamente seleccionada.


```text

```

para construir una página completa cuando Flexbox o Grid resuelven mejor el problema.

### 5. Respetar accesibilidad

Especialmente:

```text
focus
reduced motion
orden lógico
contraste
```

# 88. ⚠️ TRAMPAS DE OPOSICIÓN

## Trampa 1

```text
transition
→ transición entre estados

animation
→ secuencia definida mediante keyframes
```

---

## Trampa 2

```text
transform
→ transformación visual

position
→ posicionamiento dentro del layout
```

No son equivalentes.

---

## Trampa 3

```text
translate
→ desplazamiento

scale
→ tamaño visual

rotate
→ rotación

skew
→ inclinación
```

---

## Trampa 4

El orden de las funciones en:

```css
transform:
    translate(...)
    rotate(...);
```

puede afectar al resultado.

---

## Trampa 5

```text
box-shadow
→ sombra de caja

text-shadow
→ sombra de texto

filter: drop-shadow()
→ sombra basada en la forma alfa
```

---

## Trampa 6

```text
cover
→ cubre y puede recortar

contain
→ contiene y puede dejar espacio
```

Esto aparece tanto en:

```text
object-fit
```

como en determinados contextos de:

```text
background-size
```

---

## Trampa 7

```text
border
→ participa en el box model

outline
→ no ocupa espacio de layout como border
```

---

## Trampa 8

```text
animation-iteration-count: infinite
```

significa que la animación se repite indefinidamente.

---

## Trampa 9

```text
animation-fill-mode: forwards
```

mantiene los estilos correspondientes al final de la animación.

---

## Trampa 10

```text
animation-direction: alternate
```

hace que las iteraciones alternen dirección.

---

## Trampa 11

```text
transition-delay
```

retrasa la transición.

```text
animation-delay
```

retrasa la animación.

---

## Trampa 12

`will-change` no debería aplicarse indiscriminadamente a todos los elementos.
