# 🌐 5.5 HTML

> **Bloque:** 5 - Programación  
> **Capítulo:** 5.5 - HTML  
> **Parte:** 1  
> **Enfoque:** Fundamentos de HTML, estructura de documentos, elementos, atributos, semántica, formularios, tablas, multimedia y accesibilidad.

---

# 1. INTRODUCCIÓN

**HTML** significa:

```text
HyperText Markup Language
```

En español:

```text
Lenguaje de Marcado de Hipertexto
```

HTML es el lenguaje de marcado utilizado para estructurar documentos que pueden ser interpretados por navegadores web.

Su función principal es definir:

```text
estructura
contenido
significado semántico
```

de una página.

---

# 2. HTML NO ES UN LENGUAJE DE PROGRAMACIÓN

Esta es una distinción clásica.

HTML:

```text
→ lenguaje de marcado
```

CSS:

```text
→ lenguaje de estilos
```

JavaScript:

```text
→ lenguaje de programación
```

Podemos visualizarlo:

```text
HTML
 ↓
estructura

CSS
 ↓
presentación

JavaScript
 ↓
comportamiento
```

---

# 3. HTML Y LA WEB

Una página web puede entenderse como la combinación de:

```text
HTML
+
CSS
+
JavaScript
```

Por ejemplo:

```text
HTML
→ "hay un botón"

CSS
→ "el botón es azul y está aquí"

JavaScript
→ "cuando se pulsa, ocurre esta acción"
```

---

# 4. HTML5

HTML5 es una versión moderna del estándar HTML que incorporó numerosas mejoras, entre ellas:

```text
elementos semánticos
multimedia nativa
formularios mejorados
APIs relacionadas con la web
```

Entre los elementos semánticos encontramos:

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

---

# 5. DOCUMENTO HTML BÁSICO

Una estructura HTML mínima puede ser:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Mi página</title>
</head>
<body>

    <h1>Hola mundo</h1>

</body>
</html>
```

Tenemos:

```text
DOCTYPE
html
head
body
```

---

# 6. `<!DOCTYPE html>`

La declaración:

```html
<!DOCTYPE html>
```

indica al navegador que el documento utiliza el estándar HTML moderno.

En HTML5 la declaración es sencilla:

```html
<!DOCTYPE html>
```

No es un elemento HTML convencional.

Es una:

```text
declaración
```

---

# 7. ELEMENTO `<html>`

El elemento raíz del documento es:

```html
<html>
```

Todo el documento HTML se encuentra dentro de este elemento.

Ejemplo:

```html
<html>
    <head>
        ...
    </head>

    <body>
        ...
    </body>
</html>
```

---

# 8. ATRIBUTO `lang`

Es recomendable indicar el idioma principal:

```html
<html lang="es">
```

Por ejemplo:

```html
<html lang="en">
```

para inglés.

Este atributo aporta información útil para:

```text
accesibilidad
lectores de pantalla
motores de búsqueda
procesamiento del documento
```

---

# 9. `<head>`

El elemento:

```html
<head>
```

contiene información sobre el documento que no constituye normalmente el contenido principal visible de la página.

Puede incluir:

```text
metadatos
título
hojas de estilo
scripts
favicon
```

---

# 10. `<title>`

Define el título del documento.

Ejemplo:

```html
<title>Mi aplicación</title>
```

El título puede aparecer:

```text
pestaña del navegador
marcadores
resultados o referencias del navegador
```

Es importante no confundir:

```html
<title>
```

con:

```html
<h1>
```

---

# 11. `<body>`

Contiene el contenido que forma parte de la página.

Ejemplo:

```html
<body>

    <h1>Mi página</h1>
    <p>Contenido.</p>

</body>
```

---

# 12. METADATOS

Dentro de `<head>` podemos utilizar:

```html
<meta>
```

para proporcionar información sobre el documento.

Ejemplo:

```html
<meta charset="UTF-8">
```

---

# 13. CODIFICACIÓN DE CARACTERES

Una declaración habitual:

```html
<meta charset="UTF-8">
```

indica la codificación de caracteres.

UTF-8 permite representar una gran cantidad de caracteres y es la opción habitual en documentos HTML modernos.

---

# 14. VIEWPORT

En documentos destinados a dispositivos móviles es habitual:

```html
<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0">
```

Esto proporciona al navegador información sobre cómo adaptar la presentación del documento al dispositivo.

---

# 15. ELEMENTOS HTML

HTML está formado por elementos.

Ejemplo:

```html
<p>Hola</p>
```

Podemos distinguir:

```text
etiqueta de apertura
contenido
etiqueta de cierre
```

Conceptualmente:

```text
<p>
 ↓
contenido
 ↓
</p>
```

---

# 16. ELEMENTOS ANIDADOS

Los elementos pueden contener otros elementos.

Ejemplo:

```html
<p>
    Este texto contiene
    <strong>una palabra importante</strong>.
</p>
```

Tenemos:

```text
p
└── strong
```

La estructura debe mantenerse correctamente anidada.

---

# 17. ELEMENTOS SIN CONTENIDO

Algunos elementos no tienen contenido ni etiqueta de cierre tradicional.

Ejemplos:

```html
<br>
<img>
<input>
<meta>
<link>
<hr>
```

En HTML moderno no es necesario escribir:

```html
<br />
```

aunque esta sintaxis pueda aparecer en determinados contextos.

---

# 18. ATRIBUTOS

Los atributos proporcionan información adicional sobre un elemento.

Ejemplo:

```html
<a href="https://ejemplo.com">
    Enlace
</a>
```

Tenemos:

```text
elemento → a
atributo → href
valor → URL
```

---

# 19. ATRIBUTOS BOOLEANOS

Algunos atributos funcionan como valores booleanos.

Ejemplo:

```html
<input type="checkbox" checked>
```

La presencia de:

```text
checked
```

indica que la opción está marcada.

Otros ejemplos:

```text
disabled
readonly
required
multiple
autofocus
```

---

# 20. ATRIBUTOS GLOBALES

Algunos atributos pueden utilizarse en muchos elementos HTML.

Entre ellos:

```text
id
class
title
lang
style
hidden
data-*
```

---

# 21. `id`

El atributo:

```html
id="usuario"
```

identifica un elemento de forma única dentro del documento.

Ejemplo:

```html
<input id="usuario">
```

Un mismo `id` no debería repetirse en un documento HTML.

---

# 22. `class`

El atributo:

```html
class="boton principal"
```

permite asociar uno o varios elementos a determinadas clases.

Un documento puede tener muchos elementos con la misma clase.

Ejemplo:

```html
<button class="boton">Guardar</button>
<button class="boton">Cancelar</button>
```

---

# 23. `id` VS `class`

### `id`

```text
identificador único
```

### `class`

```text
grupo / clasificación reutilizable
```

Por eso podemos tener:

```html
<div id="menu">
```

pero:

```html
<div class="card">
<div class="card">
<div class="card">
```

---

# 24. `data-*`

HTML permite almacenar datos personalizados mediante atributos:

```html
<button data-id="42">
    Editar
</button>
```

Los atributos personalizados de este tipo deben comenzar por:

```text
data-
```

JavaScript puede acceder a ellos mediante APIs como:

```text
dataset
```

---

# 25. ENCABEZADOS

HTML proporciona:

```html
<h1>
<h2>
<h3>
<h4>
<h5>
<h6>
```

Representan diferentes niveles de encabezado.

Conceptualmente:

```text
h1
└── h2
    └── h3
```

No deben utilizarse simplemente para conseguir un tamaño visual determinado.

La presentación corresponde principalmente a:

```text
CSS
```

---

# 26. `<h1>`

Representa el encabezado de nivel más alto.

Ejemplo:

```html
<h1>Programación Web</h1>
```

Los encabezados ayudan a estructurar jerárquicamente el contenido.

---

# 27. PÁRRAFOS

El elemento:

```html
<p>
```

representa un párrafo.

Ejemplo:

```html
<p>
    Este es un párrafo.
</p>
```

---

# 28. SALTO DE LÍNEA

El elemento:

```html
<br>
```

introduce un salto de línea.

Ejemplo:

```html
Dirección:<br>
Calle Mayor 10
```

No debe utilizarse como mecanismo principal para crear espacios verticales en una página.

Para eso utilizamos:

```text
CSS
```

---

# 29. REGLA HORIZONTAL

El elemento:

```html
<hr>
```

representa una separación temática o cambio de tema.

No debe interpretarse simplemente como:

```text
"dibujar una línea"
```

aunque visualmente pueda aparecer como una.

---

# 30. ÉNFASIS Y TEXTO IMPORTANTE

HTML dispone de elementos semánticos.

Por ejemplo:

```html
<em>énfasis</em>
<strong>importante</strong>
```

No son exactamente equivalentes a:

```html
<i>
<b>
```

porque `em` y `strong` aportan significado semántico.

---

# 31. `<b>` VS `<strong>`

```html
<strong>Texto importante</strong>
```

indica importancia.

```html
<b>Texto destacado</b>
```

representa un texto al que se quiere llamar la atención sin aportar necesariamente el mismo significado semántico.

La apariencia visual no debería ser el único criterio para elegir uno u otro.

---

# 32. `<i>` VS `<em>`

```html
<em>énfasis</em>
```

representa énfasis semántico.

```html
<i>texto en una voz o estilo alternativo</i>
```

puede utilizarse para una voz, término técnico, expresión idiomática u otra forma de contenido diferenciada según el contexto.

---

# 33. LISTAS NO ORDENADAS

Se utiliza:

```html
<ul>
```

con elementos:

```html
<li>
```

Ejemplo:

```html
<ul>
    <li>Python</li>
    <li>Java</li>
    <li>JavaScript</li>
</ul>
```

---

# 34. LISTAS ORDENADAS

Se utiliza:

```html
<ol>
```

Ejemplo:

```html
<ol>
    <li>Primero</li>
    <li>Segundo</li>
    <li>Tercero</li>
</ol>
```

El orden de los elementos tiene significado.

---

# 35. LISTAS DE DESCRIPCIÓN

HTML también proporciona:

```html
<dl>
<dt>
<dd>
```

Ejemplo:

```html
<dl>
    <dt>HTML</dt>
    <dd>Lenguaje de marcado.</dd>

    <dt>CSS</dt>
    <dd>Lenguaje de estilos.</dd>
</dl>
```

Conceptualmente:

```text
dl
├── dt → término
└── dd → descripción
```

---

# 36. ENLACES

El elemento:

```html
<a>
```

representa un hiperenlace.

Ejemplo:

```html
<a href="https://ejemplo.com">
    Visitar sitio
</a>
```

El atributo principal es:

```text
href
```

---

# 37. `href`

Indica el destino del enlace.

Puede apuntar a:

```text
otra página
archivo
sección del documento
URL
recurso
```

Ejemplo:

```html
<a href="/contacto">
    Contacto
</a>
```

---

# 38. ENLACES INTERNOS

Podemos utilizar un `id` como destino:

```html
<h2 id="contacto">
    Contacto
</h2>
```

Y enlazarlo:

```html
<a href="#contacto">
    Ir a contacto
</a>
```

El carácter:

```text
#
```

indica un fragmento del documento.

---

# 39. `target`

El atributo:

```html
target
```

indica dónde abrir el recurso enlazado.

Un valor conocido:

```html
target="_blank"
```

abre el enlace en un nuevo contexto de navegación, habitualmente una nueva pestaña.

Cuando se usa `_blank` con enlaces externos, es habitual considerar también:

```html
rel="noopener"
```

según el contexto y las necesidades de seguridad.

---

# 40. IMÁGENES

El elemento:

```html
<img>
```

permite insertar imágenes.

Ejemplo:

```html
<img
    src="foto.jpg"
    alt="Descripción de la fotografía">
```

---

# 41. `src`

El atributo:

```text
src
```

indica la ubicación del recurso.

Ejemplo:

```html
<img src="imagenes/foto.jpg">
```

---

# 42. `alt`

El atributo:

```text
alt
```

proporciona un texto alternativo para la imagen.

Es especialmente importante para:

```text
accesibilidad
```

Si una imagen es puramente decorativa, el texto alternativo puede ser vacío:

```html
alt=""
```

---

# 43. DIMENSIONES DE IMÁGENES

Podemos encontrar:

```html
<img
    src="foto.jpg"
    width="800"
    height="600"
    alt="Fotografía">
```

Las dimensiones también pueden controlarse mediante CSS.

En general, CSS es el lugar adecuado para gestionar la presentación visual.

---

# 44. ELEMENTOS SEMÁNTICOS

HTML moderno proporciona elementos para expresar la estructura lógica del documento.

Los más importantes:

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

---

# 45. `<header>`

Representa contenido introductorio o cabecera de una página o sección.

Puede contener:

```text
logo
título
navegación
información introductoria
```

No significa necesariamente:

```text
"cabecera de toda la página"
```

También puede existir dentro de una sección o artículo.

---

# 46. `<nav>`

Representa una sección de navegación.

Ejemplo:

```html
<nav>
    <a href="/">Inicio</a>
    <a href="/blog">Blog</a>
    <a href="/contacto">Contacto</a>
</nav>
```

No todo grupo de enlaces tiene que ser necesariamente un `<nav>`.

---

# 47. `<main>`

Representa el contenido principal del documento.

Habitualmente debe existir un contenido principal claramente identificable.

En un documento normalmente se utiliza un único:

```html
<main>
```

como contenido principal.

---

# 48. `<section>`

Representa una sección temática de contenido.

Ejemplo:

```html
<section>
    <h2>Productos</h2>
    <p>...</p>
</section>
```

Una sección normalmente tiene sentido como parte estructurada del documento y suele beneficiarse de un encabezado.

---

# 49. `<article>`

Representa contenido independiente o autocontenido.

Ejemplos:

```text
artículo de blog
noticia
entrada de foro
publicación
```

Ejemplo:

```html
<article>
    <h2>Nuevo producto</h2>
    <p>...</p>
</article>
```

---

# 50. `<aside>`

Representa contenido relacionado pero secundario respecto al contenido principal.

Ejemplos:

```text
barra lateral
enlaces relacionados
información complementaria
```

---

# 51. `<footer>`

Representa el pie de una página o sección.

Puede contener:

```text
copyright
información de contacto
enlaces
autor
información legal
```

Al igual que `<header>`, puede aparecer asociado a una sección o artículo.

---

# 52. SEMÁNTICA

Una estructura:

```html
<div class="header">
```

puede ser visualmente similar a:

```html
<header>
```

pero no transmite el mismo significado semántico.

HTML semántico permite comunicar:

```text
qué representa el contenido
```

y no solamente:

```text
cómo se muestra
```

---

# 53. `<div>`

`div` es un contenedor genérico sin significado semántico específico.

Ejemplo:

```html
<div class="card">
    ...
</div>
```

Es útil cuando no existe un elemento semántico más apropiado.

---

# 54. `<span>`

`span` es un contenedor genérico en línea.

Ejemplo:

```html
<p>
    Precio:
    <span class="precio">20 €</span>
</p>
```

No aporta significado semántico por sí mismo.

---

# 55. `div` VS `span`

```text
div
→ contenedor genérico de tipo bloque

span
→ contenedor genérico en línea
```

La distinción moderna debe entenderse también desde el modelo de contenido HTML y CSS, no únicamente desde cómo se renderizan por defecto.

---

# 56. TABLAS

HTML proporciona:

```html
<table>
<tr>
<th>
<td>
```

para representar datos tabulares.

---

# 57. ESTRUCTURA BÁSICA DE UNA TABLA

Ejemplo:

```html
<table>
    <tr>
        <th>Nombre</th>
        <th>Edad</th>
    </tr>

    <tr>
        <td>Ana</td>
        <td>30</td>
    </tr>
</table>
```

Tenemos:

```text
table
├── tr → fila
├── th → encabezado
└── td → celda
```

---

# 58. `th` VS `td`

```text
th
→ encabezado de una celda

td
→ celda de datos
```

Los encabezados aportan semántica y accesibilidad.

---

# 59. `caption`

Podemos proporcionar un título o descripción de la tabla:

```html
<table>
    <caption>Usuarios registrados</caption>
    ...
</table>
```

---

# 60. SECCIONES DE TABLA

Podemos estructurar una tabla mediante:

```html
<thead>
<tbody>
<tfoot>
```

Ejemplo:

```html
<table>

    <thead>
        ...
    </thead>

    <tbody>
        ...
    </tbody>

    <tfoot>
        ...
    </tfoot>

</table>
```

---

# 61. CELDAS QUE OCUPAN VARIAS COLUMNAS

El atributo:

```html
colspan
```

permite que una celda ocupe varias columnas.

Ejemplo:

```html
<td colspan="2">
    Total
</td>
```

---

# 62. CELDAS QUE OCUPAN VARIAS FILAS

El atributo:

```html
rowspan
```

permite que una celda ocupe varias filas.

Ejemplo:

```html
<td rowspan="2">
    Grupo A
</td>
```

---

# 63. FORMULARIOS

El elemento:

```html
<form>
```

representa un formulario para introducir o enviar datos.

Ejemplo:

```html
<form action="/usuarios" method="post">

    ...

</form>
```

---

# 64. `action`

Indica el destino al que se enviarán los datos del formulario.

Ejemplo:

```html
<form action="/login">
```

---

# 65. `method`

Indica el método HTTP utilizado para enviar el formulario.

Los valores habituales:

```text
GET
POST
```

Ejemplo:

```html
<form method="post">
```

---

# 66. GET VS POST EN FORMULARIOS

### GET

Los datos suelen incorporarse a la URL como parámetros.

Conceptualmente:

```text
/login?usuario=ana
```

Es apropiado para solicitudes donde los parámetros forman parte de la identificación de la consulta y no para enviar datos sensibles.

### POST

Los datos se envían en el cuerpo de la petición.

Es habitual para:

```text
creación
modificación
envío de datos
```

---

# 67. `<label>`

Un `label` identifica un control de formulario.

Ejemplo:

```html
<label for="email">
    Correo electrónico
</label>

<input
    id="email"
    type="email">
```

La correspondencia se establece mediante:

```text
for
```

del `label` y:

```text
id
```

del control.

Esto mejora la accesibilidad y usabilidad.

---

# 68. `<input>`

`input` representa numerosos tipos de controles.

Ejemplos:

```html
<input type="text">
<input type="email">
<input type="password">
<input type="number">
<input type="date">
<input type="checkbox">
<input type="radio">
<input type="file">
<input type="submit">
```

---

# 69. TIPOS IMPORTANTES DE `input`

```text
text
password
email
number
date
time
datetime-local
checkbox
radio
file
hidden
submit
reset
button
url
tel
search
```

Conviene reconocerlos.

---

# 70. `name`

El atributo:

```html
name="email"
```

es especialmente importante al enviar datos de un formulario.

Ejemplo:

```html
<input
    type="email"
    name="email">
```

El nombre se utiliza como clave del campo enviado.

---

# 71. `value`

El atributo:

```html
value
```

representa el valor asociado al control.

Ejemplo:

```html
<input
    type="text"
    name="usuario"
    value="Pedro">
```

---

# 72. `placeholder`

Proporciona una indicación o ejemplo dentro del control:

```html
<input
    type="email"
    placeholder="correo@ejemplo.com">
```

No debería utilizarse como sustituto de un `label`.

---

# 73. `required`

Indica que el campo es obligatorio:

```html
<input
    type="email"
    required>
```

El navegador puede realizar validación básica antes del envío.

---

# 74. `disabled`

Un control deshabilitado:

```html
<input disabled>
```

no está disponible para la interacción normal del usuario.

Además, un control `disabled` no se incluye normalmente en el conjunto de datos enviado por el formulario.

---

# 75. `readonly`

Un control:

```html
<input readonly>
```

no puede modificarse normalmente mediante la edición del usuario, pero su valor puede seguir formando parte de los datos enviados.

### 🧠 Trampa

```text
disabled
→ deshabilitado
→ no se envía normalmente

readonly
→ no editable
→ puede enviarse
```

---

# 76. CHECKBOX

Ejemplo:

```html
<input
    type="checkbox"
    name="acepta"
    value="si">
```

Un checkbox puede estar:

```text
marcado
desmarcado
```

Su comportamiento de envío depende de si está marcado.

---

# 77. RADIO

Los botones radio permiten seleccionar una opción dentro de un grupo.

Ejemplo:

```html
<input
    type="radio"
    name="sexo"
    value="hombre">

<input
    type="radio"
    name="sexo"
    value="mujer">
```

El mismo:

```text
name
```

permite agrupar las opciones.

---

# 78. `<textarea>`

Permite introducir texto de varias líneas.

```html
<textarea
    name="comentario"
    rows="5"
    cols="40">
</textarea>
```

---

# 79. `<select>`

Permite seleccionar opciones.

```html
<select name="pais">
    <option value="es">España</option>
    <option value="fr">Francia</option>
    <option value="pt">Portugal</option>
</select>
```

---

# 80. `<option>`

Representa una opción dentro de:

```html
<select>
```

Podemos utilizar:

```html
selected
```

para indicar una opción seleccionada inicialmente.

---

# 81. `<button>`

Representa un botón.

Ejemplo:

```html
<button type="submit">
    Guardar
</button>
```

Los tipos habituales:

```text
submit
reset
button
```

Es recomendable especificar `type` cuando sea relevante, especialmente dentro de formularios.

---

# 82. MULTIMEDIA

HTML moderno permite incorporar multimedia sin depender necesariamente de plugins externos.

Elementos principales:

```html
<audio>
<video>
```

---

# 83. `<audio>`

Ejemplo:

```html
<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>
```

El atributo:

```text
controls
```

permite mostrar controles de reproducción.

---

# 84. `<video>`

Ejemplo:

```html
<video controls width="640">
    <source
        src="video.mp4"
        type="video/mp4">
</video>
```

También puede incluir:

```text
poster
controls
autoplay
muted
loop
```

según las necesidades y restricciones del navegador.

---

# 85. `<source>`

Permite proporcionar diferentes fuentes multimedia:

```html
<video controls>
    <source src="video.webm" type="video/webm">
    <source src="video.mp4" type="video/mp4">
</video>
```

El navegador puede utilizar un formato compatible.

---

# 86. `<iframe>`

Permite incrustar otro documento o contenido de otra fuente.

Ejemplo:

```html
<iframe
    src="https://ejemplo.com"
    title="Contenido externo">
</iframe>
```

Se utiliza habitualmente para:

```text
contenido embebido
mapas
vídeos
documentos
```

según las políticas y capacidades del recurso externo.

---

# 87. SEMÁNTICA Y ACCESIBILIDAD

El HTML semántico ayuda a tecnologías de asistencia a comprender la estructura de la página.

Ejemplo:

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

es normalmente más informativo que:

```html
<div>
<div>
<div>
<div>
```

para representar la misma estructura conceptual.

---

# 88. ATRIBUTOS ARIA

ARIA significa:

```text
Accessible Rich Internet Applications
```

Proporciona atributos que pueden aportar información adicional de accesibilidad cuando el HTML nativo no es suficiente.

Ejemplo:

```html
<button aria-label="Cerrar">
    X
</button>
```

### 🧠 Regla

Cuando existe un elemento HTML semántico adecuado:

```text
preferir HTML nativo
```

antes que utilizar ARIA innecesariamente.

---

# 89. HTML Y ACCESIBILIDAD

Buenas prácticas básicas:

```text
✓ usar HTML semántico
✓ asociar label con controles
✓ proporcionar alt adecuado
✓ mantener estructura lógica de encabezados
✓ utilizar controles HTML nativos cuando sean apropiados
✓ evitar usar div como sustituto de todo
```

# 90. COMENTARIOS

Los comentarios HTML se escriben:

```html
<!-- Esto es un comentario -->
```

No forman parte del contenido visible normal de la página.

# 91. ENTIDADES HTML

Ejemplos:

```text

&nbsp; → espacio no separable
```

Ejemplo:

```html
<p>5 &lt; 10</p>
```

```text
URL absoluta

fragmento
```

Ejemplos:

Una ruta relativa puede utilizar:

Conceptualmente:


# 95. HTML Y DOM

Cuando un navegador procesa un documento HTML, construye una representación estructurada conocida como:

```text
DOM
```

que significa:

```text
Document Object Model
```

Conceptualmente:

```text
HTML
 ↓
DOM
 ↓
estructura de nodos
```

JavaScript puede manipular ese DOM.

```text

│   └── title

└── body
    ├── header
    │   ├── h1
    │   └── nav

    └── main
        ├── section
```

# 97. VALIDACIÓN HTML

Un documento HTML puede validarse para comprobar que cumple determinadas reglas del estándar.

La validación ayuda a detectar:

```text
errores estructurales
atributos incorrectos
elementos mal utilizados
```

No garantiza por sí sola:

```text
buena accesibilidad
buen diseño
buena experiencia de usuario
```

---

# 98. HTML BIEN FORMADO VS VALIDACIÓN

No debemos mezclar HTML con XML.

En XML existe un concepto especialmente estricto de:

```text
bien formado
```

HTML tiene reglas propias de análisis y recuperación de errores.

Por eso no debemos trasladar automáticamente las reglas de XML a HTML.

Esto será importante cuando lleguemos a:

```text
5.8 XML
```
