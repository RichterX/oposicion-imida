# 1. INTRODUCCIÓN A PYTHON

## 1.1 ¿Qué es Python?

**Python** es un lenguaje de programación de alto nivel, interpretado, de propósito general y con una sintaxis orientada a facilitar la legibilidad del código.

Se utiliza en multitud de ámbitos:

- Desarrollo web
- Automatización
- Administración de sistemas
- Análisis de datos
- Inteligencia artificial
- Machine Learning
- Ciencia de datos
- Scripting
- Desarrollo de aplicaciones

Su filosofía pone bastante énfasis en que el código sea fácil de leer y mantener.

# 2. CARACTERÍSTICAS PRINCIPALES

## 2.1 Lenguaje de alto nivel

Python permite trabajar con conceptos relativamente alejados del funcionamiento interno del hardware.

```python
nombre = "Pedro"
```

No necesitamos gestionar manualmente la memoria para almacenar esa variable.

---

## 2.2 Interpretado

Python suele ejecutarse mediante el intérprete de Python.

De forma simplificada:

```text
Código fuente
     ↓
Intérprete Python
     ↓
Ejecución
```

> ⚠️ **Cuidado:** decir simplemente "Python no compila" es una simplificación excesiva. Python puede realizar una fase de compilación a bytecode, que posteriormente ejecuta la máquina virtual de Python.

Para una pregunta de oposición:

> Python se considera habitualmente un lenguaje interpretado.

# 3. MULTIPARADIGMA

Python permite utilizar diferentes estilos de programación.

Entre ellos:

- Programación imperativa
- Programación orientada a objetos
- Programación funcional

### Imperativa

```python
total = 10
total = total + 5
```

### Orientada a objetos

```python
class Persona:
    pass
```

### Funcional

```python
numeros = [1, 2, 3]
dobles = list(map(lambda x: x * 2, numeros))
```

# 4. TIPADO DINÁMICO

Una característica fundamental de Python es su **tipado dinámico**.

Podemos hacer:

```python
valor = 10
```

y posteriormente:

```python
valor = "Hola"
```

La misma variable puede referenciar objetos de tipos diferentes durante la ejecución.

```python
x = 10
print(type(x))

x = "Python"
print(type(x))
```

Resultado conceptual:

```text
<class 'int'>
<class 'str'>
```

---

# 5. TIPADO FUERTE

Python también se considera un lenguaje de **tipado fuerte**.

Esto es importante porque:

```python
numero = 10
texto = "5"

resultado = numero + texto
```

no realiza automáticamente una conversión de `"5"` a entero.

Se produce un error de tipo.

Para realizar la conversión explícitamente:

```python
resultado = numero + int(texto)
```

Resultado:

```text
15
```

### 🧠 Para el examen

```text
Python
├── Tipado dinámico
└── Tipado fuerte
```

No debemos confundir:

```text
Dinámico
≠
Débil
```

# 6. SENSIBILIDAD A MAYÚSCULAS Y MINÚSCULAS

Python distingue entre mayúsculas y minúsculas.

```python
nombre = "Pedro"
Nombre = "Ana"
NOMBRE = "Luis"
```

son **tres identificadores diferentes**.

Por tanto:

```python
nombre
```

no es equivalente a:

```python
Nombre
```

### ⚠️ Trampa de examen

```text
Variable
variable
VARIABLE
```

son nombres diferentes.

# 7. SINTAXIS E INDENTACIÓN

Python utiliza la **indentación para delimitar bloques de código**.

Por ejemplo:

```python
edad = 20

if edad >= 18:
    print("Mayor de edad")
```

La línea `print()` pertenece al bloque del `if` porque está indentada.

La convención habitual es utilizar **4 espacios**.

No debemos mezclar arbitrariamente espacios y tabuladores.

# 8. COMENTARIOS

Los comentarios de una línea comienzan con:

```python
#
```

Ejemplo:

```python
# Esto es un comentario
nombre = "Pedro"
```

Python no posee una sintaxis específica equivalente a `/* ... */` para comentarios multilínea.

Es frecuente utilizar:

```python
# Primera línea
# Segunda línea
# Tercera línea
```

Las cadenas multilínea:

```python
"""
Texto multilínea
"""
```

son objetos `str`, no un operador específico de comentarios.

# 12. CONSTANTES

Python no posee constantes verdaderas impuestas por el lenguaje.

Por convención se utilizan nombres en mayúsculas:

```python
PI = 3.14159
MAX_USERS = 100
```

Pero Python no impide:

```python
MAX_USERS = 200
```

Por tanto:

```text
Mayúsculas
≠
constante protegida por el lenguaje
```

# 22. `=` VS `==`

```python
=
```

es asignación.

```python
==
```

es comparación.

```python
edad = 20
```

asigna.

```python
edad == 20
```

comprueba si `edad` es igual a 20.

---

# 23. OPERADORES LÓGICOS

Python utiliza:

```text
and
or
not
```

### `and`

Ambas condiciones deben cumplirse:

```python
edad >= 18 and edad <= 65
```

### `or`

Al menos una debe cumplirse:

```python
edad < 18 or edad > 65
```

### `not`

Invierte el valor booleano:

```python
not True
```

Resultado:

```text
False
```

# 26. OPERADORES DE IDENTIDAD

Python dispone de:

```text
is

```

Estos operadores comprueban **identidad**, no simplemente igualdad de valores.

---

# 27. `==` VS `is`

```python
a = [1, 2, 3]
b = [1, 2, 3]
```

Entonces:

```python
a == b
```

→ `True`

porque contienen los mismos valores.

Pero:

```python
a is b
```

→ `False`

porque son objetos diferentes.

### Regla

```text
== → igualdad
is → identidad
```
