# 54. ⚠️ ERRORES DE CÓDIGO MUY FRECUENTES

## Error 1: modificar una lista mientras se recorre

Código problemático:

```python
for elemento in lista:
    if condicion(elemento):
        lista.remove(elemento)
```

Puede provocar comportamientos inesperados porque la estructura cambia durante la iteración.

---

## Error 2: confundir `=` con `==`

```python
=
```

asignación.

```python
==
```

comparación de igualdad.

---

## Error 3: confundir `is` con `==`

```python
is
```

identidad.

```python
==
```

igualdad.

---

## Error 4: olvidar que `range()` excluye el final

```python
range(5)
```

produce valores:

```text
0, 1, 2, 3, 4
```

---

## Error 5: olvidar que `input()` devuelve `str`

```python
edad = input("Edad: ")
```

`edad` es una cadena.

Si necesitamos un entero:

```python
edad = int(input("Edad: "))
```

---

## Error 6: usar una clave inexistente en un diccionario

```python
usuario["direccion"]
```

puede producir:

```text
KeyError
```

Una alternativa:

```python
usuario.get("direccion")
```

---

## Error 7: acceder a una posición inexistente

# 55. ⚡ RENDIMIENTO BÁSICO

No necesitamos convertirnos en expertos en optimización, pero debemos comprender algunos conceptos.

Una operación que recorre:

```text
n elementos
```

normalmente tiene un coste aproximado:

```text
O(n)
```

Una operación que no depende del número de elementos:

```text
O(1)
```
