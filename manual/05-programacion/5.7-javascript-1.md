Es importante diferenciar:

```text
JavaScript
```


JavaScript es una implementación/tecnología basada en esa especificación.

Por eso aparecen términos como:

```text
ES5
ES6
ES2015
ES2016
...
```

ES6 corresponde a:

```text
ECMAScript 2015
```

# 5. `defer`

Podemos utilizar:

```html
<script
    src="app.js"
    defer>
</script>
```

`defer` permite descargar el script mientras se procesa el documento y ejecutar el script después de que el documento haya sido analizado, manteniendo el orden entre scripts diferidos.

Es una opción habitual para scripts que dependen del DOM.

---

# 6. `async`

También existe:

```html
<script
    src="app.js"
    async>
</script>
```

Con `async`, el script se descarga de forma asíncrona y se ejecuta tan pronto como está disponible.

A diferencia de `defer`, el orden de ejecución de varios scripts `async` no está garantizado.

### 🧠 Trampa

```text
defer
→ ejecución diferida y orden preservado entre scripts defer

async
→ ejecución cuando está disponible
→ no garantiza orden entre scripts async
```

# 10. `let`

Permite declarar una variable cuyo valor puede reasignarse.

```javascript
let edad = 30;

edad = 31;
```

---

# 11. `const`

Declara un binding que no puede ser reasignado.

```javascript
const nombre = "Pedro";
```

Esto no es válido:

```javascript
nombre = "Juan";
```

### ⚠️ Importante

`const` no significa que el objeto sea completamente inmutable.

Por ejemplo:

```javascript
const usuario = {
    nombre: "Pedro"
};

usuario.nombre = "Juan";
```

Esto sí puede realizarse.

Lo que no podemos hacer es:

```javascript
usuario = {};
```

porque estaríamos reasignando el binding.

---

# 12. `var`

Es la forma tradicional de declarar variables.

```javascript
var edad = 30;
```

En JavaScript moderno normalmente se prefieren:

```text
let
const
```

porque proporcionan un comportamiento de ámbito más claro.

---

# 13. ÁMBITO DE `let` Y `const`

`let` y `const` tienen:

```text
block scope
```

Ejemplo:

```javascript
if (true) {
    let mensaje = "Hola";
}

console.log(mensaje);
```

El código exterior no puede acceder a `mensaje`.

---

# 14. ÁMBITO DE `var`

`var` tiene ámbito de:

```text
función
```

y no de bloque.

Ejemplo:

```javascript
if (true) {
    var mensaje = "Hola";
}

console.log(mensaje);
```

En este caso `mensaje` puede ser accesible fuera del bloque `if`, dentro de la misma función o ámbito global correspondiente.

# 16. HOISTING

JavaScript realiza procesos de inicialización/declaración antes de ejecutar determinados códigos.

Esto se conoce habitualmente como:

```text
hoisting
```

Pero el comportamiento depende de si utilizamos:

```text
var
let
const
function
```

No debemos asumir que todas las declaraciones funcionan igual.

---

# 17. `var` Y HOISTING

Ejemplo:

```javascript
console.log(x);

var x = 10;
```

Conceptualmente, la declaración de `x` se eleva, pero su asignación no.

Por ello el resultado es:

```text
undefined
```

y no:

```text
10
```

---

# 18. `let` Y `const`: TEMPORAL DEAD ZONE

Con:

```javascript

const
```

existe una zona temporal desde el inicio del bloque hasta la declaración denominada:

```text
Temporal Dead Zone
```

Ejemplo:

```javascript
console.log(x);

let x = 10;
```

Esto produce un error en lugar de:

```text

```

# 37. PREFIJO VS POSTFIJO

Esto es importante.

### Postfijo

```javascript
x++
```

utiliza primero el valor y después incrementa.

### Prefijo

```javascript
++x
```

incrementa primero y después utiliza el valor.

Ejemplo:

```javascript
let x = 5;

console.log(x++);
```

imprime:

```text
5
```

Después:

```text
x = 6
```

Mientras:

```javascript
let x = 5;

console.log(++x);
```

imprime:

```text
6
```

# 40. `==`

Realiza comparación estricta.

# 43. AND `&&`

Devuelve un resultado basado en la evaluación de ambos operandos.

Ejemplo:

```javascript
true && true
```

→

```text
true
```

Pero en JavaScript `&&` no está limitado a devolver booleanos: puede devolver uno de los operandos según las reglas de evaluación.

---

# 44. OR `||`

Ejemplo:

```javascript
false || true
```

→

```text
true
```

Al igual que `&&`, puede devolver valores no booleanos.

---

# 45. NOT `!`

Invierte el valor lógico según la conversión booleana:

```javascript
!true
```

→

```text
false
```

---

# 46. SHORT-CIRCUIT

Los operadores:

```text
&&
||
```

utilizan evaluación de cortocircuito.

Ejemplo:

```javascript
false && funcion();
```

La función no necesita evaluarse porque el resultado ya no puede cambiar por el segundo operando.

---

# 47. NULLISH COALESCING `??`

Permite utilizar un valor alternativo cuando el valor de la izquierda es:

```text
null
```

o:

```text
undefined
```

Ejemplo:

```javascript
const nombre =
    usuario.nombre ?? "Anónimo";
```

---

# 48. `??` VS `||`

Esto es muy importante.

```javascript
const valor =
    dato || 10;
```

considera falsy valores como:

```text
0
""
false
null
undefined
NaN
```

mientras:

```javascript
const valor =
    dato ?? 10;
```

solo utiliza el valor alternativo cuando:

```text
null
undefined
```

---

# 49. OPERADOR TERNARIO

Sintaxis:

```javascript
condicion
    ? valorSiTrue
    : valorSiFalse
```

Ejemplo:

```javascript
const mensaje =
    edad >= 18
        ? "Adulto"
        : "Menor";
```

---

# 50. OPTIONAL CHAINING `?.`

Permite acceder a propiedades o llamar determinadas operaciones evitando errores cuando una referencia intermedia es:

```text
null
undefined
```

Ejemplo:

```javascript
usuario?.direccion?.calle
```

Si `usuario` o `direccion` son `null`/`undefined`, la expresión devuelve `undefined` en lugar de intentar continuar el acceso.


# 64. FALL-THROUGH

Ejemplo:

```javascript

        console.log("Dos");
```

Si:


# 70. `for...of`



# 71. `for...in`

Itera sobre propiedades enumerables de un objeto.

Ejemplo:

```javascript

    nombre: "Pedro",

```

Puede producir:

```text

```

### 🧠 Trampa

```text
for...of
→ valores de un iterable

for...in
→ nombres de propiedades enumerables
```

# 77. ARROW FUNCTIONS

# 81. REST PARAMETERS

Permiten recoger múltiples argumentos:

```javascript
function sumar(...numeros) {
    ...
}
```

`numeros` será un array.

Ejemplo:

```javascript
function sumar(...numeros) {
    return numeros.reduce(
        (total, n) => total + n,
        0
    );
}
```

# 82. SPREAD SYNTAX

El operador:

```text
...
```

también puede expandir valores iterables u otras estructuras según el contexto.

Ejemplo:

```javascript
const numeros = [1, 2, 3];

const copia = [
    ...numeros
];
```

Resultado:

```text
[1, 2, 3]
```

### ⚠️ Trampa

El mismo símbolo:

```text
...
```

puede representar:

```text
rest
```

o:

```text
spread
```

según el contexto.

# 84. CLOSURE

Una closure aparece cuando una función conserva acceso a variables de su entorno léxico incluso después de que la función exterior haya terminado.

Ejemplo:

```javascript
function crearContador() {

    let contador = 0;

    return function() {
        contador++;
        return contador;
    };
}

const contador =
    crearContador();

contador();
contador();
```

Resultados:

```text
1
2
```

La función interna conserva acceso a:

```text
contador
```
