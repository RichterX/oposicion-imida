## 5.8 XML

P: Que es XML?
R: Lenguaje de marcado para representar datos estructurados y transportables.

P: Que significa que un XML sea bien formado?
R: Cumple reglas sintacticas: un raiz, etiquetas cerradas y anidamiento correcto.

P: Diferencia entre bien formado y valido?
R: Bien formado cumple sintaxis; valido ademas cumple una definicion (DTD/XSD).

P: Para que sirven los namespaces en XML?
R: Evitar colisiones de nombres entre vocabularios distintos.

P: Que es una DTD?
R: Definicion de estructura permitida en XML con capacidades limitadas.

P: Que aporta XSD frente a DTD?
R: Tipado mas rico, restricciones detalladas y mayor expresividad.

P: Que es XPath?
R: Lenguaje para navegar y seleccionar nodos dentro de documentos XML.

P: Que es XSLT?
R: Lenguaje para transformar XML en otros formatos, incluido XML/HTML/texto.

P: Diferencia entre parser DOM y SAX?
R: DOM carga arbol completo en memoria; SAX procesa secuencialmente por eventos.

P: Cuando conviene SAX frente a DOM?
R: En documentos muy grandes o procesamiento streaming con memoria acotada.

P: Que son atributos en XML?
R: Metadatos de un elemento; su uso debe tener sentido de modelado.

P: Error tipico en XML manual?
R: Etiquetas mal cerradas o jerarquia mal anidada.

P: Diferencia conceptual XML vs JSON?
R: XML prioriza marcado estructurado/extensible; JSON es mas ligero para intercambio de datos.

P: Uso clasico de XML en empresa publica?
R: Intercambio estructurado, integracion entre sistemas y validacion documental.

## Tarjetas de repaso transversal (5.8)

P: Regla de oro al disenar XML?
R: Definir esquema claro y validar siempre antes de integrar.

P: Trampa de examen comun?
R: Confundir bien formado con valido.

P: Objetivo final de 5.8?
R: Comprender modelado, validacion y consulta de datos XML en sistemas reales.
