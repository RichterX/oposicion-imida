## 5.6 CSS

P: Que es CSS?
R: Lenguaje de estilos para definir presentacion visual de documentos HTML.

P: Que es un selector CSS?
R: Patron para apuntar elementos a los que aplicar reglas.

P: Diferencia entre selector de clase e id?
R: .clase aplica a varios; #id apunta a uno unico.

P: Que es especificidad?
R: Regla de prioridad entre selectores cuando varias declaraciones compiten.

P: Cuando se usa !important?
R: Fuerza prioridad, pero debe evitarse salvo casos justificados de mantenimiento.

P: Que es el modelo de caja (box model)?
R: content, padding, border y margin que definen espacio ocupado.

P: Diferencia entre margin y padding?
R: margin separa por fuera; padding agrega espacio interno.

P: Que hace box-sizing: border-box?
R: Incluye padding y border dentro del ancho/alto declarado.

P: Que aporta Flexbox?
R: Distribucion unidimensional de elementos con alineacion y espacio flexible.

P: Que aporta CSS Grid?
R: Diseno bidimensional por filas y columnas.

P: Que son media queries?
R: Reglas condicionales para estilos segun ancho, orientacion u otras caracteristicas.

P: Que son variables CSS (custom properties)?
R: Valores reutilizables declarados como --nombre y usados con var().

P: Que es cascada en CSS?
R: Resolucion final segun origen, importancia, especificidad y orden.

P: Diferencia entre posicion relative y absolute?
R: relative mantiene flujo con desplazamiento; absolute sale del flujo y se referencia a contenedor posicionado.

## Tarjetas de repaso transversal (5.6)

P: Error comun en CSS grande?
R: Escalada de especificidad y uso excesivo de !important.

P: Regla util para responsive?
R: Disenar mobile-first y escalar con media queries.

P: Objetivo final de 5.6?
R: Crear interfaces mantenibles, accesibles y adaptables.
