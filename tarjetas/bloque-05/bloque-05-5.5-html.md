## 5.5 HTML

P: Que es HTML?
R: Lenguaje de marcado para estructurar contenido en la web.

P: Diferencia entre HTML y CSS?
R: HTML estructura; CSS presenta/estiliza.

P: Que es una etiqueta semantica?
R: Elemento que expresa significado estructural (header, nav, main, article, section, footer).

P: Para que sirve el atributo alt en img?
R: Texto alternativo para accesibilidad y contexto si la imagen no carga.

P: Diferencia entre id y class?
R: id identifica elemento unico; class agrupa elementos reutilizando estilos/comportamientos.

P: Para que sirve label en formularios?
R: Asociar texto descriptivo al control y mejorar accesibilidad/usabilidad.

P: Que hace el atributo required?
R: Marca un campo como obligatorio en validacion del formulario.

P: Diferencia entre block e inline a nivel conceptual?
R: Block suele ocupar linea completa; inline fluye dentro del texto.

P: Para que sirve el doctype?
R: Indicar tipo de documento y activar modo estandar del navegador.

P: Que es el DOM respecto a HTML?
R: Representacion en arbol del documento que JavaScript puede consultar/modificar.

P: Para que sirven meta charset y viewport?
R: charset define codificacion; viewport adapta renderizado en moviles.

P: Que implica accesibilidad basica en HTML?
R: Estructura semantica, etiquetas correctas, textos alternativos y navegacion clara.

P: Diferencia entre enlace absoluto y relativo?
R: Absoluto incluye URL completa; relativo depende de ruta del documento actual.

P: Error clasico en formularios?
R: Usar solo placeholders como descripcion en lugar de labels.

## Tarjetas de repaso transversal (5.5)

P: Objetivo de un HTML bien hecho?
R: Estructura semantica, accesible y mantenible.

P: Trampa de examen habitual?
R: Confundir semantica con estilo visual.

P: Prioridad tecnica en HTML?
R: Significado y accesibilidad antes de apariencia.
