# Mini-test - Bloque 07 - 7.4 Firewalls

Marca una opcion por pregunta.

## Preguntas

1. Funcion principal de un firewall:
- A) Comprimir archivos
- B) Filtrar trafico segun reglas
- C) Gestionar bases de datos
- D) Firmar documentos

2. Un firewall puede controlar:
- A) Solo trafico entrante
- B) Solo trafico saliente
- C) Entrante y saliente
- D) Ningun trafico cifrado

3. Stateful inspection aporta:
- A) Eliminacion de puertos
- B) Tabla de estado de conexiones
- C) Sustitucion de DNS
- D) Cifrado cuantico

4. DPI significa:
- A) Dynamic Port Isolation
- B) Deep Packet Inspection
- C) Data Privacy Index
- D) Default Policy Integration

5. NGFW destaca por:
- A) Solo bloquear por IP
- B) No usar reglas
- C) Control de aplicaciones e inspeccion avanzada
- D) Sustituir todo el SOC

6. UTM se caracteriza por:
- A) Unificar varias funciones de seguridad
- B) Ser solo WAF
- C) No incluir VPN
- D) No registrar eventos

7. WAF protege principalmente:
- A) SMTP
- B) HTTP/HTTPS y aplicaciones web
- C) Bluetooth
- D) DNS recursivo

8. SQL injection y XSS suelen mitigarse con:
- A) DHCP
- B) WAF y reglas de aplicacion
- C) RAID
- D) VLAN nativa

9. Segmentacion y microsegmentacion buscan:
- A) Aumentar broadcast
- B) Reducir movimiento lateral
- C) Eliminar logs
- D) Sustituir IDS

10. Permitir TCP/443 implica siempre trafico legitimo:
- A) Verdadero
- B) Falso
- C) Solo en LAN
- D) Solo con IPv6

---

## Plantilla de respuestas

1. B
2. C
3. B
4. B
5. C
6. A
7. B
8. B
9. B
10. B
