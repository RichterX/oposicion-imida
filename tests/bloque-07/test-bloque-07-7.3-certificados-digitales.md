# Mini-test - Bloque 07 - 7.3 Certificados digitales

Marca una opcion por pregunta.

## Preguntas

1. Un certificado digital vincula:
- A) Solo una contrasena con un usuario
- B) Datos de validacion con una identidad
- C) Un antivirus con una licencia
- D) Un dominio con una IP privada

2. En firma asimetrica:
- A) Se firma con clave publica
- B) Se verifica con clave privada
- C) Se firma con privada y se verifica con publica
- D) Solo existe una clave

3. Firma electronica cualificada requiere:
- A) Solo consentimiento
- B) Firma avanzada + certificado cualificado + dispositivo cualificado
- C) Solo OCR del DNI
- D) Solo sello de tiempo

4. Efecto juridico de firma cualificada:
- A) Ninguno
- B) Inferior a firma manuscrita
- C) Equivalente a firma manuscrita
- D) Solo probatorio parcial

5. Firma vs sello electronico:
- A) Son identicos
- B) Firma persona fisica; sello persona juridica
- C) Sello solo para personas fisicas
- D) Firma solo para servidores

6. CSV es:
- A) Un tipo de certificado cualificado
- B) Codigo de verificacion en sede electronica
- C) Un algoritmo de cifrado simetrico
- D) Una CA

7. CRL frente a OCSP:
- A) CRL consulta online y OCSP lista
- B) Son equivalentes tecnicamente
- C) CRL lista de revocados; OCSP consulta de estado
- D) Ninguno se usa para validacion

8. Expiracion y revocacion:
- A) Son exactamente iguales
- B) Expiracion es fin natural; revocacion perdida anticipada
- C) Revocacion solo por caducidad
- D) Expiracion implica delito

9. Para validar firma no basta con:
- A) Revisar integridad
- B) Revisar estado del certificado
- C) Verificar politica y cadena de confianza
- D) Ver que "abre" sin error

10. Las listas de confianza sirven para:
- A) Publicar contrasenas comprometidas
- B) Identificar prestadores/servicios cualificados
- C) Calcular hashes
- D) Reemplazar OCSP

---

## Plantilla de respuestas

1. B
2. C
3. B
4. C
5. B
6. B
7. C
8. B
9. D
10. B
