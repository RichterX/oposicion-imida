# Mini-test - Bloque 03 (Bases de datos)

Marca una opcion por pregunta.

## Preguntas

1. Que es SQL?
A) Un sistema operativo
B) Un lenguaje para gestionar datos en bases relacionales
C) Un protocolo de red
D) Un compilador de C

2. En una tabla relacional, la clave primaria sirve para:
A) Cifrar registros
B) Identificar de forma unica cada fila
C) Ordenar automaticamente por fecha
D) Sustituir indices

3. Que describe mejor una clave foranea?
A) Campo que referencia la clave primaria de otra tabla
B) Campo obligatorio de tipo texto
C) Campo que solo existe en Oracle
D) Campo exclusivo para copias de seguridad

4. PostgreSQL se caracteriza por:
A) Ser un antivirus
B) Ser un SGBD relacional de codigo abierto y extensible
C) Ser un editor de texto
D) No soportar SQL

5. Que lenguaje procedural se asocia a Oracle?
A) T-SQL
B) Bash
C) PL/SQL
D) Kotlin

6. PostGIS es:
A) Una distribucion Linux
B) Un protocolo de tunel VPN
C) Una extension espacial para PostgreSQL
D) Un cliente de correo

7. Que problema reduce la normalizacion?
A) Duplicidad e inconsistencias de datos
B) Fallos electricos
C) Latencia de red fisica
D) Capacidad de disco SSD

8. Que comando SQL crea una base de datos?
A) CREATE TABLE datos;
B) CREATE DATABASE nombre;
C) INSERT DATABASE nombre;
D) NEW DATABASE nombre;

9. Que ventaja aporta un procedimiento almacenado?
A) Ejecutar logica reutilizable cerca de los datos
B) Sustituir el sistema operativo
C) Eliminar la necesidad de claves
D) Evitar completamente los permisos

10. En administracion de BBDD, que combina integridad y rendimiento?
A) No usar indices ni restricciones
B) Definir claves, restricciones e indices adecuados
C) Guardar todo en una sola tabla sin relacion
D) Evitar copias de seguridad

---

## Plantilla de respuestas

1. B
2. B
3. A
4. B
5. C
6. C
7. A
8. B
9. A
10. B
