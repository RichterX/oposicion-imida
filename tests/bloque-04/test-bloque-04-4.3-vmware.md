# Mini-test - Bloque 04 - 4.3 VMware

Marca una opcion por pregunta.

## Preguntas

1. VMware en este contexto se refiere a:
- A) Un unico programa de backup
- B) Un ecosistema de virtualizacion y gestion
- C) Un protocolo de red
- D) Un sistema de archivos

2. vSphere es:
- A) Un antivirus
- B) Plataforma de virtualizacion de servidores
- C) Una distro Linux
- D) Un switch virtual fisico

3. ESXi es:
- A) Un hipervisor tipo 2
- B) Un hipervisor tipo 1
- C) Un NAS empresarial
- D) Un servidor DNS

4. vCenter Server permite:
- A) Gestion centralizada de hosts y clusters
- B) Sustituir almacenamiento SAN
- C) Convertir RAID 5 en RAID 10
- D) Configurar impresoras de red

5. Un host ESXi es:
- A) Una VM de administracion
- B) Un servidor fisico con ESXi
- C) Un repositorio Git
- D) Un cliente iSCSI

6. Que es un datastore?
- A) Un puerto FC
- B) Contenedor logico de almacenamiento para VMs
- C) Un controlador RAID
- D) Una VLAN de gestion

7. Para que sirve vMotion?
- A) Cifrar discos virtuales
- B) Migrar VM en ejecucion entre hosts
- C) Crear snapshots automaticos
- D) Apagar hosts por consumo

8. HA en VMware sirve para:
- A) Reiniciar VMs en otros hosts tras fallo
- B) Balancear carga por CPU
- C) Convertir NAS en SAN
- D) Crear usuarios AD

9. DRS sirve para:
- A) Sustituir firewall
- B) Balancear cargas entre hosts
- C) Gestionar solo backups
- D) Controlar acceso fisico

10. Por que snapshot no es backup completo?
- A) Porque es solo para Linux
- B) Porque no ofrece copia independiente completa
- C) Porque siempre borra datos antiguos
- D) Porque no guarda configuracion
