# Mini-test - Bloque 04 - 4.5 NAS

Marca una opcion por pregunta.

## Preguntas

1. NAS significa:
- A) Network Attached Storage
- B) Node Access System
- C) Native Array Service
- D) Network Admin Server

2. NAS ofrece principalmente almacenamiento:
- A) A nivel de bloque
- B) A nivel de archivo
- C) Solo en memoria
- D) Exclusivo para VMs

3. Protocolos tipicos de NAS:
- A) FC y FCoE
- B) SMB/CIFS y NFS
- C) BGP y OSPF
- D) SIP y RTP

4. En Windows, ruta tipica a un recurso NAS:
- A) /nas/projects
- B) http://nas/projects
- C) \\NAS\Compartido
- D) fc://nas/lun1

5. Un appliance NAS integra:
- A) Solo software
- B) Hardware + software de servicios de archivos
- C) Solo discos externos USB
- D) Solo un switch

6. Snapshots en NAS sirven para:
- A) Sustituir firewall
- B) Capturar estados puntuales para recuperacion
- C) Crear VLAN
- D) Reemplazar RAID

7. Snapshot sustituye backup?
- A) Si, por definicion
- B) No, solo lo complementa
- C) Solo en Linux
- D) Solo en SMB

8. Active Directory en NAS empresarial ayuda a:
- A) Gestionar autenticacion y permisos centralizados
- B) Aumentar IOPS de discos
- C) Eliminar cuotas
- D) Crear datastores VMFS

9. Diferencia base NAS vs SAN:
- A) NAS bloque; SAN archivo
- B) NAS archivo; SAN bloque
- C) Ambos solo archivo
- D) Ambos solo bloque

10. Buena practica de seguridad en NAS:
- A) Acceso admin compartido para todos
- B) Minimo privilegio y actualizaciones
- C) Desactivar auditoria
- D) Evitar segmentacion

## Plantilla de respuestas

1. A
2. B
3. B
4. C
5. B
6. B
7. B
