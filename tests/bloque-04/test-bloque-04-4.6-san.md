# Mini-test - Bloque 04 - 4.6 SAN

Marca una opcion por pregunta.

## Preguntas

1. SAN significa:
- A) Storage Area Network
- B) Server Access Node
- C) Secure Admin Network
- D) Shared Application Namespace

2. SAN entrega normalmente almacenamiento:
- A) A nivel de archivo
- B) A nivel de bloque
- C) Solo en objetos
- D) Solo en cache

3. Una LUN es:
- A) Una VLAN de almacenamiento
- B) Unidad logica presentada por la cabina al host
- C) Un tipo de snapshot
- D) Un puerto de switch Ethernet

4. En iSCSI, initiator y target son:
- A) Cliente/host que inicia y sistema que ofrece bloques
- B) Dos tipos de RAID
- C) Dos controladores de dominio
- D) Dos modos de vCenter

5. HBA en SAN es:
- A) Herramienta de backup automatica
- B) Adaptador especializado de conectividad SAN
- C) Hipervisor bare metal
- D) Politica de firewall

6. En Fibre Channel, WWNN y WWPN identifican:
- A) VLAN y subred
- B) Nodo y puerto FC
- C) Usuario y grupo AD
- D) Disco y particion

7. Zoning se usa para:
- A) Mejorar compresion de datos
- B) Controlar visibilidad entre initiators y targets
- C) Crear snapshots
- D) Configurar DHCP

8. LUN masking sirve para:
- A) Limitar que host accede a cada LUN
- B) Cifrar trafico IPsec
- C) Balancear CPU
- D) Montar shares SMB

9. Multipath (MPIO) permite:
- A) Eliminar todas las rutas salvo una
- B) Multiples rutas para resiliencia y posible reparto de carga
- C) Sustituir zoning
- D) Reemplazar vMotion

10. Puerto habitual de iSCSI:
- A) TCP 22
- B) TCP 80
- C) TCP 3260
- D) TCP 443

3. B
