# Mini-test - Bloque 04 - 4.2 Virtualizacion

Marca una opcion por pregunta.

## Preguntas

1. Que es virtualizacion?
- A) Sustituir discos HDD por SSD
- B) Crear recursos virtuales sobre hardware fisico
- C) Cifrar todas las comunicaciones
- D) Configurar DNS en routers

2. Que problema intenta resolver la virtualizacion clasica?
- A) Falta de usuarios en red
- B) Infrautilizacion de servidores fisicos
- C) Ausencia de correo electronico
- D) Saturacion de impresoras

3. Consolidacion de servidores significa:
- A) Usar mas servidores fisicos
- B) Ejecutar varias VMs en menos hosts
- C) Borrar VMs antiguas
- D) Unir dominios AD

4. Que es un hipervisor tipo 1?
- A) Corre sobre un SO anfitrion
- B) Corre directamente sobre hardware
- C) Solo sirve para contenedores
- D) Solo existe en Linux

5. En virtualizacion, host y guest son:
- A) Dos protocolos de red
- B) Host fisico/hipervisor y SO invitado en VM
- C) Dos tipos de RAID
- D) Dos servicios de correo

6. Que riesgo aumenta con la consolidacion?
- A) Menor eficiencia energetica
- B) Mayor blast radius por caida de host
- C) Menor seguridad fisica
- D) Desaparicion de snapshots

7. Que es oversubscription?
- A) Asignar menos recursos virtuales que fisicos
- B) Asignar mas recursos virtuales que fisicos
- C) Cifrar discos virtuales
- D) Deshabilitar HA

8. Que es RBAC?
- A) Balanceo por latencia
- B) Control de acceso basado en roles
- C) Replicacion binaria de clusters
- D) Reserva basica de CPU

9. Diferencia basica entre VM y contenedor:
- A) VM comparte kernel; contenedor no
- B) VM no usa red
- C) VM incluye SO invitado; contenedor comparte kernel
- D) No hay diferencia real

10. Que practica mejora seguridad de plataforma virtualizada?
- A) Exponer plano de gestion a toda la red
- B) Minimo privilegio y hardening del hipervisor
- C) Desactivar logs para rendimiento
- D) Evitar parches para estabilidad
