# Mini-test - Bloque 01 - Parte B (Windows Server)

Marca una opcion por pregunta.

## Preguntas

1. Windows Server esta orientado principalmente a:
- A) Videojuegos
- B) Uso domestico
- C) Servicios de infraestructura y red
- D) Diseno grafico

2. Que modo de instalacion reduce superficie de ataque al no incluir escritorio completo?
- A) GUI Max
- B) Server Core
- C) Desktop Lite
- D) Safe Desktop

3. En arquitectura Windows, que modo tiene acceso total al hardware?
- A) User Mode
- B) Guest Mode
- C) Kernel Mode
- D) Basic Mode

4. Que sistema de archivos aporta ACL y journaling en servidores Windows?
- A) FAT16
- B) exFAT
- C) FAT32
- D) NTFS

5. Regla basica al combinar permisos compartidos y NTFS:
- A) Prevalece el mas permisivo
- B) Prevalece el mas restrictivo
- C) Siempre gana compartido
- D) Siempre gana NTFS

6. Diferencia correcta entre proceso y servicio:
- A) Son exactamente lo mismo
- B) Servicio suele ejecutarse en segundo plano de forma continua
- C) Proceso solo existe en Linux
- D) Servicio solo se inicia manualmente

7. Cmdlet de PowerShell para listar servicios:
- A) Get-Role
- B) Show-Service
- C) Get-Service
- D) List-Service

8. Que rol proporciona resolucion de nombres en red?
- A) DHCP
- B) IIS
- C) DNS
- D) Hyper-V

9. Herramienta clave para revisar eventos del sistema:
- A) Event Viewer
- B) Paint
- C) Notepad
- D) Disk Cleanup

10. Que principio conviene seguir al instalar roles?
- A) Instalar todos por si acaso
- B) Minimo privilegio e instalar solo lo necesario
- C) Desactivar logs
- D) Evitar copias de seguridad

---

## Plantilla de respuestas

1. C
2. B
3. C
4. D
5. B
6. B
7. C
8. C
