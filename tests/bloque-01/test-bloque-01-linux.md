# Mini-test - Bloque 01 - Parte A (Linux)

Marca una opcion por pregunta.

## Preguntas

1. Que comando muestra la ruta actual?
- A) ls
- B) pwd
- C) cd
- D) whoami

2. Que directorio suele almacenar configuracion del sistema?
- A) /etc
- B) /tmp
- C) /home
- D) /opt

3. Cual es la diferencia correcta entre cp y mv?
- A) cp mueve, mv copia
- B) Ambos borran origen
- C) cp copia, mv mueve o renombra
- D) No hay diferencia

4. Que identifica de forma unica a un usuario en Linux?
- A) GID
- B) SID
- C) PID
- D) UID

5. Que comando cambia permisos de archivos?
- A) chown
- B) chmod
- C) usermod
- D) umask

6. Que herramienta muestra procesos en tiempo real?
- A) top
- B) lsblk
- C) crontab
- D) passwd

7. Para que sirve un pipe (|) en bash?
- A) Para borrar salida
- B) Para enviar salida de un comando a otro
- C) Para abrir editor
- D) Para comprimir archivos

8. Que comando de systemd muestra el estado de un servicio?
- A) systemctl status nombre-servicio
- B) service --show nombre-servicio
- C) journalctl start nombre-servicio
- D) ps status nombre-servicio

9. En apt, que hace apt update?
- A) Instala kernel
- B) Elimina paquetes obsoletos
- C) Actualiza el indice de repositorios
- D) Actualiza todos los binarios sin confirmacion

10. Para que sirve cron?
- A) Cifrar discos
- B) Programar tareas periodicas
- C) Montar volumenes
- D) Crear usuarios
