# Mini-test - Bloque 05 - 5.9 JSON

Marca una opcion por pregunta.

## Preguntas

1. JSON significa:
- A) Java Structured Object Notation
- B) JavaScript Object Notation
- C) Joint Schema Open Network
- D) Java Optional Namespace

2. Que tipos admite JSON?
- A) object, array, string, number, boolean, null
- B) function, symbol, undefined
- C) class y interface
- D) solo strings

3. En JSON, nombres de propiedades deben ir:
- A) Sin comillas
- B) Con comillas simples obligatorias
- C) Con comillas dobles
- D) Entre parentesis

4. JSON.parse hace:
- A) JS -> JSON string
- B) JSON string -> valor JS
- C) Valida XSD
- D) Crea cookie

5. JSON.stringify hace:
- A) JSON string -> JS
- B) String -> numero
- C) JS serializable -> JSON string
- D) Ejecuta fetch

6. JSON admite comentarios estandar?
- A) Si
- B) No
- C) Solo en arrays
- D) Solo en objetos vacios

7. Diferencia entre null y clave ausente:
- A) Ninguna
- B) null es valor explicito; ausente no existe
- C) Ausente equivale siempre a 0
- D) null invalida todo JSON

8. Riesgo comun al consumir JSON externo:
- A) Confiar estructura sin validar campos/tipos
- B) Usar UTF-8
- C) Usar HTTPS
- D) Usar parse

9. Por que JSON es popular en APIs?
- A) Porque solo funciona en Python
- B) Porque es ligero y ampliamente soportado
- C) Porque reemplaza HTTP
- D) Porque evita autenticacion

10. Al serializar, undefined/funciones/Symbol:
- A) Tienen representacion JSON directa estable
- B) Nunca afectan salida
- C) Se incluyen siempre como texto
- D) No tienen representacion JSON directa habitual
