# Mini-test - Bloque 05 - 5.8 XML

Marca una opcion por pregunta.

## Preguntas

1. XML se usa para:
- A) Markup de datos estructurados
- B) Compilar Java
- C) Ejecutar consultas SQL
- D) Definir CSS

2. Documento bien formado significa:
- A) Validado con XSD siempre
- B) Cumple reglas sintacticas XML
- C) Tiene al menos dos raices
- D) Solo contiene texto

3. Diferencia bien formado vs valido:
- A) Son lo mismo
- B) Bien formado es mas exigente que valido
- C) Valido cumple DTD/XSD ademas de sintaxis
- D) Valido no necesita sintaxis

4. Namespaces en XML sirven para:
- A) Cifrar etiquetas
- B) Evitar colisiones de nombres
- C) Añadir CSS inline
- D) Reemplazar XPath

5. XSD frente a DTD aporta:
- A) Menor expresividad
- B) Tipado y restricciones mas ricas
- C) Solo comentarios
- D) Renderizado en navegador

6. XPath se usa para:
- A) Consultar/navegar nodos XML
- B) Validar CSS
- C) Crear APIs REST
- D) Compilar JSON

7. XSLT se usa para:
- A) Transformar XML a otros formatos
- B) Evitar validacion
- C) Sustituir namespaces
- D) Ejecutar SQL

8. DOM parser frente a SAX:
- A) DOM streaming; SAX carga todo
- B) SAX carga todo; DOM no
- C) Son identicos
- D) DOM carga arbol completo; SAX procesa por eventos

9. Cuando conviene SAX?
- A) Documentos grandes y memoria acotada
- B) Solo documentos pequenos
- C) Cuando no hay eventos
- D) Nunca

10. Diferencia conceptual XML vs JSON:
- A) XML suele ser mas marcado/extensible; JSON mas ligero
- B) JSON siempre valida esquema automaticamente
- C) XML no admite jerarquia
- D) JSON no se usa en APIs

---

## Plantilla de respuestas

1. A
2. B
3. C
4. B
5. B
6. A
7. A
8. D
9. A
10. A
