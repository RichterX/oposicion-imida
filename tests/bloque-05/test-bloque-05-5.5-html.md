# Mini-test - Bloque 05 - 5.5 HTML

Marca una opcion por pregunta.

## Preguntas

1. HTML se usa principalmente para:
- A) Estructurar contenido
- B) Compilar Java
- C) Crear sockets
- D) Sustituir CSS

2. Etiquetas semanticas sirven para:
- A) Cambiar color automaticamente
- B) Expresar significado estructural del contenido
- C) Cifrar formularios
- D) Evitar accesibilidad

3. El atributo alt en img aporta:
- A) Animacion obligatoria
- B) Texto alternativo para accesibilidad/contexto
- C) Tamaño en pixeles
- D) Conexion HTTPS

4. Diferencia entre id y class:
- A) id para muchos y class para uno
- B) Son equivalentes siempre
- C) id unico, class reutilizable
- D) id solo en CSS y class solo en JS

5. Para que sirve label en formularios?
- A) Mejorar asociacion y accesibilidad de controles
- B) Sustituir input
- C) Añadir cookies
- D) Evitar validacion

6. Que hace required?
- A) Desactiva campo
- B) Marca campo obligatorio
- C) Convierte texto a numero
- D) Sube archivo automaticamente

7. Doctype en HTML5:
- A) Cambia URL del sitio
- B) Indica tipo de documento y modo estandar
- C) Define variables CSS
- D) Solo sirve en XML

8. Meta viewport ayuda a:
- A) Integrar SQL
- B) Compilar JavaScript
- C) Adaptar renderizado en moviles
- D) Habilitar CORS

9. Diferencia conceptual bloque vs inline:
- A) Inline ocupa linea completa siempre
- B) Bloque suele ocupar linea completa; inline fluye en texto
- C) No hay diferencia
- D) Solo depende de JavaScript

10. Error comun en formularios accesibles:
- A) Usar labels claros
- B) Evitar placeholders
- C) Usar id unicos
- D) Depender solo del placeholder sin label
