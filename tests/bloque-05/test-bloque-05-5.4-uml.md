# Mini-test - Bloque 05 - 5.4 UML

Marca una opcion por pregunta.

## Preguntas

1. UML es:
- A) Un lenguaje de programacion
- B) Un lenguaje estandar de modelado
- C) Un motor de base de datos
- D) Un framework CSS

2. Un diagrama de clases muestra principalmente:
- A) Flujo de red
- B) Logs de ejecucion
- C) Clases, atributos, metodos y relaciones
- D) Solo casos de uso

3. Una asociacion en UML representa:
- A) Relacion estructural entre clases
- B) Herencia obligatoria
- C) Dependencia temporal de CPU
- D) Regla SQL

4. Diferencia agregacion vs composicion:
- A) Son iguales
- B) Agregacion fuerte, composicion debil
- C) Agregacion debil; composicion fuerte con ciclo de vida dependiente
- D) Solo se usa en diagramas de secuencia

5. Multiplicidad indica:
- A) Numero de lineas en diagrama
- B) Cardinalidad de la relacion
- C) Version de UML
- D) Cantidad de metodos

6. Diagrama de secuencia sirve para:
- A) Modelar mensajes en orden temporal
- B) Definir esquema JSON
- C) Calcular especificidad CSS
- D) Gestionar paquetes npm

7. Diagrama de casos de uso enfatiza:
- A) Estructura de clases privadas
- B) Actores y funcionalidades desde perspectiva de usuario
- C) Rendimiento del compilador
- D) Direcciones IP

8. Diagrama de actividades modela:
- A) Solo estados de objetos
- B) Flujo de trabajo, decisiones y paralelismo
- C) Unicamente relaciones de herencia
- D) Exclusivamente paquetes

9. Diagrama de estados se usa para:
- A) Representar transiciones de estado por eventos
- B) Dibujar tablas SQL
- C) Medir latencia de red
- D) Crear APIs REST

10. Beneficio practico de UML en equipos?
- A) Sustituir pruebas unitarias
- B) Aumentar ambiguedad
- C) Prohibir cambios de diseno
- D) Mejorar comunicacion tecnica y alineacion
