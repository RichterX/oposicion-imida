# Mini-test - Bloque 05 - 5.6 CSS

Marca una opcion por pregunta.

## Preguntas

1. CSS se usa para:
- A) Definir presentacion visual
- B) Almacenar datos relacionales
- C) Compilar bytecode
- D) Gestionar hilos

2. Que es especificidad?
- A) Prioridad entre selectores cuando compiten reglas
- B) Tamaño de fuente por defecto
- C) Numero de archivos CSS
- D) Tipo de protocolo HTTP

3. Que hace !important?
- A) Elimina cascada
- B) Fuerza prioridad de declaracion, con uso limitado recomendado
- C) Convierte regla en media query
- D) Solo funciona en inline styles

4. Modelo de caja incluye:
- A) header, main, footer
- B) content, padding, border, margin
- C) rgb, hsl, hex
- D) select, option, input

5. Diferencia margin vs padding:
- A) margin interno, padding externo
- B) Son iguales
- C) margin externo; padding interno
- D) Solo aplican a tablas

6. box-sizing: border-box implica:
- A) width/height excluyen border y padding
- B) width/height incluyen padding y border
- C) No afecta dimensionado
- D) Desactiva flexbox

7. Flexbox esta orientado a:
- A) Layout unidimensional
- B) Layout bidimensional exclusivo
- C) Solo tipografias
- D) Seguridad web

8. Grid destaca por:
- A) Solo alineacion vertical
- B) Layout bidimensional filas/columnas
- C) Reemplazar HTML
- D) Evitar media queries

9. Media queries permiten:
- A) Ejecutar JavaScript
- B) Cambiar estilos segun condiciones del dispositivo/viewport
- C) Definir claves primarias
- D) Parsear JSON

10. Cascada CSS resuelve estilos segun:
- A) Orden alfabetico de selectores
- B) Solo primer archivo cargado
- C) Origen/importancia/especificidad/orden
- D) Tipo de navegador unicamente
