# 🎯 FASE 1 · DEFINIR EL OBJETIVO

## 1.1 ¿Cuál es exactamente el objetivo del muestreo?

### Respuesta modelo

Determinar si existe contaminación química en la parcela y obtener muestras suficientemente representativas de las distintas zonas para poder evaluar la presencia y concentración del contaminante y comparar los resultados entre ellas.

No se trata simplemente de encontrar la zona más contaminada, sino de obtener información fiable sobre el conjunto estudiado.

### 🧠 Clave

```text
OBJETIVO
→ detectar / cuantificar
→ contaminación
→ en la parcela
→ con muestras representativas
```

---

## 1.2 Propiedad principal

> **La representatividad.**

La muestra debe reflejar, dentro de los límites del diseño, las características relevantes del conjunto que queremos estudiar.

---

# 🗺️ FASE 2 · DISEÑAR EL PLAN

## 2.1 Elementos del plan de muestreo

Una respuesta válida podría incluir:

```text
1. Objetivo del muestreo.
2. Población / lote / parcela objeto del estudio.
3. Puntos o zonas de muestreo.
4. Método de selección de los puntos.
5. Número de muestras.
6. Tipo y cantidad de muestra.
7. Material y equipos necesarios.
8. Personal responsable.
9. Método de identificación.
10. Condiciones de conservación.
11. Condiciones de transporte.
12. Procedimiento de recepción.
13. Análisis previsto.
14. Documentación y registros.
15. Gestión de incidencias.
```

No era necesario escribir los 15. Con ocho bien planteados ya se cumplía el ejercicio.

---

## 2.2 ¿Aleatorio, sistemático, dirigido o combinación?

### Respuesta recomendada

**Una combinación de métodos**, porque el escenario proporciona información previa relevante.

Por ejemplo:

```text
DISEÑO GENERAL
→ distribución aleatoria o sistemática
       +
PUNTOS DIRIGIDOS
→ zonas especialmente relevantes
```

La zona norte tiene un antecedente potencialmente contaminante.

La zona sur presenta síntomas.

La zona este está junto a una acequia.

Estas circunstancias justifican incorporar puntos específicos en esas zonas, pero **sin abandonar el muestreo de las zonas restantes**.

### 🧠 Idea clave

No debemos elegir entre:

> "representativo"

y:

> "dirigido".

Podemos utilizar un diseño general representativo e incorporar puntos dirigidos para estudiar hipótesis concretas.

---

## 2.3 Muestrear únicamente la zona sur

### Ventaja

Permitiría estudiar con detalle la zona donde aparecen síntomas.

### Problema

La muestra estaría sesgada hacia la zona aparentemente afectada y podría no representar las cuatro hectáreas.

### Solución

Mantener un diseño que incluya toda la parcela y añadir muestras específicas de la zona sur.

```text
PARCELA COMPLETA
      ↓
MUESTREO GENERAL
      +
MUESTREO DIRIGIDO EN ZONA SUR
```

# 📍 FASE 3 · SELECCIÓN DE PUNTOS

## 3.1 Propuesta de distribución

No existe una única distribución correcta.

Una respuesta razonable:

```text
Zona norte:
→ varios puntos, incluyendo proximidad al antiguo almacenamiento.

Zona centro:
→ varios puntos distribuidos de forma regular.

Zona sur:
→ varios puntos generales + puntos dirigidos en zonas con síntomas.

Zona este:
→ varios puntos, incluyendo proximidad a la acequia.
```

Por ejemplo:

```text
NORTE    → 3 puntos
CENTRO   → 3 puntos
SUR      → 4 puntos
ESTE     → 2 puntos
```

Total:

```text
12 muestras
```

La cifra es un ejemplo de diseño, no una cantidad universal.

---

## 3.2 ¿Por qué no basta una muestra en el centro?

Porque una única muestra puede no representar:

```text
zona norte
zona sur
zona este
zona centro
```

Además, existen factores que pueden producir distribución espacial desigual:

```text
antiguo almacenamiento
+
síntomas vegetales
+
acequia
+
dirección del viento
```

Una única muestra podría ocultar variaciones importantes.

---

## 3.3 Importancia del viento

Sí.

El viento predominante norte → sur podría constituir una información relevante para plantear una posible distribución del contaminante.

No demuestra que exista contaminación ni determina por sí solo el diseño.

Pero puede justificar:

```text
mayor atención
+
puntos adicionales
+
comparación norte/sur
```

---

## 3.4 Zona próxima a la acequia

La acequia podría constituir una vía potencial de:

```text
entrada
+
dispersión
+
transporte
```

de determinados contaminantes.

Por ello resulta razonable incluirla específicamente en el plan y comparar sus resultados con puntos alejados de la acequia.

# 🧪 FASE 4 · TIPO Y CANTIDAD

## 4.1 Muestra elemental vs compuesta

### Muestra elemental

Es una porción tomada en un punto concreto.

```text
PUNTO A → MUESTRA A
PUNTO B → MUESTRA B
PUNTO C → MUESTRA C
```

### Muestra compuesta

Se obtiene combinando varias porciones o muestras elementales.

```text
A ─┐
B ─┤
C ─┼──→ COMPUESTA
D ─┘
```

Puede utilizarse para representar mejor un conjunto homogéneo o reducir el número de análisis, siempre que el procedimiento lo permita.

---

## 4.2 ¿Una única muestra compuesta para toda la parcela?

**No necesariamente.**

En este escenario sería poco recomendable porque las cuatro zonas presentan características diferentes.

Una muestra compuesta de toda la parcela podría ocultar diferencias entre:

```text
NORTE
SUR
ESTE
CENTRO
```

Sería más razonable plantear muestras separadas por zonas o subzonas.

---

## 4.3 Cantidad

No existe una cifra universal.

Dependerá de:

```text
tipo de muestra
+
método analítico
+
cantidad necesaria para el análisis
+
sensibilidad
+
posibles repeticiones
+
homogeneidad
+
condiciones de conservación
+
normativa / protocolo
```

### 🧠 Trampa

Si una pregunta de examen proporciona una cantidad concreta en un protocolo, debemos seguir esa cantidad.

Si no la proporciona:

> **no debemos inventar una cifra.**

# 🧰 FASE 5 · PREPARACIÓN DEL MATERIAL

## 5.1 Lista posible

Por ejemplo:

```text
1. Recipientes adecuados.
2. Bolsas o tubos de muestreo.
3. Etiquetas.
4. Marcador indeleble.
5. Guantes.
6. Gafas de protección.
7. Bata / ropa de protección.
8. Herramientas de toma.
9. Material para limpieza de herramientas.
10. Nevera o sistema de transporte adecuado.
11. Elementos refrigerantes si proceden.
12. Documentación / actas.
13. Hoja de registro.
14. Material para sellado o precintado.
15. EPI adicional según riesgo.
```

---

## 5.2 ¿Por qué evitar contaminación del material?

Porque una herramienta contaminada podría transferir sustancias desde una muestra anterior a otra.

Resultado:

```text
MUESTRA A
   ↓
CONTAMINA HERRAMIENTA
   ↓
MUESTRA B
   ↓
FALSO RESULTADO / CONTAMINACIÓN CRUZADA
```

Esto puede alterar los resultados y comprometer el estudio.

---

## 5.3 Medidas contra contaminación cruzada

Cualquier cuatro razonables:

```text
1. Limpiar las herramientas entre muestras.
2. Utilizar material desechable cuando proceda.
3. Cambiar guantes cuando sea necesario.
4. Utilizar recipientes limpios.
5. Separar físicamente las muestras.
6. Evitar que los recipientes entren en contacto con superficies contaminadas.
7. Utilizar procedimientos normalizados.
8. Trabajar siguiendo el orden establecido por el procedimiento.
```

---

# 🏷️ FASE 6 · IDENTIFICACIÓN

## 6.1 Código

Una posibilidad:

```text
IMIDA-2026-09-17-SUR-1030-PEDRO-01
```

O, si queremos un sistema más compacto:

```text
IMI-260917-S-1030-01
```

Lo importante no es el formato exacto, sino que permita identificar inequívocamente la muestra y relacionarla con sus registros.

---

## 6.2 Datos asociados

Al menos seis:

```text
1. Código de muestra.
2. Fecha.
3. Hora.
4. Lugar / punto de muestreo.
5. Procedencia.
6. Responsable / técnico.
7. Tipo de muestra.
8. Cantidad.
9. Condiciones de conservación.
10. Proyecto / estudio.
11. Observaciones.
12. Lote o parcela cuando corresponda.
```

---

## 6.3 ¿Por qué no basta "MUESTRA SUR"?

Porque no permite identificar inequívocamente:

```text
qué muestra
+
qué día
+
qué hora
+
qué punto
+
qué técnico
+
qué proyecto
```

Dos muestras diferentes podrían terminar etiquetadas exactamente igual.

Eso destruye la trazabilidad.

## 7.1 Factores que pueden afectar

Por ejemplo:

+

+

+

---

## 7.2 Medidas generales

```text
1. Utilizar envases adecuados.
2. Mantener la temperatura establecida.
3. Proteger de la luz cuando corresponda.
4. Reducir el tiempo hasta el análisis.
5. Evitar humedad o exposición cuando proceda.
6. Mantener los recipientes cerrados.
7. Registrar las condiciones relevantes.
8. Evitar contaminación cruzada.
```

---

## 7.3 ¿Por qué no todas las muestras igual?

Porque cada matriz puede tener distinta estabilidad.

Por ejemplo:

```text
MUESTRA A
→ necesita refrigeración

MUESTRA B
→ necesita congelación

MUESTRA C
→ debe protegerse de la luz
```

La condición correcta depende de:

```text
naturaleza de la muestra
+
analito
+
método
+
protocolo
```

# 🚚 FASE 8 · TRANSPORTE

## 8.1 Tres aspectos fundamentales

```text
1. IDENTIDAD
2. INTEGRIDAD
3. CONDICIONES DE CONSERVACIÓN
```

Esta tríada es excelente para memorizar.

---

## 8.2 Recipiente roto

Procedimiento razonable:

```text
1. Garantizar la seguridad.
2. Evitar exposición / contaminación.
3. Aislar el recipiente.
4. Registrar la incidencia.
5. Comprobar si la muestra puede recuperarse.
6. Evaluar si se ha comprometido su integridad.
7. Informar al responsable.
8. Decidir aceptación/rechazo según procedimiento.
9. Documentar la decisión.
```

No debemos simplemente reparar el recipiente y fingir que no ocurrió.

---

## 8.3 Pérdida del registro de temperatura

**No debemos declarar automáticamente inválidas todas las muestras.**

Primero habría que conocer:

```text
qué tipo de muestra es
+
qué condiciones requería
+
cuánto duró el transporte
+
qué temperatura era necesaria
+
qué otras evidencias existen
+
si puede demostrarse que las condiciones se mantuvieron
```

Después:

```text
evaluar
+
documentar
+
decidir
```

## 9.2 Temperatura incorrecta

No debe analizarse automáticamente como si nada hubiera ocurrido.

Procedimiento:

```text
REGISTRAR INCIDENCIA
       ↓
EVALUAR IMPACTO
       ↓
CONSULTAR PROCEDIMIENTO
       ↓
DECIDIR ACEPTACIÓN / RECHAZO
       ↓
DOCUMENTAR
```

Puede ser necesario consultar al responsable del estudio o del laboratorio.

---

## 9.3 Muestra sin código ni documentación

**No debería aceptarse directamente como una muestra trazable para análisis.**

La identificación es insuficiente y no podemos establecer con seguridad:

```text
origen
+
responsable
+
fecha
+
proyecto
```

Debe registrarse la incidencia y seguir el procedimiento establecido para muestras no conformes.

# 🔗 FASE 10 · TRAZABILIDAD

## 10.1 Cadena

Una respuesta posible:

```text
1. Proyecto / estudio.
2. Parcela / lote.
3. Punto de muestreo.
4. Toma de muestra.
5. Identificación.
6. Conservación.
7. Transporte.
8. Recepción.
9. Análisis.
10. Resultado.
```

---

## 10.2 ¿Qué significa trazabilidad?

Significa poder reconstruir y relacionar de manera documentada el recorrido y la historia de una muestra:

```text
ORIGEN
→
TOMA
→
CONSERVACIÓN
→
TRANSPORTE
→
RECEPCIÓN
→
ANÁLISIS
→
RESULTADO
```

---

## 10.3 Importancia

Porque permite demostrar:

```text
de dónde procede
+
quién la tomó
+
cuándo
+
cómo se conservó
+
qué análisis recibió
+
qué resultado produjo
```

Sin trazabilidad, el resultado pierde capacidad de ser interpretado y defendido.

# 🧠 FASE 11 · DETECTANDO ERRORES

## Caso A

> El técnico toma todas las muestras de la zona sur.

### Problema

Sesgo de selección.

### Por qué

La zona sur presenta síntomas, pero el objetivo es estudiar la parcela completa.

### Solución

Mantener muestreo general y añadir muestreo dirigido en la zona sur.

---

## Caso B

> Misma espátula sin limpiar.

### Problema

Contaminación cruzada.

### Solución

Limpiar adecuadamente entre muestras o utilizar material adecuado/desechable según procedimiento.

---

## Caso C

> Código, fecha, procedencia, pero no responsable.

### Problema

Trazabilidad incompleta.

### Solución

Registrar quién realizó la toma y completar la documentación.

---

## Caso D

> Una muestra enorme del centro.

### Problema

No garantiza representatividad.

El tamaño de una muestra no sustituye un buen diseño espacial.

### Solución

Distribuir adecuadamente los puntos de muestreo.

---

## Caso E

> Envase roto.

### Problema

Compromiso potencial de:

```text
integridad
+
contaminación
+
cantidad
+
conservación
```

### Solución

Registrar, evaluar y decidir según procedimiento.

---

## Caso F

> Análisis correcto, muestra no representativa.

### Respuesta

**A) Muestreo.**

El análisis puede estar perfectamente realizado.

El problema apareció antes:

```text
selección incorrecta
→ muestra sesgada
→ resultado no representativo
```

# ⚖️ FASE 12 · ERROR DE MUESTREO VS ANALÍTICO

## 12.1 Error de muestreo

Es el error introducido durante:

```text
selección
+
diseño
+
toma
+
representatividad
```

### Ejemplo

Tomar únicamente muestras de la zona sur sintomática y extrapolar sus resultados a toda la parcela.

---

## 12.2 Error analítico

Es el error introducido durante el análisis.

Puede estar relacionado con:

```text
método
+
equipo
+
reactivos
+
calibración
+
procedimiento
+
medición
```

---

## 12.3 Ejemplos

### Error de muestreo

```text
Muestrear solo la zona contaminada
y asumir que representa toda la parcela.
```

### Error analítico

```text
Aplicar incorrectamente el método,
utilizar un equipo mal calibrado
o cometer un error de medición.
```

# 🚨 FASE 14 · SITUACIÓN FINAL

## 14.1 ¿Representan las 4 hectáreas?

**No podemos afirmarlo.**

El hecho de que las muestras tengan códigos y que el análisis sea correcto no garantiza representatividad.

---

## 14.2 Problema metodológico

Existe:

> **sesgo de selección / muestreo no representativo.**

Se seleccionaron deliberadamente zonas sintomáticas.

---

## 14.3 ¿Muestreo o análisis?

**Muestreo.**

El problema aparece en la selección de las muestras.

---

## 14.4 ¿Qué hacer?

Proponer una nueva campaña o muestreo complementario diseñado para cubrir adecuadamente toda la parcela.

Por ejemplo:

```text
MUESTREO GENERAL REPRESENTATIVO
        +
PUNTOS DIRIGIDOS EN ZONAS SOSPECHOSAS
```

Después comparar los resultados.

No deberíamos simplemente borrar los datos anteriores. Los resultados obtenidos deben conservarse y documentarse como procedentes de un diseño sesgado.

# 🧠 FASE 16 · LAS 5 PREGUNTAS DE ORO

## 1. ¿Qué es lo más importante que debe garantizar una muestra?

> **Representatividad**, cuando el objetivo es extrapolar el resultado al conjunto estudiado.

---

## 2. ¿Qué información permite hablar de trazabilidad?

Como mínimo debemos poder relacionar inequívocamente:

```text
identificación
+
procedencia
+
fecha/hora
+
responsable
```

junto con el resto de registros necesarios durante el recorrido de la muestra.

El material de examen plantea precisamente esta combinación como referencia de una identificación completa. fileciteturn28file0L43-L50

---

## 3. ¿Diferencia entre muestra dirigida y representativa?

### Dirigida

Seleccionada deliberadamente por una característica o sospecha concreta.

### Representativa

Diseñada para reflejar adecuadamente el conjunto objeto del estudio.

Una muestra dirigida puede ser útil y científicamente válida para estudiar un problema concreto, pero no necesariamente representa todo el lote.

---

## 4. ¿Puede un análisis perfecto compensar un muestreo incorrecto?

> **No.**

```text
MALA MUESTRA
+
BUEN ANÁLISIS
=
RESULTADO NO NECESARIAMENTE REPRESENTATIVO
```

---

## 5. Tres palabras que resumen el control

La respuesta más apropiada para este capítulo sería:

> **Identificación + conservación + trazabilidad.**

Si se quiere resumir el control completo:

```text
REPRESENTATIVIDAD
+
TRAZABILIDAD
+
INTEGRIDAD
```

# ⚠️ ERRORES QUE QUIERO QUE EVITES EN EL EXAMEN

### 1. Confundir "muestra grande" con "muestra representativa"

```text
TAMAÑO ≠ REPRESENTATIVIDAD
```

---

### 2. Pensar que una muestra dirigida es mala

No.

Es útil para determinados objetivos.

El problema aparece cuando:

> **una muestra dirigida se utiliza para representar un conjunto que no cubre adecuadamente.**

### 3. Pensar que el laboratorio puede arreglarlo todo

No.

```text
MUESTREO
↓
MUESTRA
↓
ANÁLISIS
```

El análisis no puede reconstruir aquello que nunca se muestreó.

---

### 4. Olvidar al responsable

El material de examen da importancia a quién realiza la toma. fileciteturn28file0L43-L50

### 5. Ignorar incidencias

Una muestra dañada, sin identificación o con condiciones de conservación desconocidas no debe tratarse automáticamente como una muestra normal.

Hay que:

```text
REGISTRAR
+
EVALUAR
+
DECIDIR
+
DOCUMENTAR
```
