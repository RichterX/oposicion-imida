# 📖 ESCENARIO

El **IMIDA** inicia un proyecto de investigación para estudiar la posible presencia de un contaminante químico en una parcela agrícola experimental.

La parcela tiene una superficie de **4 hectáreas** y presenta las siguientes características:

```text
PARCELA A
├── 1 ha → zona norte
├── 1 ha → zona centro
├── 1 ha → zona sur
└── 1 ha → zona este
```

Durante las últimas semanas, el equipo de investigación ha observado que:

- La zona norte se encuentra próxima a un antiguo punto de almacenamiento de productos agrícolas.
- La zona centro presenta un crecimiento vegetal aparentemente normal.
- La zona sur muestra algunas plantas con síntomas.
- La zona este está próxima a una acequia de riego.
- El viento predominante suele desplazarse de norte a sur.

El objetivo del proyecto es:

> **Determinar si existe contaminación y obtener información suficientemente representativa de la parcela para poder comparar las distintas zonas.**

El laboratorio dispone de capacidad para realizar análisis físico-químicos de las muestras.
