La fórmula utilizada es:

``` text
Puntuación = aciertos - (errores × 0,33)
```

Las respuestas en blanco:

``` text

```

### Ejemplo

``` text

```

``` text
55 - (10 × 0,33)
= 55 - 3,30
= 51,70 puntos
```
