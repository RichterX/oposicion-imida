## 🧩 5.3 · POO

### 01 · **B** ✅
Un objeto posee estado, comportamiento e identidad.

### 02 · **B** ✅
La clase actúa como definición o molde; el objeto es una instancia concreta.

### 03 · **A** ✅
La encapsulación agrupa y protege el estado y comportamiento, exponiendo una interfaz controlada.

### 04 · **B** ✅
Coche es un tipo de Vehículo: relación **IS-A**, normalmente asociada a herencia/generalización.

### 05 · **B** ✅
La composición representa una relación parte-todo fuerte, donde el ciclo de vida de las partes está ligado al compuesto.

### 06 · **B** ✅
El polimorfismo permite que una misma operación o interfaz tenga comportamientos distintos según el objeto concreto.

### 07 · **A** ✅
SRP: una clase debe tener una única responsabilidad, o una única razón para cambiar.

### 08 · **B** ✅
OCP: abierto a extensión, cerrado a modificación.

### 09 · **C** ✅
Un diseño saludable busca **alta cohesión + bajo acoplamiento**.

### 10 · **C** ✅
YAGNI: no implementar funcionalidades que no se necesitan todavía.

### 22 · **B** ✅

### 31 · **C** ✅
`<video>` representa contenido de vídeo.

# 🎨 5.6 · CSS

### 33 · **B** ✅
CSS = Cascading Style Sheets.

### 34 · **A** ✅
CSS controla la presentación de documentos estructurados.

### 35 · **C** ✅
Un selector de ID tiene mayor especificidad que uno de clase o de elemento.

### 36 · **A** ✅
`box-sizing` determina cómo se calcula el tamaño total de un elemento respecto a contenido, padding y borde.

### 37 · **A** ✅
Con `border-box`, `width` y `height` incluyen contenido, padding y border.

### 38 · **B** ✅
Flexbox está diseñado principalmente para distribución unidimensional.

### 41 · **B** ✅
`fr` representa una fracción del espacio disponible en Grid.

`grid-template-areas` permite definir áreas con nombres.

### 44 · **B** ✅
Las Media Queries permiten aplicar estilos según características del entorno de visualización.

### 45 · **A** ✅
Media Queries se basan en características del entorno; Container Queries permiten reaccionar al tamaño/condiciones del contenedor.

### 46 · **B** ✅
`transform` permite trasladar, rotar, escalar, etc.

# 📄 5.8 · XML

### 47 · **B** ✅
XML = Extensible Markup Language.

### 48 · **A** ✅
DTD puede definir la estructura permitida de un documento XML.

### 49 · **A** ✅
XSD permite definir estructura y tipos de datos con mayor expresividad.

### 50 · **B** ✅
En DTD, `?` significa cero o una aparición.

### 51 · **C** ✅
En DTD, `+` significa una o más apariciones.

### 52 · **C** ✅
`maxOccurs` establece el máximo número de apariciones.

### 53 · **B** ✅
En XPath, `@id` selecciona el atributo `id`.

### 54 · **C** ✅
`..` representa el nodo padre.

### 55 · **A** ✅
Los predicados `[ ]` permiten filtrar resultados.

### 56 · **A** ✅
XSLT se utiliza para transformar documentos XML.

### 57 · **B** ✅
`xsl:for-each` permite iterar sobre nodos seleccionados.

### 58 · **B** ✅
DOM representa el documento como un árbol en memoria.

### 59 · **B** ✅
SAX procesa XML mediante eventos.

### 60 · **B** ✅
SAX utiliza un modelo orientado a eventos/push; StAX utiliza un modelo pull.

### 63 · **C** ✅
